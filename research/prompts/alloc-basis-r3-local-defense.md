QUESTIONS

Question 1, the central attack. G8's checker-side threshold formula, max(F_effective, oldest valid root in the ring), is literally the same predicate the runtime uses at the moment it reclaims a block, to decide whether that block may leave the defer state. If this shared predicate is computed wrongly anywhere, for example the wrong root is treated as "oldest valid", or F_effective is stale, or there is an off-by-one in the comparison, then both the runtime's defer bookkeeping and G8's checker-side recomputation of the same formula would be wrong in the same way, on the same mirror, and G8 would still report the two sides as equal. Every single mirror produced by that bug would pass G8. Is this exactly the "auditor and audited using the same piece of code" failure that Quote 1's second prohibition names, or is there a specific, mechanical difference between how the runtime uses this predicate and how G8 uses it that keeps them as "different algorithms"? Do not just assert that they are different; name the actual difference, for example: different code path, different input data, different point in time, different representation of the same logical quantity, or anything else concrete. If you cannot find such a difference, say plainly that G8 fails Quote 1's second prohibition, and say exactly which words in Quote 1 it fails.

English translation: "The checker and the implementation share exactly one thing between them: a constants module generated from the kb's field tables; the generator reads from the kb, both sides only consume the generated module, and no one is allowed to hand-edit it (citing machine-first.md: repetition must be generated, not hand-copied). Everything else is not shared at all: address-space newtypes are declared separately on each side, format parsing is written once per side, checksums each use an independent implementation, and the traversal code and the accounting code have empty intersection (citing an already-settled symbol-level test called C12, whose exception clause, 'except for format parsing and constants', is exactly the one being invoked here)."

A second passage from the same decision, quoted exactly (same file, lines 397 to 398): "一条边界要守住：生成器只发射标量值。它一旦开始发射『按字段表算出来的偏移函数』，那就是 D13（验证路线） 明令不许共享的格式解析，而不再是常量。判据是发射物里有没有分支与算术。"

English translation: "One boundary must be held: the generator only emits scalar values. The moment it starts emitting 'offset functions computed from the field table', that becomes the format parsing this decision (D13, titled the verification route) explicitly forbids sharing, and it is no longer a constant. The test is whether what is emitted contains branches and arithmetic."

The reclaim threshold formula max(F_effective, oldest valid root in the ring) is not a plain scalar constant: it takes a max of two values that both change at runtime, so by its nature it has a branch, and it depends on which root currently counts as "oldest valid", which itself depends on the instance table's current contents. By the test just quoted, "whether what is emitted contains branches and arithmetic", this formula resembles the kind of thing this decision's boundary forbids sharing, closer to format parsing than to a constant. Note also that the quoted exception clause above names exactly two categories as shareable in a limited sense, "format parsing" and "constants", each written independently once per side rather than literally shared as code. G8 does not literally share generated code between the runtime and the checker; instead, the checker would contain its own, separately written, second implementation of the same formula. Does that make G8 fall inside what this decision permits, an independent second implementation of the same logical definition, the way checksums or format parsing are each independently written twice, or does it fall outside, because the two implementations, however separately written, are still computing the identical predicate, so a mistake in the shared definition itself propagates to both? Defend by naming the specific distinction between "two independent implementations of one formula" and "one shared formula counted twice", and say which one G8 actually is, and why that placement is correct rather than convenient.
