Setting, all settled in this project. The whole volume is encrypted with an AEAD; the only plaintext left is the superblock and one layer that maps logical identity to physical address, plus a plaintext reverse index. That layer exists for one reason: a mount without the key must still be able to move blocks, because background defragmentation is a hard promise of this design. A mount without the key may move blocks but may not free them; it may only allocate inside a lease area signed by the key side, and at unlock the signature is verified or the whole batch of moves is discarded. A unit header may not carry a physical location or a device id. A data unit carries a plaintext self describing header with a five field identity. Metadata units put their identity into ciphertext once encryption is on. A pointer carries one location entry per replica, and each entry has a keyless ciphertext checksum. Authoritative state is units plus accounting plus roots; indexes are derived. A separate settled rule gives a scan rebuild a way to pick the current version among several physical versions of one unit: each unit header has a write sequence of instance id plus transaction number, an instance table says how far each instance published, and per unit class there is a tie breaking key.

The proposal. The mapping layer entry is logical identity, being tree id, object id, object birth generation and anchor offset, mapping to a physical location, being device id and slot number, plus a keyless ciphertext checksum. It carries no separator keys, no file names, no MAC, and no unit class tag. The layer is derived state: its rebuild source is the self describing unit headers plus the current version rules above. Its integrity rests on three things together: a checker rebuilds it from authoritative state and compares entry by entry, differences are always failures and may never be repaired in place; the lease area signature covers what a keyless mount wrote; and the keyless ciphertext checksum detects corrupted bytes. The proposal states plainly that the entries themselves are not authenticated and that an attacker can rearrange blocks, which an earlier decision already accepted knowingly.
