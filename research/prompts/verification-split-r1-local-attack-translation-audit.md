Row 1. Rule 8 (rules-discipline.md). Source: singlefs-ai-sop-zh/rules/rules-discipline.md:80-87 (section heading + body). First draft rendered "靠 review" as "relies on human review". Final: kept "human review" — added deliberately because this file's own vocabulary elsewhere in the same section distinguishes machine-checkable ("scripts/rules-lint.sh 判") from the remaining half that "机器分不出" (a machine cannot tell it apart), i.e. the review is implicitly by a person; flagged here as an added qualifier rather than silently left in.

Row 2. Fact 3's parenthetical note about "singlefs-ai-sop" vs "singlefs". Source: not a translation of any single source line; this whole sentence was added by this leg. Added because Fact 3's own quoted text contains the string "singlefs-ai-sop" (the SOP's own package name) and Rule 8's test is about the name of "the project that uses it" (the filesystem project, named "singlefs" without the "-ai-sop" suffix); without this note a reader could wrongly read "singlefs-ai-sop" appearing in Fact 3 as itself a violation of Rule 8. Logged as an added clarification, not present in the source line.
