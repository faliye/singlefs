Scrub requires knowing the extension point size to skip it per R3. The size is declared in the superblock of the line. R8 states the plaintext header whitelist for the unit includes only magic, format version, flags, nonce id, length, MAC. The extension point size is not listed in this whitelist, so it resides in encrypted portions of the unit's header. Scrub cannot read encrypted data without the key. Therefore, scrub cannot obtain the extension point size, making it impossible to skip the extension point. This violates R3. The asymmetry where skipping is impossible without the key but verification of the per-location checksum is possible for corruption detection breaks R3's requirement for general tools to skip the extension point. This is a direct counterexample to the candidate conclusion's assumption that existing coverage suffices.
