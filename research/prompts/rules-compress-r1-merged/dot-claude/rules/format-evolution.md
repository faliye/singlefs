# 格式演进纪律

**第一个外部用户出现之前，磁盘格式是软的**：随时可以拆了重做，不需要向后兼容。概念模型要慢（「空间怎么记账」「快照是什么」这类）：要慎重的是 `.claude/kb/decisions/` 下的决策正文，不是 `.rs` 文件。

## 硬约束

- 改格式同步更新 `crates/singlefs-checker/invariants/` 和 checker；三者不同步的 commit 不收。
- 决策变更连同推翻依据记进 `.claude/kb/decisions-history.md` 对应决策的节（形态照 `.claude/rules/changelog-format.md`），正文改 `.claude/kb/decisions/` 下对应文件。
- 有了外部用户，`format-evolution.md` 作废、改为严格兼容：那时直接改它，并把推翻依据写进决策变更史。

## 决策正文只写现状，依据写成指针；决策与实验双向登记

**决策正文**（`.claude/kb/decisions/NN-简称.md`）：

- 首行 `## D<n> 简称 —— 状态`，状态后不加括注（分项计数在索引页，日期与来历在变更史）。唯一例外：半定 / 待定的决策在状态后写「（N 项未定）」（「—— 半定（三项未定）」），N 等于「### 未定项」的条数；写了括注时门禁 doc-decisions 的 kb-shape 格判条数、门禁 doc-experiments 的 decision-links 格判形态，没写括注两格都不红，靠写的人守。
- 开头一段写射程：管什么、不管什么。
- `### 已定项` / `### 未定项` 的索引表每行一句话定案，不抄分项正文、不带日期、不超过 100 字；行末带「**状态：已定。**」，再带「**进度：已实现。**」「**进度：未实现。**」「**进度：无对象。**」三选一（kb-shape 格要的规范标记，不算字数；三个值的判法在 `.claude/kb/decisions.md`「进度」那一段）。
- 未定项的登记行另带两句判定，写在表下那一段 blocking-verdict 格定位不到：「改新池新建文件的字节：否（YYYY-MM-DD，依据：…）」「动不动格式：不动（YYYY-MM-DD，依据：…）」；两句是规范标记，不算字数，日期不算「带日期」。两句量的不是一个集合，不拿一句的结论填另一句：前一句量这一版写不写出不同字节，取值 是 / 否 / 无对象；后一句量它的答案将来会不会改动任何盘上字节或已有字节的解释口径（D15（格式冻结政策） 已定项 1），取值逐字是「**动 / 不动 / 界不定（视同动）**；**没写过视同动**」，`界不定` 不是中立的第三档。
- 每个分项一节 `#### 已定项 N：名字`，标题不带日期与来历，正文四块各以粗体标签开头：`**定案**：` 现行规则，不带日期；`**射程**：` 管到哪、不管什么、已知边角，各一两句，论证、推导、「那个实验量不准」不进射程（进实验页的「它答不了的」或三方判决）；`**依据**：` 只写指针，每条一行——`E<n>（简称）` 证明了什么（一句话，实验页已有的数不抄）、三方判决文件、用户定案（原话在变更史），依据里至少引一个实验，纯政策、没有可量的量的写「无实验：理由」（门禁报出这类分项的数）；`**欠**：` `C<n>（简称）`，没有写「无」。
- 移出正文：定案经过、改前原文、「此前……」「立项那天……」这类只在写下那天成立的句子进当月变更史；推导过程与中间数进依据指到的实验页（已有的不重复）；被否掉的候选的论证留在三方判决或 `records/`。
- 挪的时候不丢内容：旧正文删掉的每个数、式子、代码片段，在新正文、变更史或被指到的实验页里找得到；改动前后逐分项对一遍。与代码、实验、别的决策对不上的现状句按现查结果改成现值；两条已定条款互相矛盾的不在瘦身时判，记进 `.claude/kb/checks-owed.md` 交用户。

**实验页的「影响的决策」**：每个实验页有一节 `### 影响的决策`，表 `| 决策分项 | 关系 | 回看 |`。

- 决策分项写 `D<n>（简称） 已定项 k` 或 `未定项 k`；没有分项的决策、只作背景提到的写 `D<n>（简称）`。实验正文（历史版本与这一节之外）提到的每条决策都要有一行，一条决策撑着几条分项就写几行。
- 实验必须对应决策：至少一行关系是支撑、推翻或备料；结论作废或退役的实验在标题状态里写明，不判这一条。
- 关系取 支撑 / 推翻 / 备料 / 不影响。支撑、推翻写到分项，那条分项的 `**依据**：` 引回这个实验；分项依据里引的每个实验，实验页里都有这一行、关系是支撑或推翻。
- 回看写 `YYYY-MM-DD 改了` 或 `YYYY-MM-DD 不受影响：理由`。实验出了新结论（页内历史节或 `experiments-history.md` 记了新条目、改了正文、换了产物）之后每一行重新回看，日期不早于那次变动；写「改了」的，那条决策文件在同一次改动里。
- 新写的三方判决（`research/prompts/*-main-verification.md`）带一节 `## 回看决策`，同样的表；一条决策都不涉及的写一行「不涉及决策：理由」。

**实验页的「路径与结论登记」**：同一个量用两条或以上互不共享代码的路径各算一遍再比对的实验，有一节 `### 路径与结论登记`，表 `| # | 路径 | 怎么算 | 源码落点 | 读了哪些共用项 |`。

- 路径写它在正文里的名字，逐字一致；按名字认（名字说的是它怎么算，「字节级摆放」「闭式算术」），不按函数名猜。
- 源码落点写 `路径:行号 函数名`，路径在仓里现存；源码里没有对应实现的写「无实现：理由」，那是一条要么补实现、要么别说成「一条路径」的账。
- 共用项写这条路径读的每一个常量、规则、规范，一个不省；写完对每一条问「它错了，这几条会不会一起错」。
- 跨路径的比对断言钉在源码里（`assert_eq!` 这类把两条路径的输出直接连起来比）；没有的在表下写明还欠这一条。
- 结论是全称的（「对所有 X，A 与 B 相同 / 不同」），怎么算一栏写明 X 是扫遍定义域还是几个枚举点，枚举点给理由（欠账 C49（全称断言只在抽样点验过））。

**门禁管哪一半**：门禁 doc-experiments（`.claude/gate.d/doc-experiments.sh`）的 decision-links 格判「影响的决策」的表形、双向对不对得上、回看过没过期、这次改动该回看的回看了没有，还没回填的实验页与决策在 `.claude/decision-links-pending`（只减不增）；同一道的 multipath-registry 格判「路径与结论登记」的表形、源码落点存在、共用项不空，还没补的实验页在 `.claude/gate.d/multipath-registry-lag.tsv`（只缩不涨）。关系判得对不对、回看理由站不站得住、瘦身时丢没丢内容，靠逐分项对照与抽查。

## 让格式永久化的那个动作，触发点必须与拦它的闸在同一条时间线上

写「什么时候起这块字节不能再改」的条款时，同时写清谁在那一刻会被叫醒。叫不醒任何人的，把时刻挪回提交侧，或另给一道运行期的闸（写路径第一次写该结构时自检 spec 在不在、指纹对不对，缺就拒绝写）。

## 改一个格式常量：旧值的派生形态要逐类搜，改完登记进 `stale=`

门禁 code-source-discipline（`.claude/gate.d/code-source-discipline.sh`）的 format-constants 格只核 `const 名字 = 值` 那一行；同一个值的派生形态常量改了不会跟着红：消息串（`expect("148")`）、按预留宽写的读写（`skip(24)`、`len() - 24`）、下标（`[147]`）、倍数（`7 × 148 = 1036`）、商与平方（`⌊16253 / 148⌋ = 109`、`109²`）、测试里钉住的产物值（随字节变的校验和）、门禁脚本里抄过去的数。

1. 动手前按字面量、消息串、预留宽的读写、下标、倍数、商与平方、测试与门禁里钉的产物值逐类全仓搜，输出不截断。
2. 改完把只可能指旧值的串登记进它 `format-const` 标记的 `stale=`（`|` 分隔）。登记前现扫一遍，kb 正文与源码里命中 0 次才登记；裸数字（`148`）不许登记。format-constants 格只扫 kb 正文与 `scripts/experiment-apparatus/`、`research/`、`crates/` 下的 `.rs`（`research/prompts/` 下冻结证据里的 `.rs` 由 `.claude/format-constants-exclude` 放行）；别处（门禁脚本、`research/results/` 下的产物、规则与 agent 定义、`records/`、`research/prompts/`、kb 的历史节与变更史，以及别的 `.md`、`.tsv`、`Cargo.toml`、`litmus/`）照第 1 步手工全仓搜。
3. 标记写在表格单元格里的，挪到表后单独一行：`stale=` 的分隔符 `|` 会切断表格。

## 从写开始，不从读开始

先做写路径（分配策略、事务边界、COW 顺序），再做读路径。
