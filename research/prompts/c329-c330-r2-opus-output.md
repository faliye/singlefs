## 二、模型与口径

- 单元：写序 (实例, 事务号)、诞生代号 b、码 1（`Data`）或码 2 / 3（`Metadata`）；每个单元带两条真值——被挂载根引用、它的发布在不在挂载根的时间线上（被照旧的事务算在收养它的那次发布里）。
- 谓词：D18（块里携带什么信息） 第 879 行，逐分支照写（`published_predicate`）：写序实例 > 挂载根实例判损坏；= 挂载根实例看 b ≤ 挂载根 txg；< 挂载根实例无行判已发布，有行按码 1「b ≤ T_pub ∨ n ≤ W」、码 2 / 3「b ≤ T_pub」。事务号 0（空发布、固定点单元）不进「n ≤ W」（D23（journal 的角色与格式） 已定项 19 ①）。
- 行：按实例唯一、后写覆盖，回退行不被后来的恢复覆盖（`apply_rows`）。
- 违例两类：`wrongly_published` = 判已发布 ∧ 没被挂载根引用 ∧ 不在时间线上（V2 的触发观测）；`wrongly_unpublished` = 判未发布 ∧ 被挂载根引用（V3 的触发观测）。
- 故障计数沿用第一轮反推腿的口径：每次挂载一次崩 + 本次挂载暂时读不出的根数；瞬时单元写错另记一个。
- 它答不了的：没有分配器与空间账（S5 的第二格、`df` 都是推理）；Q330 那两段只算水位与撞号，择根按 (txg, 实例代号) 最大；没有枚举，参数扫只有 S1 那 16 格。确定性模型，每段跑一遍，跑多遍只说明没有隐藏状态。
