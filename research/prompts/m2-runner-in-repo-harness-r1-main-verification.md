## 三、三格逐格判决

### W1　入库装置与「不与实现共用代码」　⇒ **站不住**

攻方腿在副本上**只改一个常量**——`crates/singlefs-format/src/lib.rs` 的 `ROOT_RING_SLOTS_PER_REGION` 从 8 改成 4——重编重跑 `e156_allocation_basis_counts`：

- **代价数整体平移**：`deferred0` 484 → 370、回退候选 24 → 12、`q7b.total_l1` 96 → 85。
- **而 26 行输出逐字相同**（基线 35 行），其中包括装置里**唯一那条钉绝对值的断言**（`matches_registered=true`）、三个基底的 `referenced=12`、三行 checker 的判红判绿。退出码 0。

⇒ 装置与实现共用同一个常量，**两边一起错、逐格相等、没有任何东西会说**。`.claude/rules/implementation-first.md` 第 4 条末半句「装置的数与实现对不上时两边都查」预设两边会对不上；共用常量之后这个触发条件被消掉了。

定义里那三条限制逐条挡不住：「只读、只驱动与观测」——`use` 就是读；「不许改 core 与 checker」——装置一个字没改；「变异表归门禁 59 号」——这一维上没有断言可红。

**主 agent 另行现查坐实的三条**（这一格最要紧的不是装置，是那个常量本身）：

1. `.claude/kb/decisions/22-单元原子性怎么合成.md` 已定项 1 的字段表逐字写：「**具体取多少不是格式决策**——格式承诺的是『S 是系统配置字段 + 挂载时判区间』」，区间 4..16。
2. 而实现是 `crates/singlefs-format/src/lib.rs` 的 `pub const ROOT_RING_SLOTS_PER_REGION: u64 = 8;`——**编译期常量，不是系统配置字段**；全仓对它**零处区间判**。
3. kb 的 `format-const` 登记名里**零处登记**它 ⇒ 门禁 27 号绑不到（自陈只管已登记的常量），92 号也够不着（自陈只判「格式变了 checker 没跟」）。

账已立 C506（每区槽数 S 写成编译期常量，条文说它住系统配置）。⚠️ 这是**今天第三例「条文与实现说反话」**（另两例是回退候选集与步骤种类），据此新立门禁 82 号（条文列的集合与代码里的枚举逐个对上）。

攻方腿提的那一句收严（入库装置不许从 `crates/` 里 `use` 任何决定工作量、几何或判据门槛的常量，改成本地 `const` 加一条回比断言）**被攻过零轮**，而且它自评只挡住一半——挡得住「装置与实现对 S 不一致」，挡不住「kb 与实现一起取错」，因为 kb 今天对 S 没有登记位可抄。

### W2　写范围放宽到 `crates/`　⇒ **推不出**

`.claude/agent-common.md` 与 `.claude/rules/implementation-workflow.md`（全篇对「写范围 / 放行 / 放宽」零命中）都只讲写范围闸怎么执行，**不讲该给一个 agent 多宽的 `crates/` 写权限**。定义里那三条具体限制全部是它自己声明的，不是从共用文件推出来的；而 `.claude/agents/mutation-triage.md` 那条既有分工陈述「`crates/` 那侧派 `implementation-writer`」没有回头改，**两条路并存却互不指认**。

**主 agent 另行现查的一条**：门禁 56 号的正则 `^crates/[^/]+/src/.*\.rs$` **机械地罩住 `crates/*/src/bin/*.rs`** ⇒ 执行员写一个入库装置，就凭空给别人造了一条「代码轮判决要按路径点名它」的义务，而那条义务归 `gate-triage`、定义里一个字没提。今天 56 号能绿，只是因为主 agent 把 e156 那个 bin 列进了代码轮判决的 22 个文件里。

### W3　什么时候该用哪一支　⇒ **推不出**

触发条件挂在写跑前登记的那一方，而 `.claude/agents/experiment-designer.md` 全篇对「入库」与 harness 零命中：**没有一句话给出「入库装置」的判定条件、默认值**，也没有把「装置放在哪」这一格接到它自己已有的歧义处理条款。唯一的实例（E156（alloc-basis 四条岔路的代价数） 的跑前登记）显示这一格实际是「两种读法并列、交主 agent 认」——**拍板人是主 agent，不是设计员**，而定义写的是设计员。
