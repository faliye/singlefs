## 一、这一轮要判什么

第三轮，也是最后一轮（`.claude/rules/three-way-inference.md`「多轮」）。第二轮判决 `research/prompts/m2-rollback-forward-r2-main-verification.md` 第三节列的形态，这一轮攻。第一轮判决 `research/prompts/m2-rollback-forward-r1-main-verification.md` 与第二轮判决整份进材料。

记号：cur = 现行那一版；R_old = 回退目标；new = 回退那次发布写出的新根；Led(v) = 版本 v 的分配记录树（账）；Ref(v) = 从 v 的根走读得到的全部落点；Ref_u(v) = 其中的用户可见单元（数据单元、extent 树、inode 树的单元）；F_d = 盘 d 上最新持久有效根所带的 F。

| 格 | 被攻的形态（式子） | 问题 |
|---|---|---|
| K1 | **挂着时回退的释放与复活**：释放集 = { p : Led(cur)[p] 仍分配 ∧ p ∉ Ref(new) }，释放代 = new 的 txg；复活集 = { p ∈ Ref_u(R_old) : Led(cur)[p] 已释放 }，改回仍分配、分配代 = Led(R_old)[p] 的分配代；inode 号水位与树 ID 水位取环里全部读得出的根的 max | 按式子做，崩在那次发布的每一点、之后最新 1..k 条根读不出、回退之后接着写再回退，落在哪一版、那一版引用的块有没有被复用 |

| K5 | **B1**：卸载那一串把 F 抬到 cur 的 txg，不另判上限；空发布推到每块盘上都有带新 F 的根为止 | 与 K4 三条臂各配一遍，崩在这一串的每一点、之后最新 j 条根坏，落在哪、读不读得对、挂不挂得上 |

| K7 | **旧镜像**：(i) 删见证的同时改格式标记，旧镜像挂载时按不认识的标记拒；(ii) 见证表非空就拒可写挂载、只许只读 | 第二轮 X8 那份旧镜像在两条改法下各是什么结局；有没有旧镜像绕得过去 |
