## 每条决策的步骤

1. 存旧版：`mkdir -p /tmp/claude-1000/slim-<决策号>` 后把决策文件原样拷进去，记 sha256。写新版之前再核一次，对不上就停下交回。
2. 按索引表逐行认分项（个数不写死，有只活在索引表里的分项就补成独立小节）。重写：
   - 首行 `## D<n> 简称 —— 状态`，不带括注；开头一段只写射程。
   - 索引表每行一句话、不带日期、不超过 100 字，行末带 `**状态：已定。**`（未定项写 `**状态：未定。**`）。
   - 每个已定项 `#### 已定项 N：名字`，标题不带日期，四块 `**定案**：` / `**射程**：` / `**依据**：` / `**欠**：`。
   - **射程**只写管到哪、不管什么、已知边角，各一两句；论证、推导、「那个实验量不准」的说明不进射程，挪到实验页已有的「它答不了的」（实验页里已有就删，没有就进变更史改前原行）。
   - **依据**每条一行：`E<号>（简称）：证明了什么`，一句话，**实验页上已有的数不抄**；三方判决写文件路径；用户定案写「原话在变更史」。至少引一个实验；实在没有可量的量写 `无实验：理由`（理由至少八个字）。
   - **欠**写 `C<号>（简称）`，没有写「无」。
   - 规则句的意思、限定词一个都不许丢或放宽。
3. 依据候选与背景分开：旧正文里提到的实验，先判它是不是这条分项的依据（它的结果撑着或推翻了这条规则）。只是背景的（量的是别的事、只借了一个数）不进依据段，报告里列「背景实验：为什么不算依据」。依据段里任何 `E<号>（` 都会被门禁当成依据，所以「某某实验没测什么」这类句子不放进依据段。
4. 腐烂：说「现在怎样」的句子（有没有、几条、宽多少、实现了没）当场现查——读 `crates/`、实验页、别的决策、`.claude/kb/checks-owed.md`——再写现值；每一处在变更史「改后」逐条写，报告里列「原句 / 查了什么 / 改成什么」。两条已定条款互相矛盾的不判，原样保留，报告里列出来。
5. 变更史：在 `.claude/kb/decisions-history/2026-09.md` 的「## 历史版本」下第一条之前加一条，标题 `### 2026-09-19（其N）：D<n>（简称） 按瘦身形态重写——……`。N 在写入的那一条命令里现查当日最大号 + 1；写完跑 `bash .claude/gate.d/32-history-ordinal.sh`，撞号就把自己那条改成下一个空号。两行快查（不写「上面」「这几处」，编号带简称），**改前**用下面这条命令按旧版行号抽原行进 ```text 围栏：`awk -v L="3,5,11-14" 'BEGIN{n=split(L,a,",");for(i=1;i<=n;i++){if(split(a[i],r,"-")==2)for(j=r[1];j<=r[2];j++)k[j]=1;else k[a[i]]=1}} (NR in k){printf "%3d: %s\n",NR,$0}' 存档文件`（只换了块标签、原句一字不差进了新正文的行不用抄），**改后**，**依据**。
6. 核内容没丢、引文没断：`python3 research/scripts/decision-slim-check.py <决策文件> --history .claude/kb/decisions-history/2026-09.md`，退出码 0 才算过。报出的片段逐个处理；报出的「引文断了」，是规则句的把新正文改回逐字一致，是别处在讲历史的，交回报告让主 agent 改。
7. 实验一侧：依据里引到的每个实验页都要有「### 影响的决策」表（放在「## 历史版本」之前）。
   - 表还不存在：在「## 历史版本」前插入整张表。插之前在同一条命令里再查一次这一页有没有「### 影响的决策」——别的 agent 可能刚建了。
   - 表已存在：只插入或改自己那几行（`replace-once.py` 以表头下的分隔行或某一行整行为锚），不重写整张表。
   - 这条决策的分项行：关系写支撑或推翻，与依据段对上；回看写 `2026-09-19 不受影响：理由` 或 `2026-09-19 改了`（只有这次改了规则意思才写改了，瘦身不算）。
   - 同一页正文里提到的其它决策也各写一行（读实验页判：支撑 / 推翻 / 备料 / 不影响；支撑、推翻写到分项，而那条决策还在待回填清单里的，照样写支撑，它瘦身时会引回来）。
   - 每个实验至少有一行是支撑 / 推翻 / 备料（实验必须对应决策）；标题里写着「作废」「退役」的不管这一条。
   - 回看格与理由里提到本页实验写 `E<号>（简称）`，不写「这个实验」。
   - 页上发现现状句腐烂（数与今天对不上、引了一句决策里没有的话）：能现查坐实的直接改，在 `.claude/kb/experiments-history.md` 的「## 历史版本」下加一条（标题 `### 2026-09-19（其N）：E<号>（简称） ……`，取号同第 5 步），实验结论与产物不动；拿不准的列进报告。
8. 待回填清单 `.claude/decision-links-pending`：删掉这条决策那一行，删掉表写全了的实验页那几行（写全 = 页上提到的每条决策都有一行，且至少一行支撑 / 推翻 / 备料）。只删不加。
9. 门禁：逐个跑 `.claude/gate.d/` 下的 20、22、24、28、29、30、32-history-ordinal、37、44、48、51、60、61、75、88、10、26、23、25、43 号与 `bash .claude/scripts/doc-lint.sh "$PWD"`。**不要跑 `21 --write` 与 `49 --write`**（几个 agent 同时写生成块会互相盖，主 agent 最后统一跑）；21、49 号因为生成块没重写而红的，不用管。其余红的修到绿；红的是别的决策或别的会话的文件、不在你这一批的，写进报告，不去改。

## 约束

- 这个仓有别的会话与别的 agent 同时在改。决策文件本身可以整份重写（写前核 sha256）；变更史、实验页、实验变更史、`.claude/kb/checks-owed.md`、`.claude/decision-links-pending` 一律用 `python3 research/scripts/replace-once.py 文件 旧串 新串` 定点改，不许整份重写。
- 只改派发点名的决策、它们引到的实验页、两份变更史、待回填清单。别的决策一个字不动（它们引这条决策的地方要改的，列进报告）。`.claude/kb/checks-owed.md` 不改，要立的账列进报告。
- 不提交、不暂存、不建分支；不用 `git checkout` / `git restore` / `git stash`。
- 长命令放后台（Bash 的 run_in_background），不写 sleep 轮询。

## 交付

报告写到 `/tmp/claude-1000/slim-<组名>/report.md`（分段追加，每次不超过 150 行）；回复只写报告路径与门禁结论。报告每条决策一节：用时（开始、结束的 `date -u`）；正文字数前后（`python3 -c` 数「## 历史版本」之前的字符）；每个已定项的依据引了哪些实验、几个写「无实验」；背景实验与理由；腐烂清单（原句 / 查了什么 / 改成什么）；矛盾；要立的账；动了哪些实验页、哪几页移出了清单、哪几页留着为什么；每道门禁的退出码。
