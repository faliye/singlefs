# E145 跑前登记：码2自描述头与映射树key宽的代价

写于 2026-09-13 08:13 JST，装置写之前。

## 问的是

C306（码 2 头不自描述 key 宽）与 C307（映射树两种 key 宽怎么装进一棵定宽 key 的树）。用户 2026-09-13 定向：「码 2 可以自描述」。
问自描述要付几个字节、掉不掉扇出与树高，以及扫描期没有树表时能不能解出头；映射树两种 key 宽的三条装法各付什么。

## 被测对象的定义（逐字贴）

- D18（块里携带什么信息） 已定项 7 索引节点类身份段：「树 ID + 层级 + **该树已定携带的 key 区间**（D18（块里携带什么信息）已定项 2：记账树已定带、dirent 树推迟、不许外推）+ 诞生代号 + fsid + **写序 4（只实例代号）+ 出生序号 4 + 载荷 CRC 4 + 预留 2**」，「宽度随实现定」。E142（第一个事务的干跑） 按它算出头宽 81 + 2 × key 宽。
- D19（块指针的结构与宽度预算） 已定项 6：「码 1 数据单元 | 类标签 1 + 出生树 8 + 出生 txg 8 + 写序 10（实例代号 4 + 事务号 6） | 27」「码 2 / 码 3 | 类标签 1 + 出生树 8 + 出生 txg 8 + 实例代号 4 + 出生序号 4 | 25」。
- D8（核心索引结构） 已定项 2：节点 16384；D18（块里携带什么信息） 已定项 14：预留位 28 紧接类身份段之后。
- 条目宽照 E142（第一个事务的干跑）：inode 内部 117、extent 叶 109、分配 20、记账 34、映射 55（key 27）/ 53（key 25）、树表 145。

## 臂

码 2 头（C306）：

| 臂 | 头 | 扫描期怎么解 |
|---|---|---|
| A 今天 | 81 + 2 × key 宽 | 没有树表就不知道 key 宽：只能拿登记过的 key 宽逐个试，哪个宽下头校验和过就是哪个；没登记的树解不出 |
| B 自描述 | A + key 宽 1 + 条目数 2 + 条目宽 2 = 86 + 2 × key 宽 | 读头里的 key 宽 |
| C 定宽区间 | 81 + 2 × 32 + 条目数 2 + 条目宽 2 + key 宽 1 = 150 | 头宽固定，key 宽字段说明区间里有效的前几字节 |

映射树（C307）：

| 臂 | 条目 | 树表条目 | 一次点查读几个根 |
|---|---|---|---|
| a 补零到 27 | 55 | 1 | 1 |
| b 两棵树 | 码 1 树 55、码 2 / 码 3 树 53 | 2 | 1（按类挑树） |
| c 自描述条目 | 1 字节 key 长 + key + 28，节点内加 2 字节偏移表 ⇒ 58 / 56 | 1 | 1，但节点内不能定宽二分 |

规模：条目数取 10 TB 池 ÷ 32 KiB = 335 544 320 个数据单元；码 2 / 码 3 按数据单元的 1/8 计（extent 叶 109 字节装 149 条、inode 叶 233 条，取粗档）。

## 判据（跑前写死）

| # | 问 | 判红条件 | 什么观测会让它触发 | 触发时判谁输 |
|---|---|---|---|---|
| 1 | 头宽绝对值 | A 在 key 宽 8 / 12 / 22 / 24 / 27 下不是 97 / 105 / 125 / 129 / 135；B 不是各加 5；C 不是 150 | `header` 行 | 装置算错，改完重跑 |

| 3 | 树高 | 三条臂在规模点上的树高相差 > 0 ⇒ 记下哪棵树、哪条臂 | `height` 行 | 不判输，那是代价 |

**失败条款**：判据 4 的「A 解出没登记的」或「B / C 解不全」触发 ⇒ 整轮作废。**触发观测**：`scan` 行 `resolved` 的数。

## 倾向与反过来

倾向：B 每节点多 5 字节，五棵树扇出各掉 0 或 1，树高一格不掉；C 多 40 到 69 字节，扇出掉 1 到 3；映射树 a 与 b 树高相同、b 多一条树表条目、c 的 58 字节让扇出掉 15 条左右但树高不变。
反过来：若 B 让哪棵树多一层，「自描述便宜」这句就不成立，那格如实记；若 A 的逐宽试探里出现二义（两个宽都过校验和），A 连登记树也不可靠，C306 的严重程度升级。

## 它答不了的

1. 计数模型，不量时间；树高按满装算，真实填充率更低、更高。
2. 扫描解头只造单元头，不造真实池；没登记的树用 key 宽 16 代表「将来的树」。
3. 不答 D15（格式冻结政策） 那层：自描述字段进第 1 层还是第 4 层，由决策定。
4. 确定性：跑 N 遍一样，证据强度来自绝对值断言与变异。
