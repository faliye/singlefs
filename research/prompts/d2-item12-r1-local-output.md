1. No counterexample exists for P0. The lemma correctly states that for w≥3, a parity grid cannot carry self-describing bytes without reserving H bytes per member as all-zero. If a parity grid had a header, the header would not be covered by parity (since parity only covers data payload, not headers), making it unrecoverable on failure. The only solutions are either no header on parity grids (as in the proposal) or all-zero reservations. No layout allows parity grid headers without violating recoverability or adding redundant storage. The step blocking a counterexample is the fundamental constraint that parity operations only cover data payload; headers are outside this scope and thus unprotected.
