# 腿：正推（云端 A / Sonnet）——超级块槽宽取哪一条

**立场：正推。** 从条款与 E126 的数推到结论，把它写成能贴进 D22 的条款。**不要找反例。**

**先读** `research/prompts/_sb-slot-width-background.md`（第 7 节是要判的问题）。原文自己核。

**必须逐条回答**：

1. **四条候选逐条判，给出你推荐的那一条**，并说清它撞的那条条款怎么处置
   （改条款 / 收窄射程 / 拒绝挂载 / 接受代价）。
2. **「超级块槽是不是一个单元」这一问单独答。** `.claude/rules/fs-design.md` 逐字
   「任何不做成单元的盘上空间，自动落在这些机制之外，而且不会有人报警」，并给了五条机制。
   ⇒ 若取甲/乙/丙（槽宽不等于单元大小），超级块槽**是不是**落在那五条之外？
   逐条判那五条对超级块槽今天成不成立。**这一问可能直接决定答案。**
3. **D2 已定硬要求 1 的射程**：它逐字说「不发出小于 `io_min` 的写」。
   这条是为**数据/单元写**立的还是也管固定结构？去读 D2「写的粒度」那一节的上下文。
   若它本来就只管数据写，C212 那条冲突就是**射程问题**不是**槽宽问题**，
   那超级块槽宽的判据里根本不该有 io_min 这一维。**这一问可能整个改变判决。**
4. **给出条款原文**（可直接贴进 D22「已定项」一节，带射程句），
   并明写它**不**解决什么。若你的结论是「今天仍不能定、要用户定案」，
   就写清这个岔路要用户在什么之间选，每条路的代价一句话。
