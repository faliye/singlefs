## 模型

沿用 E127（分裂合并之下组身份要不要存） 的「节点（一个槽装若干 key）」骨架但不分裂不合并：单对象节点装 1 个 key，容器节点装 ≤ 7 个 key。runs 按 **key 序**数：key k 与 k+1 相邻 ⟺ 同一个节点，或两个节点的槽号相邻。跨装置闸：容量 1、不打包、M = 0 时三条 E93 臂族（first_fit / bump_seg / bump_nb / bump_cp）必须逐字复现 E93（老化下的放置与碎片度） 入库产物的 14 个 `aging_median`（与 E95（老化的节点布局臂） 的闸同型）。
到达序：每个 checkpoint 的脏集合先按 E93 的 `dirty_set` 取（保持随机数序列与 E93 一致），再用同一个随机数发生器做一次 Fisher–Yates 洗牌得到到达序；丙按洗牌后的顺序 bump 放置。
容器打包：每个 checkpoint 沿 key 序巡回至多 P = 64 个「上次写距今 ≥ K」的单对象 key，按 key 序每 7 个装一个容器（不足 7 的等下一轮），容器 bump 放置；被写脏的容器成员 COW 成单对象节点搬出。K ∈ {16, 64}。
全空聚簇段数：`free_slots_per_segment == 64` 的段数，每采样点由增量计数与全扫两条路径各算一遍。
提交内生块：每 checkpoint 从 bump 段分配 M 个「内生块」占位（不进 runs），下一 checkpoint 收尾时释放进 defer。

## 判据（跑前写死，跑完不许改）

1. **手算锚点**：8 个 key、16 个槽、段 4，脏 {1, 3, 5, 7} 到达序 [5, 1, 7, 3]：乙把 1,3,5,7 依次放进段 2（槽 8..11）⇒ runs 手算；丙把 5,1,7,3 依次放进槽 8..11 ⇒ runs 手算；两者必须不同，否则丙没有分辨力，整轮作废。容器锚点：8 个 key、K = 0、P = 7 ⇒ 第一次巡回把 0..6 装进一个容器落槽 8，key 7 留在槽 7 ⇒ runs = 2（容器内 0..6 连续、6 与 7 断、7 单独），且容器槽计数 = 1。
2. **守恒**：增量 runs == 审计 runs；每个 key 恰在一个节点里；容器 ≤ 7 个 key；空 + 占 == 总槽数；增量全空段数 == 全扫全空段数；defer 的槽本轮不可复用。
3. **阳性对照每臂都过闸**：强制放置全隔离 runs == L、连续 runs == 1。
4. **跨装置闸**：容量 1、不打包、M = 0 时 14 个 E93 `aging_median` 逐字复现，对不上判红。
5. **M 的回落率**：bump_seg 在 M = 0 时的 fallback_pct 与 E93 产物同（92%–94%）；M = 4 / 9 报出来，不判。
6. **要回答的两问**（报数，判决归 D3（空间分配） 未定项 8 的三方）：(a) 丙与乙的 runs 中位数之差在两组负载 × 三档 M 上各多少；若六格都在 ±5% 以内 ⇒ E93 的 bump_seg 数可当到达序基线用，否则 D3（空间分配） 未定项 8 的候选表要换成丙的数。(b) 容器臂（K = 16 / 64）的 runs、全空聚簇段数、写放大比乙各多少；打包之后全空段数有没有从 0 变成正数。
7. 不判降级、不定政策：判决归 D3（空间分配） 未定项 8。
