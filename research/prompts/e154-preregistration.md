## 一、问题

主 agent 给的问题逐字：

> 一个「只有抬 F 才装得下」的写请求，在分配准入两道闸的几种读法下、配两种回收时点，走到哪一步、付出多少：
> - 删掉 s 字节之后，同样大小的写要经过几次改变用户可见状态的发布才成功（D3（空间分配） 已定项 9 第 2 条的界 3 按这种发布计；报每一次的轨迹，不只报成功那一次）；
> - 用户看到的 `df` 报出 ≥ s 而写 s 失败的次数（D3（空间分配） 已定项 9 第 1 条）；`df` 的读法写死为「第一道闸左边」，第一道闸按 D28（挂载期承诺量） 已定项 2 读「已发布统计量 − 在飞已批准」；
> - 一次准入里推空发布的次数（上限 B = 4 + 2 k_tol，D16（发布语义） 已定项 1）；
> - 回收比「F 写进第一条根」推迟了几次发布；
> - 有没有卡死：抬 F 自己的空发布分配不到固定点、进程之后再也发不出固定点。
>
> 两道闸的三种读法：
> - 串：照 `.claude/kb/decisions/03-空间分配.md` 已定项 12 的字面，先过 D28（挂载期承诺量） 已定项 1 的「可用 ≥ 需求」，不过就拒；过了再走 D16（发布语义） 已定项 1 的抬 F 逻辑。
> - 串-重判：第一道闸不过时推一次抬 F 的空发布、回收、重判第一道闸，至多 B 次，过了再走第二道闸。
> - 合：第一道闸把「抬 F 在有界步数内放得回来的已释放」算作可用，用户看到的 `df` 取 D16（发布语义） 已定项 1 的 `df` 式子。
>
> 两种回收时点：
> - G7：两块盘都带上新 F 的持久根之后才回收；记账行按「这条根持久之后的 F_生效」判可再分配。
> - F-扣：写第一条带新 F 的根之前回收并扣住（被扣住的槽不发），每块盘都带上新 F 之后放开；记账行按这条根自己带的 F 判。
>

> 第 1 项「已分配」的口径写死为占着（仍分配 + 已释放而不可再分配），D28（挂载期承诺量） 已定项 1 里「− defer 待释放」那一项按这个口径删掉（不删就重复扣，这一点不是这个实验问的，登记里写明取法）。

## 五、臂、阳性对照、真实基线

纯计数模型：没有 I/O、没有并发、没有随机源，同一份输入跑 N 遍必然一样；跑多遍只说明没有隐藏状态，证据强度来自「七」的绝对值断言与「九」的变异。

### 5.1 模型的世界（所有臂共用）

| 项 | 取法 |
|---|---|
| 盘 | 两块等大；每块盘单元区 C 个 16 KiB 槽；每个单元两盘同槽，所以槽状态只存一份（R1） |
| 槽状态 | 空闲 / 仍分配 / 已释放（带释放代 g、带「空发布放掉的」标志 e）/ 扣住（只有 F-扣 一族有）；另有一个与状态正交的「隔离」位（影子账，只在 H6 出现）。守恒：空闲 + 仍分配 + 已释放 + 扣住 = C，每个事件之后断言 |
| 分配 | 取槽号最低的可发槽（空闲 ∧ 不隔离 ∧ 不扣住）；数据单元 2 槽、起点偶数；固定点每槽 1 个（R12） |
| 根环 | R = 3 个区域、每区 S 槽；txg 落区域 txg mod 3、槽 (txg / 3) mod S；区域设备 [0, 1, 0]。写失败的槽保留旧内容 |
| 一条持久根记 | txg、实例、所带 F、落在哪块盘、非空与否、被抛弃与否（按实例表）、这次发布之后全部槽状态的快照（重建与回退从它载入）、它引用的槽 = 快照里仍分配的槽 |
| F_生效 | 两块盘各取「该盘上持久有效根所带 F 的最大值」，再取两者的小值（`recovery.rs` 351–371 行同式） |
| 环里最旧有效根 | 环里持久、自证合法、不被实例表判为被抛弃的根的最小 txg |
| 抬 F 上限 | min(两块盘各自最新的持久有效根的 txg 的小值, 第 4 新的非空持久有效根的 txg)；有效含 txg ≥ F_生效；非空不足 4 个取最旧有效根 |
| 候选集（安全检查用） | 持久 ∧ 有效 ∧ txg ≥ F_生效 的根，加上环里还在的被抛弃根（D23 已定项 14：被抛弃时间线的根离开根环之前它们引用的单元不许重新分配） |
| 一次发布 | ① 释放：上一版的 c 个固定点槽 → 已释放（g = 这次 txg，e = 这次是空发布）；用户发布里被删对象的数据槽 → 已释放（e = 否）；写行发布把旧实例表 2 槽 → 已释放（e = 是）② 分配：已批准请求的数据槽、c 个固定点槽、写行发布另加实例表 2 槽；任何一格分配不到 ⇒ 这次发布不成立，槽状态退回发布之前（`transaction.rs` 954–960 行同形），记一次「发布分配失败」③ 写根：成功则持久；注入的失败走 R8 ④ 持久之后：更新 F_生效、环里最旧有效根、已发布统计量（记账行），按回收时点回收 |
| 发布的种类 | 用户发布（封住一个窗口，里面有已批准的写或删；非空）；推空发布（空）；写行发布与暖机空发布（空）；回退那次发布（非空，R9）。改变用户可见状态的发布 = 非空发布 |
| 开销 | 每次发布的固定点 c = c_max 槽（R3）；写行发布另加 2 槽实例表链 |
| 删除 | 不过准入（D3（空间分配） 主结论第 3 条管的是「任何增加空间占用的操作」）；一个删除自成一个窗口、马上封成一次用户发布 |
| 写 | 过准入（按臂）；批准时「在飞已批准」加 2n；窗口封住时分配 2n 数据槽、在飞减 2n；数据分配不到记一次「准入过了而分配失败」、这个请求报 ENOSPC、窗口里其余内容照发 |
| 切换预留 M_sw | 挂载时 = (N_switch + 1) × (2 + R × c) 槽，N_switch = 3；挂载的写行与暖机做完扣掉一份，平时 = 3 份；每次实例切换做完再扣一份（R8） |
| 崩溃与重开 | 进程没了：扣住、在飞、影子账都丢；恢复选 txg 最大的持久有效根，从它的快照载入槽状态，按 max(F_生效, 环里最旧有效根) 回收（立刻可发）；取新实例、写行发布（空，带 F_生效）、暖机空发布到本实例的根覆盖两块盘（带同一个 F）；M_sw 回到 4 份再扣一份 |
| 管理员回退 | 进程重开：从候选里选 R_old；取新实例；槽状态从 R_old 的快照载入，按 max(F_生效, 环里最旧有效根) 回收；影子账：只被环里被抛弃根引用、不被候选根引用、不在 R_old 快照里仍分配的槽置隔离位；回退那次发布（非空，txg = 环里最大 txg + 1，写实例表 2 槽 + c）；暖机；I_gate 按 R11 算。之后每次发布持久时重算隔离集（被抛弃根转出环的，它独有的槽取消隔离），每次抬 F 时按新 F 的候选集重算 |

记账行（已发布统计量里的「占着」）在第 p 条根持久时算：占着_pub(p) = 仍分配 + 「按行规则不可再分配的已释放」。行规则：已释放 ∧ g ≤ max(F_行, 根 p 持久之后的环里最旧有效根) 算可再分配；F_行 由回收时点定（5.3）。扣住的槽在记账里算空闲。

### 5.2 闸读的量（单位：每块盘的槽）

| 名字 | 式子 |
|---|---|
| U | 可发的空闲槽（空闲 ∧ 不隔离 ∧ 不扣住） |
| U_all | 全部空闲槽（含隔离与扣住） |
| Rel | 已释放槽数（全部） |
| L_meta | 活元数据 = 最近一次持久发布写出的固定点槽数（R4），等于 c |
| P_ck | checkpoint 保留池 = c（D28（挂载期承诺量） 已定项 4） |
| P_push | 推空保留池 = 10 + 7c |
| Res | 推空最坏残留 = 5 + 6c |
| lag | 滞后量 = #{已释放 ∧ g > max(第 4 新的非空持久有效根的 txg, 环里最旧有效根) ∧ e = 否} |
| InF | 在飞已批准（不含正在判的这个请求） |
| I_gate | 被抛弃根独占量（R11）；H6 之外恒 0 |
| 可用_串 | C − 占着_pub − M_sw − I_gate − P_ck − InF（D28 已定项 1，「已分配」读成占着、删掉「defer 待释放」一项，待删占用、已承诺预留、不可回收都是 0） |

| 可分配_D16 | min(U − InF + L_meta − P_push, df_D16 − InF)（R5） |

`df` 报出的空闲按臂取（5.3），单位换成字节时乘 16384；写 s = 2n 槽。

### 5.3 臂

一条臂 = 闸的读法 × 回收时点 × 推空停法，共 4 × 3 × 2 = 24 条。每条臂的「怎么做」只用 5.1 与 5.2 的量写；「做完会怎样」只写从「怎么做」直接推得出的东西，不写它在哪一格赢。

一次准入的发布预算：这次准入开始之后发起的每一次发布尝试（推空、根写失败的那次、切换的写行发布、暖机空发布）都计数，计到 B = 8 就停、报 ENOSPC（记成「B 做满」）。

**推空一次**：发一次推空发布，所带 F = max(F_顶, 目标)；F_顶 = 已持久的根里所带 F 的最大值，目标 = min(已释放槽里 g 的最大值, 抬 F 上限)。同窗里有已批准的请求时，第一次推空封住那个窗口、成为非空用户发布（R7）。

| 读法 | 怎么做 | 做完会怎样（推得出的） | 支持它的人怎么说 |
|---|---|---|---|

### 5.4 历史

公共前缀：起点是第一次挂载做完的状态——环里有 txg 0（mkfs，盘 0）、1、2（暖机，分落盘 1、盘 0）三条根，都是空发布，F = 0，c 个固定点槽与 2 个实例表槽仍分配，其余空闲，M_sw = 3 份。

**填满**：先写对象 X（n 个单元，一个请求一个窗口），再一个接一个写 1 单元的填充对象，直到某个填充写报 ENOSPC（按臂自己的准入，推空照做）。X 最先写，所以 X 的槽号最低、刚回收就会被最低槽政策复用（给安全检查一个敏感的取样点）。
**垫片**：删 p 个填充对象（p ∈ {0, 1, 2}，每个一次用户发布），让后面的推空落在 txg mod 3 的不同相位上；每个处置实际需要几次覆盖记成观测量。
**删 X**：一次用户发布，记为 P_d。
**触动**：删一个填充对象（一次非空发布）。
**重试循环**：尝试写 Y（n 个单元）；不成就触动一次，再尝试；最多 J_max = 3S + 5 次触动。每次尝试记一行（「八」）。

| 历史 | 前缀之后做什么 | 对应问法里的哪一句 |
|---|---|---|
| **H1** | 填满、垫片、删 X、重试循环（第 0 次尝试紧跟 P_d） | 写满后删一个对象再写回同样大小 |
| **H2** | 就是 H1 里 n = 1 的格：X 是 2 槽，小于 c = 4 与 c = 9 的一次空发布固定点 | 删的对象小于一次空发布的固定点块数；n = 16（32 槽）是它的对面 |
| **H3a** | 填满、垫片、删 X、连续 3 次触动（中间不尝试）；然后同一个窗口里先到请求 A（n 单元）、后到请求 B（1 单元），两个都判完再封窗；没成的那个进重试循环 | 同一个窗口里两个请求一起准入、其中一个触发推空 |
| **H3b** | 同 H3a，先到 B（1 单元）、后到 A（n 单元） | 同上，次序反过来 |
| **H4a** | 同 H3a 的前缀到 3 次触动；尝试写 Y；这次准入里第一条带新 F 的推空根持久之后立刻崩溃（这条根只在一块盘上）；重开；重试循环接着走（触动计数接着数） | 推空发布之中崩溃，第一条带新 F 的根只落了一块盘，再重开 |
| **H4b** | 同 H4a，崩在这次准入的第二次推空已经分配、单元写完、根还没持久的时候 | 同上，崩在第二条根之前 |

### 5.7 真实基线

真实基线 = **串-重判 × G7**，两种推空停法各算一条（P-止、P-满），因为 D16 已定项 1 的停法本身有两种读法（R6）。它是主 agent 说三轮三方之后站住的那一组，也是要写进 `crates/` 的候选；「真实基线」只是角色，不是预设它赢。今天的实现最接近的是 F-扣（抬 F 部分），准入部分没有对应。

对照组分工照 `.claude/singlefs-ai-sop/rules/test-discipline.md`：阳性对照（5.6）测不出差异 ⇒ 装置有问题、作废；真实基线与对面的臂测不出差异 ⇒ 正当结果，如实记下（失败条款 F6）。

每个旋钮的两个（或三个）取样点方向相反，理由在 5.5。每个 臂 × 历史 × 量 的判定（Q1、Q2a、Q2b、Q3、Q5a、Q5b、Q6、Q7）逐个旋钮比：其余旋钮固定、只动这一个，判定翻面就记「不稳定：<旋钮> 从 <点> 到 <点>」；不翻就记两点的值。比较结论（「X 胜 / 输 / 同」）同样逐旋钮比。

报一张「翻面表」：行 = 臂 × 历史 × 量，列 = C、n、c、S、pad，格里写「翻」或「稳」加两点的值。任何一格「翻」的判定，写结论时不许说「这是这条臂的性质」，只能说「在 <这些点> 上是 X、在 <那些点> 上是 Y」（`.claude/rules/mutation-sampling.md` 第六类）。

判别力自证（跑完产物之后、写结论之前做一次）：挑一个在两个 S 取样点上 K_成 不同、而在门槛 3 下判定相同（翻面表里是「稳」）的 臂 × 历史，把 Q1 门槛临时改成两点 K_成 的中间值，翻面表那一格必须由「稳」变「翻」；改回去再跑翻面表，必须回到「稳」。挑不出这样的格，就在 Q2a 上用同样办法做（门槛挪到两点次数之间）；两个量都挑不出，翻面表记「判别力没有自证」，敏感性结论降为「没看到翻面，检查分不分得出没证」。

def serial_k(S, d=100):
    # 串：只有触动发布，没有推空；ring 3S 槽，槽号 (region=txg%3, slot=(txg//3)%S)
    ring = {}
    for txg in range(0, d + 1):
        ring[(txg % 3, (txg // 3) % S)] = txg
    k = 0

        oldest = min(ring.values())

            return k
        k += 1
        t = d + k
        ring[(t % 3, (t // 3) % S)] = t
