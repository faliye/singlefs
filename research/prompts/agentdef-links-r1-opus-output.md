## 打中 1：两种次序都红，而两份定义各自都照字面做对了

### 这条缝的机制

75 号判据 ③ 是**双向**的（`75-decision-experiment-links.sh:9-10`，整行抄）：

```
#   ③ 双向：关系是支撑或推翻的那条分项，它的「**依据**」段要引回这个实验；反过来，
#      分项「**依据**」段引的每个实验，那个实验页里要有这一行、关系是支撑或推翻。待回填清单里的决策不判这一条。
```

两侧各由一个 agent 独占：实验页那张表只许 `experiment-runner` 写（`agent-write-scope.tsv:15` `experiment-runner	.claude/kb/experiments/**	实验页`；现查写范围闸，`experiment-runner` 写 `.claude/kb/decisions/19-块指针的结构与宽度预算.md` 退出码 2）；依据段只许 `kb-scribe` 写。

新加的两句把这两侧**互设成对方的前置条件**：

- `experiment-runner.md:35`（7b，整行的一段）：「**支撑与推翻写到分项**（`D<n>（简称） 已定项 k`），写之前查那条分项的「**依据**」段引没引这个实验，引不回的改写成备料或不影响、把这一格列进报告」 ⇒ **依据段先引，才准写支撑**。
- `kb-scribe.md:30`（3b）：「缺行、分项号对不上、或关系是备料 / 不影响的，逐条列进报告交主 agent，**不自己动实验页的表**（判关系不在你的活里）」 ⇒ **表先是支撑，书记员才不报缺**；而它照样得把依据写下去，因为 `kb-scribe.md:22` 明写「依据里至少引一个实验」，`kb-scribe.md:13` 又明写「照规格写，不补内容、不做判断」，它不能自己把那条引用删掉。

两侧各自等对方先动，而两个 agent 都被禁止先动对方那一格。

## 打中 3：改成备料之后依据段还引着——③ 决策侧判红

直接答：**判红，类别是「不对称」，点名的文件是决策文件**。副本状态 B 的那一行原样：

```
      [不对称] .claude/kb/decisions/19-块指针的结构与宽度预算.md：D19 已定项 5 的依据引了 E96，.claude/kb/experiments/96-混合架构的一致性.md 的影响的决策表里没有「支撑 / 推翻」这一行
```

判它的是 `75-decision-experiment-links.sh` 的决策侧那一段（行 `342-345`）：`ok` 要求表里存在 `parse_decision_ref(cells[0]) == (decision, item)` 且关系在 `BASIS_RELATIONS = ('支撑', '推翻')` 里——**备料不在里面**。7b 的「引不回的改写成备料或不影响」在这一侧是**没有出口的**：它只在实验页那一侧（行 `322-324`，只对支撑 / 推翻生效）躲开了红，决策那一侧照红不误。

换句话说，7b 那半句给出的「安全降级」只对**依据段确实没引**的情形安全。而它指示执行员去查的是「那条分项」，不是「所有依据引了这个实验的分项」——只要有**任何**一条分项的依据引着这个实验、而表里没有对应的支撑 / 推翻行，75 号就红。执行员按 7b 字面做完，根本不会去看别的分项。这就接到下面的附格。

**推翻这一条的现象**：75 号把 `BASIS_RELATIONS` 扩到含备料，或 ③ 决策侧那一段被删。两者今天都不成立（行 `64`、`342-345` 现查在）。

## 打中 4：一个 agent 跑红了另一个该写的那一格——书记员那侧是死结

两侧不对称，因为 75 号两个方向**点名的文件不同**：

| 谁跑 75 号 | 红的类别与点名的文件 | 那个文件在它这一轮的改动里吗 | 共用约束给的出口 |

| `experiment-runner` | 决策侧不对称，点名 `.claude/kb/decisions/*.md` | 不在（它的写范围不含 decisions/，闸退出码 2 实测） | 有：照 `agent-common.md:49` 不修、照写 |
| `kb-scribe` | 决策侧不对称，点名 `.claude/kb/decisions/*.md` | **在**——那正是它这一轮刚写的文件 | **没有** |

`agent-common.md:49` 整行抄：

```
- 退出码 77 是「本次未跑」，不是通过。红了先看它点名的文件与行在不在这一轮的改动里；不在的不修，照写。
```
