### 1.2 读法写死

- **事务、发布、写**：事务 T1…Tk 按取号先后编号（事务号即下标）。每个事务写 1 个数据单元 U（D16 已定项 5 的「一事务一单元」）与 r 条记录（r ∈ {1, 2}，D23 已定项 7「可以跨多条」；提交标记在它 jsn 最大的那条上）。每次发布另写 1 个共享单元 S（D23 已定项 17 的共享提交内生块，抽象成一个写）、1 个根槽 FUA 写 F、1 个系统配置轮换写 C。一次发布的写序照 D16 已定项 7：本发布的 U 与 S → 屏障 → 本发布的记录 → 屏障 → F（FUA）→ C → 屏障。
- **设备**：一块盘（抽象；`crates/` 每个写与屏障都发到每块盘，`crates/singlefs-core/src/transaction.rs:285`、`:332`–`:339`，两块盘时屏障也是每块盘各一道，见第三节）。切段照 D13 已定项 4 原样：屏障关段；FUA 写关掉它所在的段、与那一段里前面没被屏障隔开的写同段；C 是原地覆写，取三态（新 / 没持久 / 撕），其余写取两态；同一块盘上连着的屏障并成一道。
- **崩溃状态**：一个历史在一个臂下可能有多个执行（写的发出次序）；崩溃状态 = （持久集合，连同每条持久记录的 jsn 与每个写的态；已返回 fsync 的事务集合）。**按内容去重**：同一历史、同一臂、同一 Q1 条件下所有执行的崩溃状态并成一个集合，每个量数的是这个集合里满足条件的元素个数。另报「执行数」。
- **fsync 返回**（D16 已定项 7 + D13 已定项 2）：Ti 的 fsync 在时刻 t 已返回，当且仅当 t 之前 ① Ti 所在发布的最后一道屏障（C 之后那道）已完成，且 ② 对每个 j < i：Tj 已作废，或 Tj 的记录全部已发出且其后已有一道屏障或 FUA 完成。「已追加」取读法 R2「已发出且已被一道完成的屏障或 FUA 罩住」。另一读法 R1「已发出」在 Tj 的记录晚于 Ti 的最后一道屏障发出时，让 Ti 在下一道屏障之前就返回；本登记不建模 R1（第十一节未建模；待主 agent 认，派执行员之前要两读都跑就在第十二节补成一条臂）。理由：这条前置约束的用途是 D23 已定项 7「W 能当精确前缀」，要的是记录在盘上。第三个析取支「已确定实例切换或转只读」本登记的历史里不出现（第四段）。
- **作废**：H1「作废·窄」= 事务在取号之后、发出任何写之前作废（与 D23 已定项 7「一个事务在发出单元写之后失败即实例切换」相容）；H2「作废·宽」= 事务发出了 U 与它的第一条记录（只在 r = 2 时有）之后作废，D13 已定项 2 字面「已作废」不限时点而 D23 已定项 7 不许，单独报、不进合法历史的判定（留不留待主 agent 在派执行员之前认）。
- **恢复**：择根取持久的 F 里 txg 最大的那个（没有就取历史开始前的根 txg 0，它恒持久、覆盖到 jsn 0）；水位以上的记录、链首、前缀规则照第五节 5.3 的丙0（`crates/` 今天的 `replay_core` 逐判转写）；Q3 三个候选只换掉第五节写明的那几判。被择根的那一版**包含 txg 不大于它的每次发布**（单一树根、每次发布建在前一版上：`crates/singlefs-core/src/transaction.rs:4726`、`:4732`–`:4737` 从上一版现算）。
- **「不合法前缀」**（Q2）：严格连续段 = 从链首起、jsn 逐一连续、全部持久、在水位以上的最长一段记录（只用连续与水位两条，不用别的判）。N2a = 严格连续段里有两个或更多事务各有记录、而各自带提交标记的那条不在段里的崩溃状态数（问题单「号连续而内容属于两个半截事务」的字面）。模式 P = 严格连续段里某个事务 X 的提交记录不在段里，而段里有另一个事务 Y 的提交记录、且 Y 有一条记录的 jsn 大于 X 在段里的第一条（「残缺 A 之后有完整 B」，问题单 Q3 的前提）；N2b = 满足 P 的崩溃状态数。
- **「合法历史」**：H0（全部完成）与 H1（作废·窄）。H2 单独报。
- 分母：每个量都报分子与分母（同一格的崩溃状态总数）。

#### 已定项 4：崩溃点重放只枚举整写子集

**定案**：崩溃点重放要枚举的崩溃状态集合定义为：录下来的写请求流**按设备**切成段——一次写只被它自己那块盘上之后的屏障（或它那块盘上的 FUA 写）排在之后的写前面；当前段里每块有写的盘都被自己的屏障或 FUA 放行时这一段才关上，有一块盘还没放行，这道屏障（或 FUA）不关段、前后的写同段。一个崩溃状态是「前若干段全部持久，当前段每次写各取它的几态、任意组合，之后各段全部没持久」；枚举的单位是**一次整写**。带 FUA 的写只放行它自己那块盘：它与那块盘上前面没被屏障隔开的写同段，别的盘上的写不因它持久。一次写取两态（持久 / 没持久）；**原地覆写**（不是单元写、长于一个扇区、罩住的范围里原来有东西的写，系统配置槽写与覆盖旧记录的 journal 写属于这一类）多取第三态「新旧都读不出」，全量与快档都枚举；第三态的镜像罩那次写的整个范围，新旧不同的那一截前一半是新字节、后一半是旧字节（按字节撕，不按扇区）；其余写的撕裂态一律并进「这次写没持久」。「没持久」的位置上，镜像里放的是**崩溃前那个位置的旧字节**，不是零，而且这些镜像（第三态的在内）要真的生成出来喂给 checker 与记录核对器，不许只当计数。镜像双写（D2（RAID 条带策略） 已定项 6 的 w ≥ 2、D22（单元原子性怎么合成） 已定项 8 的 journal 镜像）按**设备**各算一次写，harness 的状态数按自己的写流另算闭式。**同一块盘上连着的屏障并成一道**：录制流里一道屏障与这块盘上一道屏障之间没有任何一次写（别的盘的屏障不算写）时，这一道不记（`crates/singlefs-harness/src/lib.rs` 的 `push`），独立模型照同一条规矩记；中间没有写，这一段不产生崩溃状态，合并与否不改变崩溃状态集合，只改变操作数与种类串。

**射程**：它定义的是模型层的枚举域。真实设备的 FLUSH / FUA 是否如宣称生效归 C6（块层语义假设写错），要在 QEMU 里用真设备验。按设备切段多出实际走不到的状态（一块盘没放行时，别的盘上已放行的写也留在段里取任意组合），不漏走得到的。撕裂分两类：原地覆写之外的写（单元写、不长于一个扇区的写、罩住的范围里原来没东西的写）撕裂态与「没持久」的差别只有 CRC32C 的碰撞概率（32 位，D19（块指针的结构与宽度预算） 已定项 2、D23（journal 的角色与格式） 已定项 11），**知情接受**，撕裂粒度不进模型，与 D20（承重面：单元的原子性与自包含）「有父指针的单元不依赖任何宽度」一致；原地覆写撕裂时那一处的旧内容也没了，「没持久」却留着完整的旧内容，两者不是同一个状态，所以单独枚举。层 0 的扇区取 512 字节；两条层 0 流上取第三态的只有系统配置槽写。已知边角：第三态的旧字节取「这次写之前的写全落了」那一版，同段更早、与它重叠的写没落的组合里旧的那一半多带那次写的字节（两条层 0 流上这种组合一次都没有）；根槽写长于一个扇区又罩住旧内容时第一版不支持第三态（harness 断言；层 0 的池都按 512 字节物理块建，走不到）。设备把一次写撕成恰好撞上校验和碰撞的形态不在模型内。D13（验证路线） 已定项 5 与它正交：一个定枚举域、一个定 crate 边界。

## 五、臂、阳性对照、真实基线

### 5.1 Q1 条件（不是臂，是分格的条件；Q1 开着，每格各报，不合并）

| 条件 | 对应问题单 Q1 的候选 | 写怎么排 |
|---|---|---|
| 串落 | 准备并行、落盘串行 | 每个事务自成一次发布（txg = 事务号，作废的事务不占发布）；发布 i+1 的第一个写在发布 i 的最后一道屏障完成之后才发出 |
| 同发 | 一次发布装多个事务 | k 个事务进同一次发布，共用一个 S、F、C 与三道屏障；U 按事务号次序，记录段的次序与 jsn 由 Q2 臂定 |
| 多飞·根序 | 多次发布同时在飞（子形态一） | 每个事务自成一次发布；各发布按各自的发布内次序，发布之间任意交错；只加一条：F 与 C 都按 txg 先后发出 |
| 多飞·根乱 | 多次发布同时在飞（子形态二） | 同上，不加 F、C 的次序约束 |

候选原文「多个根同时未落盘」没写根槽写之间有没有次序，两个子形态都登记、不预设。每条 Q2、Q3 臂在四个条件下都跑；丙2 在「同发」下只能靠「一次发布只施加一部分」保住 B，那几格单数进「部分施加」一行（与 D16 已定项 4 的冲突），不另立臂。

### 5.2 Q2 的臂（追加纪律）

| 臂 | 怎么做 | 做完会怎样（由「怎么做」推出） |
|---|---|---|
| 甲整段（单一追加者，读法 i） | 一个追加者逐个事务追加：Ti 的全部记录连着发出；发出 Ti 的第一条之前要求每个 j < i 的 Tj 记录全部已发出或已作废；jsn 在发出时按发出次序给 | jsn 次序等于事务号次序，每个事务的记录 jsn 连号 |
| 甲交错（单一追加者，读法 ii；留不留待主 agent 在派执行员之前认） | 一个追加者按记录就绪逐条追加：只要求 Ti 的第一条在每个 j < i 的 Tj 的第一条之后发出（或 Tj 已作废）；jsn 按发出次序给 | 各事务首条的 jsn 按事务号递增；不同事务的记录可以交错 |
| 乙整段（预留槽位乱序写） | 取号时 Ti 按事务号次序预留 r_i 个连号 jsn；各事务的记录在它自己的发布内次序允许时就发出，发出次序不受别的事务约束；作废事务的预留槽（H1 全部、H2 剩下的）由提交管道写占位记录（事务号 0、提交标记 1，D23 已定项 19 ① 的形态），占位写在下一个落盘的发布的记录段里——串落：下一个非作废事务的发布，没有下一个时另开一次空发布（只写 S、占位记录、F、C）；同发：同一次发布；多飞：作废事务之后紧接着的那个发布 | jsn 次序等于事务号次序，每个事务连号；没有永久的洞 |
| 对照丁（无纪律，阳性对照） | 每条记录发出时取下一个 jsn，事务之间的发出次序任意，不按号起头 | 在两个事务都 r = 2 时必然能造出 N2a > 0 的状态（A1、B1 两条持久、各自的提交记录不持久） |

两种读法的出处：问题单 Q2 甲的原文「事务号小的没就绪时后面的等」没说「就绪」是整个事务还是一条记录；D13 已定项 2「记录按事务号顺序追加」同样两读。乙的原文「取号时预留」给了时点，只登记整段一种；条数取号时未知时要按上界预留、多余的写占位，那一形态不建模（第十一节「未建模」）。甲交错与对照丁的崩溃状态在「同发」下只差执行数（首条按号与否），判据不变。

**每条 Q2 臂的阳性对照（拿掉它自己的纪律，走它自己那条代码路径）**：甲整段去掉「前面事务记录全部已发出」；甲交错去掉「首条按号」；乙整段把预留改成发出时逐条取号。三条都在「同发、k = 2、r = (2, 2)、H0」上跑，各自必须 N2a > 0 且 N2b > 0；对照丁本身也跑同一格、同样必须 > 0。

### 5.3 Q3 的臂（恢复取什么）

公共的前三步：① 择根 = 持久的 F 里 txg 最大的（没有就取 txg 0 的起始根）；② 候选记录 = 持久、txg 大于所选根的记录（单实例，`lib.rs:232` 的实例比较恒相等）；③ 链首 = 所选根那次发布里带「本次发布末条」标志的那条记录的 jsn + 1；所选根是起始根、或那条记录不持久时没有锚点，走 `lib.rs:445`（链首要 txg = 根 + 1 且本次发布内序号为 1）。

### 5.4 历史

- H0：k ∈ {2, 3}，r ∈ {1, 2}^k（k = 2 四种、k = 3 八种），没有作废。
- H1（作废·窄）：H0 的每个 (k, r) × 作废事务 v ∈ {1..k}；Tv 取号之后、发出任何写之前作废（乙整段已预留它的槽）。
- H2（作废·宽，单独报，不进合法历史的判定）：H0 的每个 (k, r) × 每个 r_v = 2 的 v；Tv 发出 U 与它的第一条记录之后作废。甲整段下一个事务的记录连着发出，中间不能作废，H2 对它不适用（写「不适用」，不算 0）。
- 作废对恢复不可见（作废是提交管道的内存状态，D13 已定项 2 括注），只改变 fsync 返回条件 ② 与哪些写会发出。

### 5.5 真实基线

串落 × 甲整段 × 丙0（H0、H1）：一次发布一个事务的今天。`crates/` 今天没有作废这条路，H1 在甲整段下就是那个事务不出现。今天一次发布里装多个事务的形态是同发 × 甲整段 × 丙0。真实基线的各违例量必须全为 0（第七节 A1），不为 0 走第十节 F1。

### 5.6 实现量、分段与排序

### 5.7 等待模型（第三段用；离散事件，抽象单位，不是本机计时）

- 只跑 H0、每个事务 r 相同（r ∈ {1, 2}），k ∈ {1, 2, 4, 8, 16, 32, 64}（C488 与 D25 已定项 7 的并发下限 16 落在区间里面）；k 个事务都在时刻 0 调 fsync。
- 准备时间两种剖面：等速（每个事务的计划在时刻 0 就绪）；慢头（T1 在时刻 Δ 就绪，其余在 0）。
- 设备：一个先进先出的服务台，写耗 w、屏障耗 b、FUA 耗 b；一个操作在「它发出」与「前一个操作完成」两者较晚时开始。连着的屏障（中间没有写）不占时间。
- 同一次发布内：下一个操作在上一个操作**完成**之后才发出（同步）；不同发布的操作按发出时刻进同一个服务台，同刻按事务号。
- 甲整段、甲交错：一个追加者（CPU 单服务台），每条记录耗 h；一条记录在它所属发布的 B1 完成、且满足臂的次序约束之后进追加者，追加者做完那一刻发出这条记录写。乙整段：时刻 0 起按事务号逐个预留，每个耗 g（CPU 单服务台）；一条记录在它所属发布的 B1 完成且本事务预留完成之后由事务自己发出。
- 串落：Ti 的第一个操作在 Ti−1 的 B3 完成之后且 Ti 就绪之后发出。同发：U 按事务就绪发出，S 在全部 U 之后，其后照发布内次序。多飞：各发布各自推进；根序子形态另要求 F_i 在 F_{i−1} 完成之后、C_i 在 C_{i−1} 完成之后发出。
- Ti 的 fsync 返回时刻 = 第一节 1.2 的两个条件同时成立的最早时刻。
- 两个代价取样点（拍的，方向相反）：P1 设备主导 w = 0.05、b = 1、h = g = 0.005、Δ = 5；P2 CPU 主导 w = 0.05、b = 1、h = g = 0.5、Δ = 5。
- 报：每个 (Q1 条件, Q2 臂, 剖面, 取样点, k)：W_max = 最晚返回的那个事务的返回时刻、W_mean；最晚返回那个事务关键路径上的三个分量——等过的屏障与 FUA 数 n_bar、设备写数 n_dev、CPU 步数 n_cpu（h 或 g 的步数）。关键路径按「每个操作的开始时刻由哪个前驱定」逐个往回追。

from functools import lru_cache

def publish_ops(p, txs, r, sysconf_states=3):
    ops = [('w', f'U{t}', 2) for t in txs] + [('w', f'S{p}', 2), ('bar', p)]
    for t in txs:
        ops += [('w', f'R{t}.{i}', 2) for i in range(1, r[t] + 1)]
    ops += [('bar', p), ('fua', f'F{p}', p), ('w', f'C{p}', sysconf_states), ('bar', ('end', p))]
    return ops

def states_of_execution(ops, returns_at):
    """returns_at(closer_index, ops_prefix) -> set of tx whose fsync returned by then"""
    closers = [i for i, op in enumerate(ops) if op[0] in ('bar', 'fua')]
    result = set()
    # segment j+1 = writes after closer j up to closer j+1 (FUA write included in its own segment)
    bounds = [-1] + closers
    for j in range(len(bounds)):
        done_upto = bounds[j]  # ops with index <= done_upto are complete
        durable = []
        for i in range(done_upto + 1):
            op = ops[i]
            if op[0] == 'w': durable.append((op[1], 'new'))
            if op[0] == 'fua': durable.append((op[1], 'new'))
        nxt = bounds[j + 1] if j + 1 < len(bounds) else len(ops) - 1
        seg = []
        for i in range(done_upto + 1, nxt + 1):
            op = ops[i]
            if op[0] == 'w': seg.append((op[1], op[2]))
            if op[0] == 'fua': seg.append((op[1], 2))
        F = frozenset(returns_at(done_upto, ops))
        choices = []
        for name, n in seg:
            choices.append([None, (name, 'new')] + ([(name, 'torn')] if n == 3 else []))
        for combo in itertools.product(*choices):
            D = frozenset(durable + [c for c in combo if c is not None])
            result.add((D, F))
    return result

def serial_returns(publish_of_tx):
    def f(done_upto, ops):
        out = set()
        for i in range(done_upto + 1):
            op = ops[i]
            if op[0] == 'bar' and isinstance(op[1], tuple):
                out |= {t for t, p in publish_of_tx.items() if p == op[1][1]}
        return out
    return f

def q1a(k, r):
    ops = []
    for t in range(1, k + 1):
        ops += publish_ops(t, [t], r)
    return len(states_of_execution(ops, serial_returns({t: t for t in range(1, k + 1)})))

def q1b(k, r):
    ops = publish_ops(1, list(range(1, k + 1)), r)
    return len(states_of_execution(ops, serial_returns({t: 1 for t in range(1, k + 1)})))

def closed_q1a(k, r): return 1 + sum(8 + 2 ** r[t] for t in range(1, k + 1))
def closed_q1b(k, r): return 2 ** (k + 1) + 2 ** sum(r[t] for t in range(1, k + 1)) + 3

def interleavings(streams, first_order):
    """记录流的交错数（每个事务自己的记录保序）；first_order=True 时各事务的第一条按事务号先后。"""
    total = 0
    n = sum(len(s) for s in streams)
    labels = []
    for idx, s in enumerate(streams): labels += [idx] * len(s)
    seen = set()
    for perm in set(itertools.permutations(labels)):
        if first_order:
            firsts = [perm.index(i) for i in range(len(streams))]
            if firsts != sorted(firsts): continue
        total += 1
    return total

if __name__ == '__main__':
    for k, rv in [(2, (1, 1)), (2, (2, 2)), (2, (1, 2)), (3, (1, 1, 1)), (3, (2, 2, 2))]:
        r = {t: rv[t - 1] for t in range(1, k + 1)}
        a, ca = q1a(k, r), closed_q1a(k, r)
        b, cb = q1b(k, r), closed_q1b(k, r)
        print(f'k={k} r={rv}  Q1-a brute={a} closed={ca}  Q1-b brute={b} closed={cb}')
    for rv in [(2, 1), (1, 2), (2, 2), (2, 2, 2), (1, 1, 1), (2, 1, 1)]:
        streams = [list(range(x)) for x in rv]
        print(f'records r={rv}: interleave(any)={interleavings(streams, False)} interleave(first-in-order)={interleavings(streams, True)} multinomial={math.factorial(sum(rv)) // math.prod(math.factorial(x) for x in rv)}')

```python
#!/usr/bin/env python3
"""E169 登记用的分母锚点（Q1-c，k=2）：只数执行数与按内容去重的崩溃状态数，不判违例。"""
import sys
sys.path.insert(0, __import__('os').path.dirname(__import__('os').path.abspath(__file__)))
from anchors import publish_ops
import itertools

def merges(seqs):
    # all interleavings preserving each sequence's order
    n = [len(s) for s in seqs]
    def rec(pos):
        if all(pos[i] == n[i] for i in range(len(seqs))):
            yield []
            return
        for i in range(len(seqs)):
            if pos[i] < n[i]:
                p2 = list(pos); p2[i] += 1
                for rest in rec(tuple(p2)):
                    yield [(i, seqs[i][pos[i]])] + rest
    yield from rec(tuple(0 for _ in seqs))

def allowed(ex, arm, roots):
    def idx(pred):
        return [j for j, (i, op) in enumerate(ex) if pred(i, op)]
    rec = lambda t: idx(lambda i, op: i == t and op[0] == 'w' and op[1].startswith('R'))
    r0, r1 = rec(0), rec(1)
    if arm == 'jia_whole' and min(r1) < max(r0): return False
    if arm == 'jia_interleave' and min(r1) < min(r0): return False
    if roots == 'c1':
        f = lambda t, pre: idx(lambda i, op: i == t and op[1] == f'{pre}{t+1}')[0]
        if f(1, 'F') < f(0, 'F') or f(1, 'C') < f(0, 'C'): return False
    return True

def label(ex, arm, r):
    out = []
    if arm in ('jia_whole', 'yi_whole'):
        jsn = {}; n = 0
        for t in (1, 2):
            for i in range(1, r[t] + 1):
                n += 1; jsn[f'R{t}.{i}'] = n
    else:
        jsn = {}; n = 0
        for (_, op) in ex:
            if op[0] == 'w' and op[1].startswith('R'):
                n += 1; jsn[op[1]] = n
    for (i, op) in ex:
        if op[0] == 'w' and op[1].startswith('R'):
            out.append(('w', f'{op[1]}@{jsn[op[1]]}', op[2]))
        elif op[0] == 'bar':
            out.append(('bar', (i, op[1])))
        else:
            out.append(op)
    return out

def returns(ops):
    # T1 returns when its end barrier done; T2 when its end barrier done and all T1 records issued before a completed closer
    def f(done_upto, _ops):
        out = set()
        closer_done = [j for j in range(done_upto + 1) if ops[j][0] in ('bar', 'fua')]
        end1 = any(ops[j][0] == 'bar' and ops[j][1] == (0, ('end', 1)) for j in closer_done)
        end2 = any(ops[j][0] == 'bar' and ops[j][1] == (1, ('end', 2)) for j in closer_done)
        if end1: out.add(1)
        last_closer = max(closer_done) if closer_done else -1
        t1_recs = [j for j, op in enumerate(ops) if op[0] == 'w' and op[1].startswith('R1.')]
        if end2 and all(j < last_closer for j in t1_recs): out.add(2)
        return out
    return f

def states(ops):
    from anchors import states_of_execution
    return states_of_execution(ops, returns(ops))

for rv in [(1, 1), (2, 2)]:
    r = {1: rv[0], 2: rv[1]}
    seqs = [publish_ops(1, [1], r), publish_ops(2, [2], r)]
    all_ex = list(merges(seqs))
    for roots in ('c1', 'c2'):
        for arm in ('jia_whole', 'jia_interleave', 'yi_whole', 'ding'):
            exs = [ex for ex in all_ex if allowed(ex, arm, roots)]
            S = set()
            for ex in exs:
                S |= states(label(ex, arm, r))
            print(f'r={rv} {roots} {arm}: executions={len(exs)} distinct_crash_states={len(S)}', flush=True)
    print(f'r={rv} total merges={len(all_ex)}')
```

    def f(done_upto, _):
        out=set()
        cd=[j for j in range(done_upto+1) if ops[j][0] in ('bar','fua')]
        if any(ops[j][0]=='bar' and ops[j][1]==(0,('end',1)) for j in cd): out.add(1)
        if any(ops[j][0]=='bar' and ops[j][1]==(1,('end',2)) for j in cd): out.add(2)

    return f
