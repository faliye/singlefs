# C245（超级块槽的写频率，两条条款说反话） 第一轮：正推腿（Sonnet）

你的立场是**正推**：从条款与机制出发，按判据 T1–T5 逐条臂（甲、乙、丙）推到结论，给出你认为站得住的那一条的正面论证；同时**逐条核前提表的转述与附录原文对不对得上**——对不上就是失败条款触发，要写出来。

要特别回答：
1. T2 三格：按今天的条文，恢复的哪一步读 tail、读了之后拿它干什么；把 tail 改成 0 / 陈旧值 / 超前值，每一步的输出变不变。逐步写，不要只下结论。
2. 前提十一说「计数器从前缀末 + 1 接着写」：前缀末在乙、丙两条臂下能不能不靠 tail 求出，包括环回绕、实例切换、回退行 W、一条记录中间坏掉这四种形状。
3. 前提十四 I-8.5 与前提八对不上：I-8.5 今天该怎么读，三条臂各自要它变成什么。
4. 前提十二是主 agent 的观测：去附录里的超级块字段表核一遍，每次发布到底哪些字段会变。有别的字段每次必变，就写出来，因为那会让「超级块每次发布必写」不再只是为了 tail。
5. 每条臂一条会红的检查与判别力自证（T5）。

## 怎么交付（照做，不照做这一轮作废）

- 读 `research/prompts/_c245-r1-background.md`（正文 + 小节清单 + kb 原文附录）。附录不够时可以读 kb 原文，但**引 kb 条款一律写 kb 文件名加那份文件自己的行号**，行号去 kb 文件里现查，不从背景材料里数。
- 报告写进 `research/prompts/c245-r1-sonnet-output.md`：**分段写**，每一次工具调用写进文件的内容不超过 150 行，第一段排他新建（文件已存在就停下报告），之后追加；最后的回复只写一两句话和文件路径。
- 不许改仓里任何别的文件，不许读别的腿这一轮的产出（`research/prompts/c245-r1-*-output.md`）。
- 转述 kb 条款要整行抄，不许摘句。每条结论写「什么现象会推翻它」。
