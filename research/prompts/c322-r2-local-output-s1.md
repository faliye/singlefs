6. A2 costs one extra barrier per acquisition; B2 costs two. A2 is recommended because one barrier suffices to ensure both superblocks are durable before units. The single observation that would change this is if device-specific write ordering requires per-device barriers to guarantee durability (e.g., hardware quirks where a single barrier does not ensure both superblocks are durable), but this is unlikely with standard flush barriers.
