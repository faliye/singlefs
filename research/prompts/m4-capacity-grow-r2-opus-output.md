## 第 1 格：乙、丙、丁的漏放行与误拒

### H8 判据「误拒」的字面让三条规则一起中（打中判据本身）

判据原文：「或误拒（没有落点越界而可写永久拒）的历史」（`research/prompts/_m4-capacity-grow-r2-body.md:15`）。

历史（推的，模型里落在「误拒-各槽表全同」）：盘 1 长到 2X → 可写挂载，取号第二轮盘 1 那一写落了、盘 0 那一写撕裂，断电在第二轮屏障返回之前 → 盘 0 {T1, 坏}、盘 1 {T1, T1}，没有一个单元越过 X → 用户看挂载失败，把盘 1 缩回 X → 每个自证槽都是 T1，乙取大、丙无标记取大、丁取小，三条都得 T1 > X，可写拒；表只增，除了再长回去没有出路。

四问：① 不分辨臂：盘上已经没有 T0，任何读者都只能取 T1。② 判别子观测不到：屏障返回之前与之后，盘面逐字节相同；这次挂载对用户是失败的，对盘是记成了。③ 满足的是判据「没有落点越界而可写永久拒」的整句字面。④ 每条规则都修不了。同一类还有第一轮 M3「M3 记下、没用、缩回：可写永久拒（定案的代价，不是漏）」（`research/prompts/m4-capacity-grow-r1-opus-output.md:180`）与丁放弃写回自己撕裂（H5）。

推论：任何写序在提交之前都要有最后一写把最后一份旧表的证据盖掉（或撕掉），那一写落了、屏障还没返回时断电，盘面就是「记成了」。所以判据要拆：表全同类是定案「变大 ⇒ 放行并记」「| 设备容量 | 变小 ⇒ **拒绝**；变大 ⇒ 放行并记 |」（`.claude/kb/decisions/12-目标介质.md:74`）自带的代价，另记；判臂只看表不全同类。下面各节照这样拆。

### H1 乙（逐项取大）

漏放行：没打中（推的，模型读数待跑）。逐项取大取到盘上最大的那张；越过 X 的单元只在四槽都是 T1 之后才写：取号「每轮之后一道屏障，第二轮那道屏障完成才把新号交出去」（`crates/singlefs-core/src/transaction.rs:1095`）。之后要让 T1 一槽不剩，单故障做不到（每盘只坏一槽），换回旧镜像只换一块盘。试过的形状：单次与两次断电的全部组合、换回镜像放进 X 与 2X 的盘、单故障叠在每个动作上、取号只一轮。

误拒（表不全同类）：J5（已知）。另一条不要断电的进路：取号第二轮报 I/O 错 → 回卷每块盘只覆写较旧那一槽，「另一槽留着新号（下一次取号跳过它）」（`crates/singlefs-core/src/transaction.rs:772`），那一槽是第一轮写的 T1 → 乙取大得 T1 → 用户缩回 → 永久拒。模型里是「误拒-表不全同」带「回卷」标签那一行。四问：① 分辨臂（丁取小、丙看标记都不拒）。② 系统看得到 T0 与 T1 两张，规则只取大的。③ 判据整句。④ 丁、丙修；乙自己没有修法（不加标记就分不出「写到一半」）。

新：J5 那些盘面上 G5 永久红（H9）。生效表 T1、所选那一版统计按 T0，可写永久拒，没有一次发布能把统计改过来；checker 若照等式判，这些盘面一直红。正推的收法（取号未发布态改判不大于）能把它判绿，但前提见 H9。

### H2 丙（意图三轮）：五步构造形复现，四步活快照形打穿第一轮的零轮收紧

定义照第一轮（取号之后另三轮：较旧槽写 T0 + 标记、另一槽写 T1、带标记那一槽写 T1；有带标记的自证槽取带标记那几槽的表，否则取大）。

五步形（推的，模型「丙-意图三轮-取号不带标记」与「丙-意图三轮-取号带标记」的「漏放行-只读不点名」带「换回留的镜像」标签）：

1. 盘 1 长到 2X；可写挂载，意图第二轮盘 0 那一写落了、盘 1 那一写没落，断电。盘 0 {T1, T0 + 标记}，盘 1 {T0 + 标记, T0}。
2. 用户给盘 1 留镜像。
3. 再可写挂载（2X），三轮走完、两次发布，txg 1 的根落盘 1、txg 2 的根落盘 0，落点到 2X。
4. 把第 2 步的镜像放回 X 大的盘 1。
5. 只读挂载：盘 1 那一槽带标记 → 取 T0 → 盘 1 探测 X 不小于 T0 → 不点名；所选那一版（盘 0 上 txg 2）的落点越过盘 1 盘尾。

四步活快照形（新，模型同一行带「活快照」标签）：第 1 步不断电，用户在这次挂载的意图第二轮盘 1 那一写之前对盘 1 做活快照（LVM 快照对一块盘就是这一刻的盘面），挂载照常做完、发布到 2X；之后同第 4、5 步。这里盘 0 上不带标记的 T1 槽与盘 1 上的标记是同一次挂载写的，实例代号相等。我第一轮的零轮收紧「标记带写它那一次的实例代号，有不带标记的 T1 槽实例代号严格大于标记的实例代号时取大」（`research/prompts/m4-capacity-grow-r1-opus-output.md:105`）要求严格大于，在这一形上不翻，照样不点名（模型「丙-意图三轮-取号带标记-实例代号作废」那一臂，推的）。

四问：① 分辨臂（乙、丁都点名：盘 0 两槽 T1）。② 系统看得到盘 0 的 T1 槽与它的 (实例代号, tail)；发布之后的轮换把 tail 推过标记那一写的 tail。③ 「只读挂载做成且不点名」那一分句。④ 改法：标记按位置作废——有不带标记、表比标记那张大、(实例代号, tail) 严格大于标记那一写的自证槽，就不认标记（零轮，只在我的模型上，待主 agent 跑；同一次挂载里意图三轮的写 tail 都相同，不误翻）。另一条改法是 H10 的「只读另点名落后盘」：这两形里盘 1 都落后且缺单元。

### H3 丙：照第一轮写法，下一次挂载的取号把标记抹掉（误拒，表不全同类）

第一轮没写丙在挂起状态下取号写什么。照「写者带这次挂载生效的表」（K1）的字面，取号写生效表 T0、不带标记。历史（推的，模型「丙-意图三轮-取号不带标记」的「误拒-表不全同」）：

1. 意图第二轮盘 0 落了、盘 1 没落，断电：盘 0 {T1, T0 + 标记}，盘 1 {T0 + 标记, T0}。
2. 用户缩回 X。可写挂载：标记在场取 T0，放行；要记的表就是 T0，不跑意图轮。
3. 取号第一轮两盘都落：盘 0 较旧那一槽（带标记）换成 T0 无标记，盘 1 同；第二轮盘 1 落了、盘 0 没落，断电：盘 0 {T0, T1}，盘 1 {T0, T0}——标记一槽不剩、T1 还在。
4. 下一次挂载：无标记取大得 T1，盘 1 探测 X → 可写永久拒；盘上从没有越过 X 的单元。

四问：① 分辨臂（丁取小不拒）。② 系统在第 2 步看得到标记。③ 判据整句。④ 改法：挂起时取号也带标记（模型「取号带标记」那三臂）。带了之后表不全同类的误拒推的是 0；剩下的是标记那一槽被撕（意图第三轮或放弃写回时盘 1 只剩带标记那一槽、它被撕）落进表全同类，与 H5 同形。

### 丁（生效取最小、点名按最大、挂起的变大写回旧表放弃）

定义照正文：「全部槽未写齐新表的变大可以写回旧表放弃」（`research/prompts/_m4-capacity-grow-r2-body.md:11`）；放弃的写法照第一轮正推，要记的表不逐项不小于盘上最大表时写生效表，「放弃挂起的变大，点名那块盘」（`research/prompts/m4-capacity-grow-r1-sonnet-output.md:39`）。

漏放行：没打中（推的）。理由两条：越过 X 的单元写在四槽都是 T1 之后，此后 T0 只有两条路回到盘上——换回旧镜像（那块盘落后且缺单元，可写由落后支拒，只读由「点名按最大」点名，盘 0 两槽 T1 至少剩一槽），或某个写者写了 T0（下面 H6、H7 与第一轮 K1）。单故障下盘 0 两槽 T1 只坏一槽，最大那张还在。模型「丁-取小点名按大放弃」那一臂的两种漏放行推的是 0，单故障那一档同。

表不全同类误拒：没打中（推的）。表不全同时生效表是最小那张 T0，只有探测小于 T0（缩到旧容量之下）才拒，那是「变小 ⇒ 拒绝」本身。正文挂着的那一格（旧镜像盘面上可写挂载按旧容量接着跑）走不到，理由在 H10。

三条写者约束，各自不成立时各中一格：

#### H6 取号只剩一轮（C974 删第二轮）：盘没缩也永久拒

C974 那一行：「今天没有一形量到它改变结局」（`.claude/kb/checks-owed.md:578`），去留没定。历史（推的，模型「丁-取小点名按大放弃-取号只一轮」的「误拒-表不全同」）：盘 1 长到 2X → 可写挂载，取号一轮把两盘较旧那一槽写成 T1（每盘 {T1, T0}），屏障 → 写行那次发布把单元写到 2X、根落盘 → 断电在轮换之前 → 下一次挂载：取小得 T0，所选那一版落点 2X > T0 那一项 → 记录越界拒可写；盘 1 探测 2X，没有落点越过盘尾；拒在任何写之前，永久。用户什么都没动。

四问：① 分辨臂：乙取大不拒（第一轮 K3 已说乙不依赖第二轮）；甲（成链取最小）与丁同中。② 系统看得到两盘较新那一槽的 T1 与根里的落点。③ 判据整句。④ 改法：取号保留两轮，或 C974 删第二轮时「要记的表不等于生效表」那一次自补一轮（第一轮正推已这样写，零轮）；丁与甲因此把 C974 的去留变成硬约束，乙不变。

#### H7 回卷抄本盘最新槽：一次 I/O 错就把变大记成

第一轮正推给回卷的写法是「抄这块盘上自证槽里世代号最大那一槽的表」（`research/prompts/m4-capacity-grow-r1-sonnet-output.md:83`）。历史（推的，模型「丁-取小点名按大放弃-回卷抄本盘最新槽」的「误拒-各槽表全同」带「回卷」标签）：取号第一轮两盘落成 T1、屏障；第二轮盘 0 那一写报 I/O 错、盘 1 那一写没落 → 回卷：每块盘覆写较旧那一槽（T0），抄本盘最新槽 = T1 → 四槽全 T1，挂载报错 → 用户缩回 X → 永久拒。没有断电，也没有单元越过 X。

四问：① 落在表全同类，按 H8 不分辨臂；但这个盘面是回卷写法造出来的：回卷带读时生效表 T0 时，盘面是 {T1(新号), T0(旧号)} 两盘各一，丁取小不拒。② 回卷那一刻系统手里有读时的生效表。③ 判据整句。④ 改法：回卷带读时生效表（零轮）；这一条同时是 G5 收法成立的前提（H9）。

#### 第一轮 K1 在丁上的样子（自证用）

轮换抄读时生效表（判决改句之前「写者抄择到的表」的读法）：第一次发布之后每盘较旧那一槽变回 T0，丁取小得 T0 → 记录越界拒、盘没缩，表不全同类误拒。模型拿这一臂当「判表不全同类误拒的那条路子会红」的自证。

## 第 2 格：丁的放弃写回

### 与「记录只升不降」不冲突

丁的生效表是盘上各表的最小那张。放弃写回只在盘上表不全同时发生（全同就没有可放弃的），写的就是那张最小的；所以写回前后生效表不变，最大那张降回去。「只升不降」若读成「生效表只升不降」，不冲突；读成「任何一槽的表只升不降」，冲突，但那一读法下没有任何读者按单槽的表做过事：越过 X 的分配要等四槽都是 T1，放弃发生时一个越过 X 的单元都没有（推的，模型里体现为丁那一臂两种漏放行都是 0）。条款落笔时那一句要写成生效表。点名按最大：放弃之前点名、放弃之后不点名，这是对的。

### H5 放弃写回自己断电：撕掉最后一份 T0，没记成的变大被记成

历史（推的，模型「丁-取小点名按大放弃」的「误拒-各槽表全同」带「放弃挂起的变大」标签）：

1. 盘 1 长到 2X；可写挂载，取号第一轮两盘落 T1、屏障；第二轮盘 1 落了、盘 0 没落，断电。盘 0 {T1(较新), T0(较旧)}，盘 1 {T1, T1}。全盘只剩盘 0 较旧那一槽是 T0。
2. 用户缩回 X。可写挂载：丁取小得 T0，放行；要记的表不大于盘上最大表，放弃，取号写 T0。
3. 放弃的取号第一轮：盘 0 覆写较旧那一槽（正是那份 T0）——撕裂；盘 1 覆写较旧那一槽（T1）——没落；断电。盘 0 {T1, 坏}，盘 1 {T1, T1}。
4. 下一次挂载：盘上全是 T1，丁取小也得 T1 → 可写永久拒。

四问：① 盘面落在表全同类，不分辨臂；但历史分辨：乙在第 2 步就拒（J5），丁原本能放弃，是它自己的写序把唯一的 T0 先拿去覆写。② 系统在第 2 步看得到每块盘较旧那一槽带什么表。③ 判据整句。④ 改法（零轮）：放弃那两轮拆成逐盘写、每写之后一道屏障，先写「覆写处不带旧表」的盘（这一例先写盘 1，盘 1 有了一份 T0 之后再动盘 0 那份）。不变式：任一刻盘上至少有一份已持久的 T0。代价：放弃那一次多一道屏障。模型「丁-取小点名按大放弃-放弃先写没旧表的盘」那一臂带「放弃挂起的变大」标签的表全同类误拒推的是 0。

放弃写回的其余断电态（推的）：放弃只写 T0，丁的生效表（最小那张）不会因它升；放弃只发生在没有越过 X 的单元时，所以它的断电态里漏放行没有对象。中途用户又把盘放大，下一次挂载按「要记的表逐项不小于盘上最大表」重新记，盘上最多同时 T0、T1、T3 三张，成链。

## 第 3 格：G5

### H9 坐实会红；今天就有；三条规则窗口不同；正推的收法缺两样

今天的 checker 判 I-5.2 拿的是探测容量：「let capacity = reader.device_bytes(*device)」（`crates/singlefs-checker/src/walk.rs:22288`），记账的空闲取自分配器空闲图「PerDeviceAccountingRow::FreeBytes => device_map.free_slots() * SLOT_BYTES,」（`crates/singlefs-core/src/transaction.rs:16342`），分配器按探测字节数建：「DeviceFreeMap::with_unit_area_start(*identity, device.size_in_bytes(), unit_area_start)」（`crates/singlefs-core/src/mount.rs:3242`）。所以今天盘一变大、第一次可写挂载发布之前的每个盘面（不只是崩溃态）checker 都红；第一轮判决之前那一题已定「I-3.16、I-5.2 的盘末改取记录值」（`research/prompts/m4-capacity-r3-main-verification.md:33`），改了之后窗口变成「生效表变新」到「第一条按新表算统计的根落盘」。读码推的，没跑。

三条规则窗口起点不同（推的，模型三个 G5 计数）：

| 规则 | 窗口从哪一写起 | 永久红（拒可写、没有发布能改统计） |
|---|---|---|
| 乙 | 取号第一轮第一个 T1 槽落盘 | J5 全部盘面、H1 的回卷形 |
| 丙 | 意图第三轮把最后一个带标记的槽盖掉或撕掉 | 表全同类（H8）那些 |
| 丁 | 四槽都成 T1（第二轮两写都落，或一落一撕） | 表全同类那些 |

正推的收法：「盘上某个自证槽的实例代号大于最新有效根的实例代号」（`research/prompts/m4-capacity-grow-r1-sonnet-output.md:168`）时改判「统计容量不大于生效表」。打它两处：

1. 回卷写的是旧实例代号。若回卷带的表是本盘最新槽的 T1（正推第一轮给回卷的写法，H7），取号第二轮报错回卷之后每盘 {T1 旧号, T1 新号}；再加每盘坏一槽，承诺内「容错承诺是单故障：每盘一槽系统配置坏在承诺里」（`.claude/kb/decisions/22-单元原子性怎么合成.md:185`），坏的恰是新号那一槽 → 盘上自证槽全是旧号、表全是 T1，最新根是旧号、统计按 T0 → 判据不认取号未发布态，照等式判红。模型「丁-取小点名按大放弃-回卷抄本盘最新槽」在单故障那一档的「G5-取号未发布态改判之后仍红」推的大于 0。回卷带读时生效表（H7 的改法）时这一形回到 T0，不红。
2. 只改了 I-5.2、I-3.20 的和。I-3.16 判碎片度与全空段要按盘末重算最后那一段空闲，见「盘末取探测容量那一格的判别力」（`crates/singlefs-checker/invariants/05-空间记账.md:23`），窗口里盘末按生效表就多出 X 到 2X 那一段，同样红；收法要连 I-3.16 的盘末一起改成「取统计自己的容量」（空闲 + 已分配 + 不可回收，即 I-3.20 (a) 那一和），并另判它不大于生效表。代价：窗口里 I-3.20 (a) 与 I-5.2 的独立性没了（容量取自统计自己），只剩「不大于生效表」一道；要保住，得让根自带容量（记账加一行，格式改动），不在第一版。

四问：① 不分辨臂（三条都有窗口），窗口长短与永久红那一格分辨（乙最差）。② checker 在窗口里看得到生效表与统计，看不到旧表（丁表全同之后、乙也一样），所以只能判不等式。③ 正文第 3 问「I-5.2、I-3.16、I-3.20 在这一段崩溃态上红不红」整句。④ 收法三件合起来：取号未发布态改判不大于（正推）+ I-3.16 盘末取统计自己的容量（新）+ 回卷带读时生效表（新）；全部零轮，只在推演上过。

## 第 4 格：判决坐实 J3 的那一步

### H10 够证 J3 在甲上发生，不够拿 J3 判规则；可写落后支先拒

判决那一步：「点名的是两槽都不可择的盘，没有点名落后盘的栏」（`research/prompts/m4-capacity-grow-r1-main-verification.md:16`）。现读核对：只读挂载报告那一栏「pub devices_without_a_mountable_system_configuration_slot: Vec<DeviceIdentity>,」（`crates/singlefs-core/src/mounted_read.rs:637`）；读到只坏一份另有计数，「只读挂载只计数、不搬」（`crates/singlefs-core/src/mounted_read.rs:91`），是计数不是点名，而且只在读到盘 1 那份时才加。所以「甲在 J3 上只读不点名」站得住。

不够的地方：

1. 只读不点名的是落后盘这一整类，不只越过盘尾那一支。把同一份旧镜像放进 2X 的盘（不缩），盘 1 一样缺所选那一版的单元，只读一样从盘 0 那份读、一样不点名；这时探测 2X 不小于任何一张表，乙、丙、丁的容量点名都不响。也就是说 J3 只在「换回镜像同时把盘缩回」这一支分辨规则，母类对三条规则一样漏（不算本题判据里的漏放行，因为没有越过盘尾）。可写那一侧早有这一判：「在取号之前返回，一个写都没发、盘上逐字节不变。只读挂载照旧」（`crates/singlefs-core/src/mount.rs:275`）。
2. 修 J3 有一条判决没看的路：只读挂载跑一遍同一个落后判（只读盘，可写挂载的落后支本来就只读），把落后且缺单元的盘点名。J3 两形、丙的 H2 两形里换回的盘都落后且缺单元，这一条都点得到（推的，模型「甲-成链取最小点名按生效表-只读另点名落后盘」那一臂的只读不点名推的是 0）。有了它，「点名按最大」就不是修 J3 的唯一出路，甲也站得回来；判甲出局的依据要改写成「甲 + 只读点落后盘」与「丁」二选一。
3. 可写落后支对 J3 盘面：盘 1 最新自证槽的 (实例代号, tail) 落后于所选那一版，所选那一版自己那次发布写下的单元盘 1 上没有，都在 (tail, 那一版] 窗口里，记缺；窗口取不到时「时全部算缺」（`crates/singlefs-core/src/mount.rs:7075`）→ `WritableMountRefusedByDevicesWithoutTheSelectedVersion`，在任何写之前。乙、丙、丁、甲一样。所以正文挂着的「旧镜像盘面上可写挂载按旧容量接着跑」（`research/prompts/_m4-capacity-grow-r2-body.md:11`）走不到：要让 T0 回到盘上、又不落后，只剩写者写 T0（H6、H7、K1），那几条另有改法。

四问：① J3 分辨甲与乙丁，母类不分辨。② 只读挂载那一刻看得到盘 1 的系统配置落后、看得到所选那一版的单元清单；今天它不读、不判。③ J3 满足的是「只读挂载做成且不点名」；母类不满足「越过盘尾」，不在本题判据里。④ 「点名按最大」修 J3、不修母类；「只读另点名落后盘」两样都修（零轮）。

### 补：丙在单故障档还剩一形，另一条作废条件

「标记按位置作废」在单故障那一档推的还漏一形（模型「丙-意图三轮-取号带标记-位置作废」单故障档「漏放行-只读不点名」带「换回留的镜像+活快照+坏」标签）：一次挂载里意图第二轮之前给盘 1 留活快照；挂载走完意图三轮、发 txg 1（根落盘 1）与 txg 2（根落盘 0，落点到 2X），断电在 txg 2 的轮换之前，盘 0 {txg 1 轮换那一槽, 意图第三轮那一槽}；之后把镜像放回 X 大的盘 1，同时盘 0 较新那一槽坏（承诺内）。盘 0 只剩意图第三轮那一槽，它的位置等于标记那一写的位置，不翻；标记在场取 T0，不点名。丁在同一盘面上点名（盘 0 那一槽是 T1）。

另一条作废条件（零轮，模型「丙-意图三轮-取号带标记-所选根更新作废」）：所选那一版的根 (实例代号, txg) 严格大于标记那一写的位置就不认标记。意图三轮都在取号之后、本次挂载第一次发布之前，挂起状态下所选的根一定是这次挂载之前的；越过 X 的单元一定随一次比标记新的发布落盘。它不看哪一槽还在，单故障拿不走它（推的）。

## 没打中的形状

- 乙的漏放行：单次与两次断电（取号、回卷、两次发布的轮换，每写三态）× 用户五种动作 × 留镜像的时机（mkfs 之后、挂载结束、取号与意图轮途中活快照）× 单故障叠加；取号只一轮。推的 0，理由在 H1。
- 丁的漏放行与表不全同类误拒：同上的取样，另加放弃写回的每个断电态、放弃之后再放大到 3X。推的 0，理由在丁那一节与 H10。
- 甲（只读另点名落后盘）：J3 两形、H2 两形；推的 0。
- 正文第 4 问挂着的「可写按旧容量接着跑」：只要 T0 回到盘上的路是换回镜像，落后支先拒（H10 第 3 条）；写者写回 T0 的三条路各自另有改法。
- 跨盘不成链：只有放弃之后另一块盘又变大、再换回挂起时留的镜像才造得出（盘 0 记成 (2A, X)、盘 1 镜像里是 (A, 2X)）；那块盘落后且缺单元，可写由落后支拒；甲照它的定义整池拒，丁取逐项最小不拒只读。模型盘 0 恒定，没取样这一形，是推的。
- 没试：多于两块盘、两块盘一起变大的次序、根写撕裂（只取落没落）、单元写的撕裂、离线出路写什么表、管理员回退（`roll_back_by_a_forward_publish` 的统计按调整之后的分配器现算，读码看不出它碰 G5）。

## 这条腿自己的限度

- 模型没跑：子 agent 不交任务，派发也要求自己不跑。上面所有计数与「推的 0」都等主 agent 那两条命令；只做了 `python3 -m py_compile`。模型里的逻辑错只能等读数暴露，三条自证是唯一的防线。
- 模型是抽象的：槽按角色记、不记世代号；落点只记一个「最远落点」；落后支化成「这块盘收到的版本早于所选那一版」；单元写不枚举、根写不撕；用户动作只动盘 1。这些简化让历史上限停在两次挂载、单故障一档停在一次挂载。
- 崩溃态：每一轮系统配置槽写的三态组合全枚举，没有缩；缩的是历史条数（两次挂载）、发布计划（两种）、留镜像的次数（一段历史至多再留一次）与单故障档的挂载次数（一次）。缩前缩后各多少没量（模型没跑）。
- H10 第 1 条「换回镜像放进 2X 的盘三条规则一样不点名」是读码推的；它不在本题判据里，模型不数它。
- 正推腿与辩方腿的这一轮报告没读（辩方报告在禁读清单里）；第一轮两份报告与判决读了。
