# 「复核改判」表与候选表漏召回 第三轮三方

日期：2026-09-21。**这是最后一轮**——`.claude/rules/three-way-inference.md`「多轮：一次打穿不算数，三轮里多数打穿才算」定「第三轮之后停，不开第四轮」，这一轮里新冒出来的零轮形态不再为它开一轮，写进判决的交用户表标「零轮」。

前两轮：`research/prompts/agentdef-r1-main-verification.md`（判那条规则，攻方六格打中五格，四个改法进第二轮）、`research/prompts/agentdef-r2-main-verification.md`（判四个改法，一个都不采纳，那条规则留着一个字不改）。

## 课题

第二轮云端攻方在报告末尾自己提了一条收严，**被攻过零轮**，第二轮判决把它标零轮、没有采纳。这一轮攻它。逐字原文（`research/prompts/agentdef-r2-opus-output.md:288`）：

> 这一格是**可落成会失败的检查**的，这是它比 D、F 更该被看一眼的地方：要求同步记录里另有一张「复核改判」表（载体、原判定、改判后的判定、抓到它靠的是哪一件东西），门禁 68 号能机械核（载体格式、两个判定都是五种之一、两者不相等、末格非空），而且它在**0 处判错**的那一轮可以是 0 行表——与现有 ④「表可以 0 行」同形。它同时给 D 格提供了改法一提供不了的那件东西：一条「全看」独有的产物（抽样抽不到的行上的改判，只可能来自全看）。

同一份报告还报了一个 **H 格**，四个改法与这条收严都没碰（`research/prompts/agentdef-r2-opus-output.md:291`）：四个改法管的全是「已经进了候选表那 138 行怎么判」，而漏召回发生在更前面一步——写表人给一件真变了的事实选一个基准里从没出现过的检索词、再标「新立：」，那件事实的旧说法一行都进不了候选表。

## 分工

⚠️ 前两轮攻过的角度一律不许重复：第一轮六格 A–F（判决第三节那张表），第二轮五问（四个改法各自修不修得掉、两句并存、出处拿不拿得到、两两冲突、G 格）。

| 腿 | 这一轮的角度 |
|---|---|
| 云端攻方（Opus） | **攻「复核改判」表这条收严**。它声称「抽样抽不到的行上的改判只可能来自全看」——**这句话成立吗**？有没有别的路子产生同样的行（重跑一次 sweep、读别人的判定报告、按判定种类的分布反推）？第二轮那个 `forge.py` 的手法搬到这张表上还管不管用——不读一行载体，能不能从已入库的两份判定报告里机械造出一张合规的「复核改判」表？它说「0 处判错的轮可以是 0 行表」，那么一个**从头到尾没做全看**的轮次，交一张 0 行表算不算合规？ |
| 云端辩方（Sonnet） | **替这条收严辩护，同时复核第二轮判决**。第二轮判「四个改法一个都不采纳」而这条收严被标零轮挂起——它与那四个真的同级吗（攻方说它多一样东西：全看独有的产物）？另复核第二轮判决第二节改判的那两格（F 格改判、B 格降级）站不站得住，以及第二轮判决把「06:42 曾被判错只有一面之词」这件事写进 C468（判错的原始证据不落盘） 而不是拿它推翻 C 格，这个处置对不对 |
| 本地攻方 | **只攻 H 格**：候选表的漏召回。给写死的事实表——`research/scripts/stale-candidates.py:35-37` 那段工具作者自陈「管不到的」的原文（整段抄进提示，英文转述要逐句核）、候选表 138 行 21 组的规模、判定五种（不相干 / 事件句不改 / 要改 / 要人看 / 要补）。逐格问：写表人要让一件真变了的事实不进候选表，最少要做几件事？这几件事在事实表或候选表里留不留痕迹？主 agent 读事实表时，按什么判据能看出「这一行的检索词选得让它自己进不了候选」？ |

## 要判出什么

1. 「复核改判」表这条收严：采纳、改写后采纳、还是不采纳。采纳要写清它落成检查之后**什么输入会让它红**。
2. H 格：立不立账；立的话判据是什么形态。
3. 第三轮之后停。这一轮新冒出的零轮形态写进判决的交用户表标「零轮」，不再开第四轮。
