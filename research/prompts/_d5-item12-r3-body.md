## 三、候选（三条臂按前两轮的判决收严；收严都被攻过零轮）

**三条臂共同的前提**（前两轮查出、与臂无关）：被销毁的快照从写意图那一刻起不算活引用，prev 在写意图的那个事务里传给那一刻的下一侧；销毁头的意图要等同一个头上更早的级联意图做完才动条目；I-3.5 ③ 与 I-3.6 在有未完成意图时先扣掉「意图将放」的条目再判。

- **丙-区间（带上界）**：key = 头的树 ID 8 + 纪元 8 + 中央映射 key 27 = 43，value 空；纪元 = 块被杀那一刻头的 `previous_snapshot_txg`；快照 X 的 deadlist = 纪元落在 `[prev(X).txg, X.txg)` 的条目，头的 = `[prev(头), ∞)`；建快照只推进 prev(头)；销毁 S 时写意图 (头, lo = S.txg, hi, P = prev(S))，hi 在下一侧是快照时取它的 txg、是头时取写意图的那个 checkpoint 号；之后按批放掉 [lo, hi) 里 birth > P 的条目，不改任何条目的键。零树表字节。依赖前提十三。
- **乙（带次序）**：key = 号 8 + 中央映射 key 27 = 35；号住头 / 快照的 inode 树那一条条目的预留 8 字节；头的初始号取自己的树 ID，建快照时新快照拿走头的号、头换新号 = 新快照的树 ID；销毁 S 时在写意图的事务里决定搬哪一份、当场换号，把两个号与方向写进意图；同一个头谱系上的级联意图按写意图的次序做；挑边固定为「搬 S 那一份」（最坏改键 D(S)），不在写意图时数条数。
- **丙′（预留）**：key 同宽 43；纪元段装块被杀那一刻头的上一个快照的树 ID，这个树 ID 存进头条目的预留 8 字节；克隆头的第一段装 0；快照 X 的 deadlist = (头, X 的上一个快照的树 ID) 那一段；销毁 S 时写意图，把下一侧那一段里 birth > prev(S).txg 的放掉、留下的改键到 (头, S 的上一个快照的树 ID)；同一个头谱系上的级联意图按写意图的次序做。
