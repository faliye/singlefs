# 项目 subagent 的共用约束

`.claude/agents/` 下每个定义开工前先读这一份；与定义冲突时以定义为准。
共用约束与各份定义只写怎么做：步骤、约束、判据、交付。「为什么」、实测、经过与带日期的记录进 `records/2026-10-29-subagent拆分提案.md` 或 `.claude/kb/`，这里要用时写成读取指令（「开工先读：`文件`「小节」」）；上游门禁「规则纪律（项目本地）」阶段判这一句（`.claude/rules/implementation-workflow.md`「改 agent 定义与共用约束，走同一条三步」）。

## 派发

- 只由主 agent 派发。子 agent 手里没有 Agent 工具：不派 subagent，也不从 Bash 里起 `claude` 会话（「执行前拒绝的写法」⑬）。
- 轮名、产出路径、草稿目录、禁读清单由派发提示给；定义里的路径（`<轮>`）只是形态。输入缺一样不开工，回复只写缺什么。
- 派发提示写「已排除：…」的，同一条里给那条命令的原文与输出（长的给输出文件路径），只给结论的不算。收到的「已排除」当线索：开工先核那条命令真跑成了（退出码、没被丢掉的报错），核不成的照没排除办，报告写明。
- 主 agent 派发：简单任务（修改一下、查询一下、计划一下这类单一、流程简单的）自己直接做，不派；派之前先规划，同类任务一起派，尽量不串行；严格照定义设的 model 与 effort，effort 不超过 high，要超过弹窗告知用户；同一件任务连续三次派发失败，主 agent 自己做。

## 规则怎么读

`.claude/agents/` 下的定义都开了 `omitClaudeMd`：项目 CLAUDE.md、它 `@` 的规则、用户级 CLAUDE.md 与主 agent 的私有记忆都不进子 agent 的上下文。

- 规则文件（`.claude/rules/` 与 `.claude/singlefs-ai-sop/rules/` 下的 `.md`）：定义「开工先读：」一行点名的，与共用约束点名的（「每个定义都照守」那一条，与「写」一节里写「开工另读」的），开工整份读，不受读入大小的限制；「开工先读：」点名的小节是这件活要照做的那几条。定义与共用约束的步骤里写「照 <规则>「<节>」」的，做那一步之前读那一节，读全；只写「照 <规则>」没写节的，做那一步之前读那一份。
- 「开工先读：」点名的别的文件只读点名的小节：先 `grep -n '^#' 文件` 找起止行，再按行读；点的是整份的，先看节标题，只读与这件活有关的节。
- 没被「开工先读：」点名的别的文件：1,000 行以内的整读一次（Read 或 `cat`），不切片；超过的先 `grep -n` 定位再按行段读；读过、之后没改过的不重读。
- 每个定义都照守、不再各自点名的三处：跑命令照 `.claude/singlefs-ai-sop/rules/command-safety.md`（退不回去的操作，动手前先想一遍；`pkill -f` / `killall` 一律禁用）；给人看的文字照 `.claude/singlefs-ai-sop/rules/writing-discipline.md`（文风要简单自然）；说外部状态之前现查（`.claude/rules/evidence-discipline.md`「陈述外部状态之前，现查一次」）。
- 报告与进度记录里的时间只写日期，用 `TZ=Asia/Tokyo date +%F` 取（不用裸 `date`），不写时刻与时区（门禁 doc-text 的 clock-times 格判；写进仓里的，写闸当场拒）。
- 候选、臂、方案、判据、提问编号有了变体，起一个新名字（那一族下一个没用过的号，或短的描述性名字），不加撇号类角标（U+2032、U+2033、U+2034、U+02B9、U+02BA；门禁 doc-text 的 prime-marks 格全仓判，写法照 `.claude/rules/path-moves.md`「变体起新名字，不用角标」）。
- 派发提示与定义都没给的项目事实（某份 kb 在哪、某条决策的原文）去仓里现查，不凭印象补。
- **找不到历史实验的数据、提示或产物，去 `git log` 里看**：早于本轮的实验记录不留在工作区（本轮的留着，下一次提交删上一批；门禁 doc-experiments 的 archive-past-rounds 格判）；只写文件名、不写路径的引用当已归档的查，不当坏链接。查法：`git log --all --diff-filter=D --name-only -- "*<文件名>*"` 找删它的提交，`git show <提交>^:<路径>` 读当时的内容。读到的是当时的数、不是结论：拿它支撑新结论之前先重新跑一遍（`.claude/singlefs-ai-sop/rules/kb-discipline.md`）；别的用法照 `.claude/rules/evidence-discipline.md`「原样保存的证据不许事后改」「旧证据是参考，不是依据」那一条。

## 写

- **不新建判定库**（核心策略，没有例外）：判定一律经 prune-server 客户端按各族的键前缀写进它自己那一份 RocksDB；不另开目录、TSV、sqlite 或另一份 RocksDB 存判定，各族只走服务，再写旧库算违例；并回即删的中转库与对临时服务起的自证库不算；自证与压测不写真服务。改动里出现新的判定存放处，主 agent 打回。写测试、门禁、入口脚本、实验装置的，开工另读 `.claude/rules/verification.md`「判定库只有一份：全仓统一写进 prune-server 的那份 RocksDB」。
- **所有任务都要多机可用，不许绑定某一台**（核心策略，没有例外）：测试、自证、门禁、入口脚本、实验装置、服务的控制命令，派到两台任一台都要跑得起、判得对，结果两台都读得到；派到某一台就红的是缺陷，当场修，不往任务服务加只派一台的名单。不读会改变判定结局的本机独有状态，不写死主机名与地址，环境只从多机配置读；写这几类的，开工另读 `.claude/rules/verification.md`「所有任务都要多机可用，不许绑定某一台」。多机配置 `NFS_SHARED_ROOTS` 点名的共享根（含仓、工作根 `~/.local/share/singlefs/work/` 与会话记录目录）两台挂在同一绝对路径，不经 `~` 与 `$HOME` 取（第二台的家目录是另一个）：运行记录、产物、草稿目录、仓副本与要两台都读的输出放共享根下；交给服务的工作目录与参数里的路径原样带、不改写，第二台在同一路径上跑、不用取回；工作目录或命令里（含 `bash -c` 那个词里）有落在共享根外的绝对路径（含 `/tmp` 下的），`task submit` 当场退 3。新写的脚本从参数或环境变量取目录，不硬写家目录。
- 只写派发提示与定义「写范围」一节给的路径。两道闸照写范围表 `.claude/hooks/agent-write-scope.tsv` 判：Write / Edit 由写闸拒，Bash 里的写由检出钩子 ⑫ 执行前拒。被拒之后不换 Bash 或别的办法写过去，写进报告交主 agent。没有项目定义的 agent（内置类型、定义已删的旧实例）两道都只许写工作根。会话临时目录根 `/tmp/claude-<uid>/`（Claude Code 给各会话的临时目录与 scratchpad 都在它底下）不在任何子 agent 的写范围里：草稿与报告写派发提示给的草稿目录，用不上可以空着。
- **Bash 里写的落点要此刻算得出**：写死的值照算（`for 名字 in 写死的词` 逐个取值、前面赋的写死值、写死的 `cd` 之后的 `$PWD`、`mktemp -d` 赋的变量、`$HOME`、引号外的花括号逐个展开、`eval` 的字面代码、放在赋过值的变量里的定点写脚本词）；命令替换、没赋过值或来源不明的变量、`while read` 与 `for f in $列表` 的循环变量、通配、`xargs` / `find -exec` / `parallel` 接进来的词、cd 到算不出的目录之后的相对路径、重定向目标上展开成几个词的花括号都算不出，照拒。备份原文件用 `python3 scripts/agents/copy-originals.py copy <草稿目录> <文件>…`，按文件写多份输出写成 `for 名字 in 写死的词` 或逐条写字面路径。命令词不由变量、命令替换拼（`$c`、`eval "$c"`，项目代码闸照「认不出起什么的写法」拒）。钩子判不到的写法（代码在变量里的 `eval "$c"`、脚本文件里的、python / perl / ruby / tclsh 起的脚本文件里起的）全靠自己守。
- 手写改动：tools 里有 Edit 的用 Edit（旧串在文件里恰好命中一次，与 `scripts/kb/replace-once.py` 同义；这一轮自己新建的文件可以 `replace_all`）；新建文件，有 Write 的用 Write（先 `ls` 确认不存在），**tools 里没有 Write** 的一律排他新建：`set -o noclobber` 后 `cat > 文件 <<'EOF'`，文件已存在就停下报告，之后 `>>` 追加；Write、Edit 都没有的，改已有文件只用 `scripts/kb/replace-once.py` 或 `scripts/kb/replace-batch.py` 定点替换（先 `--dry-run`），不整份重写。除了排他新建，Bash 里只许定义点名的写入工具写仓内文件（「子 agent 不交任务」那一条列的那几样），不用 python / sed 就地改（「执行前拒绝的写法」⑧）。草稿目录里（仓副本、日志、自己的辅助脚本）用什么写都行。
- 报告分段写，每一次写进文件的内容不超过 150 行，表格与代码块整块放进同一段（`.claude/rules/three-way-inference.md`「云端腿的报告要分段落盘」）。
- **开工先认锁**（tools 里有 Write / Edit 的）：「草稿目录：」点名的目录里有派发闸建的写者锁 `.writer-lock`，你往里的第一次 Write / Edit 由写闸认持锁者（认法在 `.claude/hooks/lib_writer_lock.py` 文件头）。被拒而拒绝说明点名了别的持锁者的，这个目录归它：停下，已有的与没写完的写进报告交回，不换 Bash 或别的路径写进去（Bash 里的写闸看不见锁，同样不许）。子目录另派给别的子 agent 之后，父目录的持锁者不写那个子目录。
- **建仓副本**：建仓副本或编译目录之前，先 `du -sh` 列自己草稿目录下已有的副本与编译目录，用完的先删。仓副本只用 `python3 scripts/hosts/minimal-copy.py <仓根> <副本> --with-test-inputs` 建（直接跑、不经服务；派发提示给了段树或验证段第 1 步留下的快照的，`<仓根>` 填它；拷哪些它按闭包现算，算法在 `scripts/hosts/lib_repository_copy.py` 文件头）；要门禁表的加 `--with-gate-tables`；要主 agent 在副本里交带 `--item` 的门禁与崩溃放量入口、起仓里脚本的，逐条加 `--with scripts=<为什么>`、`--with .claude/scripts=<为什么>`、`--with .claude/singlefs-ai-sop=<为什么>`。不自己 `rsync`、`cp` 拷 `crates/` 与仓根条目，不手列清单；它拒了（闭包算不成、超阈值）照它的出路办。
- **用完就删**：副本、编译目录与运行目录里的中转库（并回服务那一份之后就该删的中转目录）用完就删，不留给以后的趟或别的任务。子 agent 交回之前删掉自己认领、自己建的那几份，删之前 `du -sh` 记大小写进报告；完工清理闸拦（「执行前拒绝的写法」完工清理闸那一项）。删不掉的编译目录、工作树与仓副本（`rm` 被权限拒、被别的闸挡），交回正文里逐个写一行「交主 agent 删 <全路径>：<删不掉的原因，至少 8 个字>」（全路径照抄闸列的清单）；删得掉的照删，不拿这一行代替。经服务跑的编译目录由服务给，交任务的主 agent 用完 `task-server/task clean <号>` 删，谁都不自己 `rm`。要交给主 agent 接着用的副本（主 agent 照报告「要主 agent 跑的命令」在里面跑），在它所在认领目录的 `.deliverables` 写一行「<相对路径> 交接 <主 agent 在里面跑什么>」；报告、补丁、打补丁前的备份同写进 `.deliverables`，写法在 `.claude/hooks/completion-cleanup-guard.sh` 文件头「要留的交付物」。
- **名字、注释、文档、输出文字都不用序数或位置代称**，也不用缩写与「a / b / c」这类略列：不写 `layer0`、`stream_0`、`first_stream`、「层 0」「第一条流」「第一项」，写它是什么、做什么（`enumerate_crash_states`、「崩溃点重放」「新池新建文件流」「录入段」）；所有语言、所有文本一样。登记过的改名在 `.claude/kb/term-renames.md`，别处一律用新名。
- 在一份文件里新加函数、类、方法或 shell 函数之前，先在同一份文件里按名字搜一遍（`grep -nE '(def|class) <名>\b|^<名>\(\)|function <名>\b' <文件>`）；同一作用域里已有这个名字的，换一个说出内容的名字或改用已有的，不定义第二份。
- 进仓的文字不写会话全名（`singlefs-<两位>`；非写不可写两位短号，或写「别的会话」「<做什么>那一路的会话」），不写批次字母代号（`5a`、`9g`、`5g-rs`、`24c-1`、`SC02`），写那一批做了什么；调度记录依赖表的「第 N 批」批号照留。
- **里程碑 17 收尾之前不兼容任何旧东西，代码与格式尤其如此**：格式锁定之前没有旧盘、旧库、旧产物要认，旧逻辑不做特殊处理。不写、不留：认旧版本的分支、为旧镜像或旧库单开的拒绝分支与错误种类、旧布局号与旧版本号常量、迁移脚本与补旧行的子命令、只为旧行放宽的读法（`legacy_ok` 这类）、只为旧数据留的编号约束（「新码接在最后、旧码不动」这类），以及造旧形态输入的测试与它们的变异行。格式、布局、编号、表的列改了，读者只认这一版：别的一律走同一条「认不得」的拒绝，出路写重建、换新目录或重跑，不按旧版本分别认、分别报；旧库、旧镜像、旧产物不迁移。`research/` 下是当时的记录，豁免，门禁与脚本里只为读它留的放宽照留。改的文件里碰到的兼容代码连同它的测试与变异行一并删掉；不在自己写范围里的，写进报告交主 agent。
- **代码与脚本的注释、说明只写现状，不写历史**：射程是 `crates/`、`scripts/`、`task-server/`、`prune-server/`、`.claude/hooks/`、`.claude/gate.d/`、`.claude/scripts/` 下的注释（`//`、`///`、`//!`、`/* */`、`#`）、Python 文档串、脚本文件头（用法、判法、弄坏开关说明、退出码表）与这几处的 `README.md`；`.claude/gate.d/fixtures/` 与 `.claude/singlefs-ai-sop/` 不管。只写这段代码此刻是什么、做什么、为什么非这样不可；不写日期、谁定的与哪一轮打中的（「用户弹窗定案」「第二轮攻方腿」「三轮判决第三节」、批号）、改动经过（「此前」「原先」「起初」「最初」「后来改成」「改成了」「换成了」「修过」）、旧值与旧做法、弄坏开关的「改前的样子」（写开关弄坏了什么、打开后哪一项该红）；要指依据，写现行登记位的编号与名字（决策分项、欠账号、不变量号、规则文件与小节标题）。判据：放到这段代码第一次写下的那天去读还是真话，就是现状；说运行时先后的（「放回原来的值」「后来的写被拒」）照写。历史的落点：改了什么、怎么证的红进 commit message；决策与实验的变更进 `.claude/kb/decisions-history.md`、`.claude/kb/experiments-history.md`；一轮的经过、量到的数与用户原话进 `records/`；三方打中了什么进 `research/prompts/<轮>-main-verification.md`。特殊缘由只三类：日期本身是数据（日期格式的说明与例子、测试输入里的日期、解析历史条目的代码讲它认的形态）、引外部文档或源码写读到的那一天、绕开外部工具缺陷写从哪个版本起与修好后删哪一段；那一行的注释写 `history-kept: <理由>`，理由至少 8 个字，「留着方便查来历」不算。路径与文件名里的日期是名字，照写。改存量照命中逐行改写，不整段删 `///` 或 `// SAFETY:`（`.claude/singlefs-ai-sop/scripts/comment-only-change.py` 把整段增删算改代码）。门禁 doc-text 的 comment-history 格全仓判；存量在只缩不涨的 `.claude/gate.d/comment-history-lag.tsv`，改净一个文件删它那一行，新写的不许往里加。
- 写进仓里的注释与 `.md` 引 D、E 编号写成「编号（简称）」，简称取登记位里的（`.claude/singlefs-ai-sop/rules/kb-discipline.md`（5. 编号只能做索引，不能做称呼））。
- 私有主机信息不进仓：本机的主机名与服务名，第二台的主机名与别名、IP、第二台上的路径，两台的服务单元名，清场脚本的内容，不写进 kb、records、research、规则、定义、代码注释与 commit message；写「本机」「第二台」，真实值只在仓根被 git 忽略的 `multi-host.env` 与 `~/.config/singlefs/` 里。贴原样输出、整行抄原话、冻结证据里遇到私有值的，换成 `〔本机主机名〕`、`〔第二台的主机名〕` 这类说法，同一行注明换掉了什么；这一句优先于「贴原样输出」「整行抄」「证据不许事后改」。门禁 doc-text 的 `private-values` 格判新加的行。
- **进仓的文字只写本项目的东西**：记录、kb、判决、注释、commit message 不写本机与第二台上不归本项目的目录名、路径、别的工程与它们的占用；要说空间只说本项目自己的目录与总的可用量，别的写「其余不归 singlefs」。门禁 doc-text 的 `out-of-project-names` 格判新加的行（singlefs 自己的脚本读的仓外路径登记在 `.claude/out-of-project-paths`，只放行那条路径本身）。

## 不做

- 不做 git 写操作（`add`、`commit`、`stash`、`checkout`、`restore`、`reset`、`worktree`……），不提交，不推送。

## 报告

- 交回与报告在不影响正确性的前提下写简练：写结论、依据与没做什么，不写做事的经过、不复述派发提示与定义；要求的命令与原样输出、行号、推翻条件照样给，嫌长就放进报告文件、交回里指过去。
- 引规则与 kb 的条款优先写 `文件@小节标题`（标题逐字、不带井号；`scripts/agents/cite-check.py` 认这种写法），不为一个行号再读一遍文件；引脚本、代码、产物写那份文件自己的行号，用 `grep -n` 或 `awk 'NR==行号'` 现取，不从背景材料里数、不从 `sed -n 'A,Bp'` 的输出里数偏移；没现查过的写「行号待查」。引原文整行抄，不摘句；贴的命令输出是这一次真跑出来的原样。
- 能用命令核的事实，贴命令与原样输出，输出不截断、嫌长先数；报告里的条数、阶段数、命中数用命令数，不手数。
