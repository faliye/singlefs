**机制：攒批只在被攒的操作共享祖先时才帮到甲。** 流不共享脊柱时，

甲每批 ≈ `批 + min(流数,批)×树高 + 2`，乙 ≈ `批 + 1`
⇒ **比值在「批 ≈ 流数」处见顶，批超过流数之后单调塌向 1**（128 流时批 200 已降到 2.89）。

> **「与组提交是替代品」只在「批大小 ≤ 并发流数」时是错的；
> 批大于流数时它是对的。**

⚠️ **这不改变定案**——轴二是被轴一**结构性**排除的（延后祖先 ⇒ 新根不可能自洽 ⇒ 发不出根），
与收益多少无关。改的是依据 ③ 的强度，不是结论。

**③ 还有一条必须同时写下的反向读法**：乙的收益只在单流同步写上存在，

### 「单流 vs 多流」不是原始变量：一条精确公式，四条负载是它上面的四个点

**2026-08-29 三方论证后定案。** 此前多处论证把「单流 / 多流」当成负载的分类轴，

> **块数 = 一次 fsync 触到的叶子数 + Σ各层被触到的互异节点数 + 1 根槽 + 1 记录**

四条负载逐格验过，**零拟合**（arm=intent，ckpt_interval=1000）：

| multistream | 10 | 10 + (10+10+10+1) + 1 + 1 = 43.00 | 43.00 | 0.00 |

| | 脊柱共享型（seq） | 脊柱不相交型（multistream） |

### 5.2 池与负载

- **池**：P 个文件。F1 每个文件 1 个数据单元（数据单元数 = P）；F8A 每个文件 8 个数据单元（数据单元数 = 8P）。inode 记录数 = P。
- **族**（d = 一次 fsync 改的数据单元数，f = 改的 inode 记录数）：F1：d = 1、f = 1（发布 B 的形状）；F8A：d = 8、f = 1，一个文件的 8 个单元。
- **一次 fsync 之内**这 d 条 extent 记录、f 条 inode 记录在 key 上相邻（D25 的「1 条共享脊柱」；F1 只有一条）。
- **落点方式只管 fsync 与 fsync 之间**：seq = 第 t 次 fsync 改第 t 个位置起的那一段，依次往后推、到尾回绕；rand = 每次在全池里均匀取一段。
- **覆盖写**：每次 fsync 改的数据单元都换新落点，旧版释放（与发布 B 同，`transaction.rs` 1196–1211）。
- **checkpoint 间隔 N**：WAL 两臂每 N 次 fsync 做一次 checkpoint；甲每次 fsync 就是一次发布，N 对甲不起作用。

### 5.3 一次持久化碰到哪些节点（期望值公式）

**记号**：树 T 第 l 层（叶为 0 层）有 `n_l` 个节点，一个第 l 层节点罩 `cov_l` 条条目（`cov_0` = 有效叶容量，`cov_{l+1}` = `cov_l` × 有效内部扇出）。一次持久化对一棵树的改动分成若干**组**：

- **连续组**：从位置 s 起相邻的 k 条。
- **散组**：k 条，在一段长 R 条的区间里均匀独立地落。

**第 l 层期望脏节点数**：
1. 一棵树上的连续组按起点排好，相邻两组之间的空隙 `gap_i` = 后一组起点 − 前一组末条位置。连续组合起来碰到的第 l 层节点数 `C_l = min(n_l, 1 + Σ_i (k_i − 1)/cov_l + Σ_i min(1, gap_i/cov_l))`（节点边界位置随机时区间并集跨过的边界数的期望加 1）。
2. 一个散组在第 l 层：`m = max(1, R/cov_l)`，期望碰到 `S_l = m × (1 − (1 − 1/m)^k)` 个。
3. 几组合起来：`U_l = n_l × (1 − (1 − C_l/n_l) × Π_散组 (1 − S_l/n_l))`；没有任何改动的层记 0；有改动时根层恒 1。

**各树的组从哪来**（「新」= 这次写出的单元，「旧版」= 它替换掉的那一版）：
- extent 树：一个连续组，k = d，位置 = 这次 fsync 改的那一段。inode 树：一个连续组，k = f。
- 记账树：15 行全部重写（D5 已定项 2「每行每发布重写」），全部节点脏。
- 树表：改了根的树（extent、inode、分配记录、记账）是相邻 4 条，一个连续组。
- 映射树：key = (类, 出生树, 出生 txg, …)，条目按区间排：(1,11) 数据单元、(2,11) extent 节点、(2,12) inode 内部节点、(2,13) 分配记录树节点、(2,14) 记账树节点、(3,12) inode 叶容器，区间长度 = 各自的个数；区间内按出生 txg 从旧到新。每个新写的受映射单元在它那个区间末端插一条（连续组）；每个旧版删一条，位置按下面的位置策略。
- 分配记录树：key = (设备, 槽号)，每块盘一个区间，区间内按分配先后排（K8 的近似：槽号序 ≈ 分配序）。每个新写的单元每块盘在区间末端加一条（连续组）；每个旧版每块盘改写一条，位置按位置策略。

**位置策略（K8，三个取样点，全部格都算）**：一个旧版要么「近」（上一次持久化刚写的，落在区间末端、与插入并成一个连续组），要么「远」。
- **L近**：只有数据单元的旧版可以远（数据单元数 > d 时：seq 远的是全池最旧的那一段，连续组、在区间起点；rand 是散组）；节点的旧版一律近。
- **L远**：节点所在层 `n_l` > 1 的，旧版一律远（seq 放区间起点连续组、rand 散组）；数据单元同 L近；rand 下数据单元新落点的分配记录也按散组（最低空槽复用打散槽号序）。
- **L均（主）**：seq：第 l 层节点的旧版远的比例 = min(1, d/cov_l)（推进时跨过节点边界的频率），远的放区间起点连续组；rand：远的比例 = 1 − q，`q = min(1, U_l / n_l)` 取这一格稳态下同一层每次持久化被碰到的比例（自洽：它随不动点一起迭代），远的放散组。数据单元同 L近。

**不动点**：写出单元数 W = d + 各树脏节点数之和。映射的插删取决于数据单元、extent、inode、分配记录树、记账树的脏节点；分配记录的新增与改写取决于 W 与各旧版；而分配记录树、映射树自己的脏节点又进 W。同时各树条目数（K5）也依赖节点数。做法：从「只有 extent、inode、记账、树表」起，反复重算条目数、层数、各组、`U_l`、W，直到两次迭代之间每个量变化都 < 10⁻⁹；上限 1000 次，到上限还在变就记「不收敛」（第十节 F2）。同一个节点在一次持久化里只写一次，由 `U_l ≤ n_l` 保证。

## 六、报哪些量与各自的判据

**标签规则 R（照第一次登记第六节，一个字不改）**：一串值 v(x₁) … v(x_m) 按轴排好，第 i 步 `δ_i = v(x_{i+1}) / v(x_i) − 1`。随轴扩大：最后 min(3, m − 1) 步每步 δ ≥ +5%；随轴缩小：最后 min(3, m − 1) 步每步 δ ≤ −5%；收敛：最后一步 |δ| < 5%；其它：以上都不是（报每一步的 δ）。这一次用在 P 轴、N 轴与 k 轴上。

**`s` 的两道门槛**：10% 与 0。10% 是登记时选的，与第一次登记第 2–4 行「上界够进候选」那道 10% 同值，不由任何臂的定义推出；写它时已知的 `s` 只有第四节第一行那两个 P = 1 的值（37.9%、46.8%，K9），都离 10% 很远。0 是「翻面」的字面：甲不比这条 WAL 臂贵。N_b = 1 的格上 `s` 由记录条数的取整给出（第一节），不算判据。

### 8.2 几何敏感性

|---|---|---|

## 十、失败条款

**F2 不动点在某一格不收敛。**

**F3 位置策略决定结论。** 模型没有模拟真实历史，旧版落在哪是取法。

# E155 第二次跑登记 B17：K8r ③（L远 + rand 下数据单元新落点的分配记录按散组）在函数一级的锚点。

# 数据旧版 1 条（散，K8r ②）、节点旧版 8 条（L远：散）。对照：数据新落点也并进尾部（第一次装置的做法）。
import math
def continuous(n, cov, groups, gaps):
    t=1.0+sum((g-1)/cov for g in groups)+sum(min(1.0, x/cov) for x in gaps)
    return min(float(n), t)
def scattered(k, region, cov):
    if k<=0: return 0.0
    m=max(1.0, region/cov); return m*(1-(1-1/m)**k)
def combine(n, cont, scat):
    s=1-min(1.0, cont/n)
    for x in scat: s*=1-min(1.0, x/n)
    return n*(1-s)
R=12000; cov=812; n=math.ceil(R/cov)
k8r=combine(n, continuous(n, cov, [8], []), [scattered(1+1+8, R, cov)])
old=combine(n, continuous(n, cov, [9], []), [scattered(1+8, R, cov)])
print("B17 nodes", n, "K8r3 data insert scattered", round(k8r,6), "| data insert at tail", round(old,6))
