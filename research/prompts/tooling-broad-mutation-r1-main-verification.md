## 三、判决

1. **分类（钩子）不过**：T1 有三类子 agent 发得出、分类放过、实际起整趟或改全局状态的命令，照跑前判据第 1 条必须改。
2. **驱动的「整趟中断续接、逐条落行」站住**：两条腿合计二十多个强杀时刻加主 agent 一次真跑都没打穿，可以继续用它跑第一段。
3. **驱动的判定可信度有缺口**（H7、H10、H12、H3、H9、H11、H13）：都不影响「已判的不重跑」，但影响一行结果能不能当定论；第二段开跑之前必须改完。
4. 主 agent 自己的规格缺陷一处：第二段写成完整 `cargo test`，重复第一段。
