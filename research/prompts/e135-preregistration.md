# E135 跑前登记：动态回退下界 F 能不能既守住「环里的候选都是真的」、又在盘紧时腾出空间

写于装置之前（2026-09-11）。来源：D16（发布语义） 未定项 1 的 2026-09-11 那一轮——用户问「能否动态缩容」，
主 agent 起草了第五条臂（回退下界 F），它**未经三方论证、未进模型**。按 `.claude/singlefs-ai-sop/rules/test-discipline.md`
「实验开跑之前，答案不许已经存在」，下面的臂、世界、判据、失败条款都在写装置之前写死，跑完不改；改了就是新实验。

⚠️ **写登记的人有倾向**：倾向臂 D（动态回退下界）成立。倾向写在这里是为了让判据防着它，见「结果反过来我接不接受」。

## 要回答的三件事

1. **正确性**：臂 D 在崩溃择根回退、掉一块盘、根槽写失败、管理员回退这几种情形下，候选集里会不会冒出假候选
   （自证合法、实例有效、而它引用的块已被复用）。
2. **腾出量**：盘紧时抬高 F，能腾出多少块、隔几次发布之后才能用。
3. **盘满时的行为**：在近满盘上反复删建，臂 A（整环 + 推空）、臂 C（K 取下限、候选集照今天的字面）、臂 D（整环 + 抬 F）
   各出多少次假性 ENOSPC、多少次发布卡死、可退代数最低掉到几。

## 臂（定义跑前写死）

「假候选」一律按 D22（单元原子性怎么合成） 的原话判：候选集里的一个根，它引用的块有任何一块已被复用。

| 臂 | 可再分配的谓词 | 候选集 | 盘紧时（准入失败）怎么办 |
|---|---|---|---|
| A `ring_persisted`（臂甲） | 已释放 ∧ 释放代 ≤ 环里**已持久的**最旧根的 txg（写失败的槽按旧内容算） | 环里按实例表有效的全部根 | 推空：连续做空发布，直到窗口里的释放全部放回，仍不够才报 ENOSPC（C283（准入失败时不先推发布就报 ENOSPC） 的形态） |
| B `ring_arithmetic`（对照，C282（环里最旧根没有定义） 的靶子） | 同 A，但最旧根按算术取 当前 − N + 1 | 同 A | 同 A |
| C `k_runtime`（臂乙） | 已释放 ∧ 释放代 ≤ 当前 − K + 1，K = K_min | 环里按实例表有效的全部根（D23（journal 的角色与格式） 已定项 14 今天的字面） | 不做别的 |
| D `floor`（臂戊，倾向） | 已释放 ∧ 释放代 ≤ max(F_生效, 环里已持久的最旧根的 txg) | 环里按实例表有效、且 txg ≥ F_恢复 的根；F_恢复 = 环里**全部**自证合法的根（含被抛弃时间线的根）所带 F 的最大值 | 抬高 F（一次抬到够用为止，上限 当前 − K_min + 1），F 随之后每个根写下；F 只增不减；带新 F 的第一个根持久之后，再过 K_min 次持久发布，F_生效 才等于它 |
| E `floor_no_delay`（对照） | 同 D，但 F_生效 在带它的根一持久就等于它 | 同 D | 同 D |
| F `floor_chosen_root`（对照） | 同 D | 同 D，但 F_恢复 只取所选根自己带的 F | 同 D |

K_min = max(崩溃恢复要的 2, 掉盘择根回退 + 1)；第一版两盘、R = 3 时掉盘 0 最坏回退 2 代（C222（I-7.4 的下限 2 与第一版两盘几何要的 3 打架） 逐字） ⇒ K_min = 3。

## 装置的口径（跑前写死）

- R = 3，S ∈ {1, 4, 16}，N = 3S。槽位：区域 = txg mod 3，区内槽 = ⌊txg / 3⌋ mod S（区内槽位公式仓里只是预想，
  first-txn-layout.md 标着「预想」）。区域 0、2 在盘 0，区域 1 在盘 1（同一张表的预想归属）。mkfs 把第 0 代种进全部槽。
- 块级计数模型，不建字节。每个块记（分配代，释放代）；一个 txg 为 T 的根引用块 b ⟺ 分配代 ≤ T < 释放代。
  复用 = 把块的分配代改写成当前代，于是旧根里那一段就指向了被改写的内容。
- 每次非空发布释放恰好 13 块、分配 13 块（E123（K 与回退深度的二选一各要付什么） 的 `BLOCKS_PER_FSYNC`，来自 D25 粗粒度定案）。
  空发布写 c_empty 块、释放上一次空发布那 c_empty 块，c_empty ∈ {1, 5}（预想：只重写树表单元 / 重写树表单元加一条深 3 的脊柱）。
- 保留池 = 一次非空发布的开销 13 块，只有发布看得见它（D23（journal 的角色与格式）「死锁 2」一行的破法）。
- 种子 24 个；每个世界跑 400 次发布。

## 世界

| 世界 | 发生什么 |
|---|---|
| `steady` | 只做删建与发布，没有任何故障 |
| `torn_newest` | 随机某次发布的根槽写被撕（该槽判无效），随即崩溃；恢复择新 ⇒ 退一代 |
| `disk0_loss` | 随机某次发布之后盘 0 整块丢失（区域 0、2 全没），恢复择新 ⇒ 最多退两代 |
| `slot_write_fail` | 随机某次发布的根槽写失败、槽里留着旧根，txg 推进一格再发（D23（journal 的角色与格式） 已定项 14 的索引行） |
| `admin_rollback` | 先在盘紧处抬一次 F、等它生效、再复用一批块，然后管理员回退到候选集里最旧的那个根，接着发布 |
| `near_full` | 预填到 97%，每次发布前删一个随机对象、建一个同样大小的对象；准入失败时按各臂那一列处置 |
| `rollback_first_publish` | C281（回退后第一次发布会复用被抛弃时间线还引用的块） 的构造：回退那次发布分配了被抛弃时间线还引用的落点，根槽 FUA 之前崩溃。**单独报，不拿来判臂** |

每次发布之后、每次崩溃恢复之后、每次回退之后，把当时的候选集逐个过一遍，数假候选。

## 跑前补登（2026-09-11，写装置时发现；此前一次都没跑过，没有任何产物）

写装置时发现上面有五处按字面执行不了或有两个读法，在跑之前改定，理由逐条写下：

1. **故障世界里臂 D / E / F 的 F 从来不会被抬**：准入只在 `near_full` 里失败，而判据 3 的两个靶子（臂 E 在 `disk0_loss`、
   臂 F 在 `admin_rollback`）要的恰恰是「刚抬过 F」。⇒ `torn_newest`、`disk0_loss`、`slot_write_fail`、`admin_rollback`
   四个世界里，给三条 F 臂在故障之前安排一次强制盘紧（照「盘紧时怎么办」那一列处置）；故障落在盘紧之后第 1 个或第 K_min + 1 个
   非空窗口（种子奇偶各取一半）；`admin_rollback` 的回退落在盘紧之后第 K_min + 3 个非空窗口，好让被 F 放出的块先被复用。
   臂 A / B / C 不做这一步。
2. **判据 2 没写在什么时刻数**，两个时刻差 1：发布之前（本窗口的复用已发生、新根还没写）是 N − K，发布刚完成是 N − K − 1。
   ⇒ 两个时刻都钉：发布之前 0 / 9 / 45，发布之后 0 / 8 / 44。E92（最坏块重用延迟需求） 的 N − K 对应「发布之前」。
3. **判据 5 的 Δ 没写在哪个时刻取**：F 生效要再等 K_min 次发布，这期间环里最旧根也在前移。⇒ Δ 取生效那一刻：
   Δ = F − 生效时环里最旧根的 txg。按登记的形态（在最新持久根 P0 处把 F 抬到 P0 − 2，第一个带它的根是 P0 + 1，
   P0 + 4 时生效，那时最旧根是 P0 + 5 − N），Δ = max(0, N − 7)：S = 1 / 4 / 16 时腾出 0 / 65 / 533 块，
   都在抬 F 之后的第 K_min + 1 次发布时。
4. **判据 3 的「24 个种子合计」按 S 也合计**。S = 1 时 N = K_min = 3，F 最多只能抬到最旧根，三条 F 臂与臂 A 在那一档等价，照报。
5. **口径补一条**：每次非空发布的 13 块拆成用户对象 8 块（走普通准入，看不见保留池）加元数据 5 块（发布自己的 COW，能用保留池）；
   `near_full` 先在 70% 预热 2N + 10 个窗口（不计数），再补到 97%——否则 mkfs 种下的 N 份第 0 代会让开头 N 次发布什么都复用不了，
   量到的是 mkfs 的瞬态，不是近满盘。

## 它答不了的（跑前写死）

1. **墙钟**：全按发布计。「负载重时 17 毫秒、空闲时 4 分钟」那张换算表不从这里出。
2. **真设备**：计数模型，不碰设备、不建撕裂字节。
3. **journal 重放窗口**：只建根一级的引用，不建记录；E92（最坏块重用延迟需求） 的 c2（在飞记录数上限）本仓没有值，这里也不编。
4. **实例表**只建到判定候选有效所需的那一点（回退行的 T 上限）；实例切换不建。
5. 槽位公式与盘归属用的是 first-txn-layout.md 的预想；换一种公式，K_min 与判据 3 的靶子世界可能要重算。
6. 「可退多深才够」是产品判断，实验只给代价。
