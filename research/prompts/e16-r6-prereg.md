### 13.8 E16 这一份自己的命令

**命令一 b**：批轴上哪些批的乙块数随 67 → 64 变（`anchors_e16_r6.py`，全文；脚本 sha256 `6c15e14c5b44a964358c402df9d80c91a1e59dc16a5f9f6520789cdb7aab4f68`，输出 sha256 `8c7922b16523536fb30da337020bb08f0d993a7334a165de75845cfb2f8781f0`）。乙在 B = 63–73 上的块数在命令一（13.7）输出的最后一段。

```python
#!/usr/bin/env python3
# E16 第 6 次（差分）的独立锚点：批轴上哪些批的乙块数随每条点名项数 67 → 64 变。
# 批轴与流数轴手抄自 e16_fifth_run_peak_under_today_widths.rs:419-445（加上这一次登记的 63、65），不 import 装置。
from math import ceil
streams = sorted(set([2, 3, 4, 6, 7, 8, 11, 12, 16, 24, 32, 48, 64, 96, 128, 192, 256] + [384, 512, 768, 1024]))
base = [1, 2, 3, 4, 5, 6, 7, 8, 10, 11, 12, 14, 16, 20, 24, 28, 32, 40, 48, 50, 56, 64, 67, 68, 70, 72, 73, 80, 96, 100,
        112, 128, 160, 192, 200, 224, 256, 320, 384, 448, 512, 640, 768, 1024, 1280, 1536, 2048, 3072, 4096]
ext = [6144, 8192, 12288, 16384]
new_points = [63, 65]
union = set()
for s in streams:
    union |= set(base + ext + new_points + [s - 1, s, s + 1])
union.discard(0)
changed = sorted(b for b in union if ceil(b / 64) != ceil(b / 67))
same = sorted(b for b in union if ceil(b / 64) == ceil(b / 67))
print("stream_axis", len(streams), streams)
print("batch_values_union", len(union))
print("l_blocks_changed_batches", len(changed), changed)
print("l_blocks_same_batches_count", len(same), "max_same", max(same))
print("smallest_changed", min(changed))
```
