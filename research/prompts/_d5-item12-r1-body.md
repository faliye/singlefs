## 二、洞

D5（快照 / 空间记账机制） 未定项 12 的三问（按什么身份记一块、按 `birth` 怎么分桶、value 装什么），加上 C145（deadlist 在盘上没有落点） 那一半：交接语义要求快照也要能指到一份 deadlist，而「条目归谁」怎么编码没写。

## 三、候选（按「条目归谁」分三条臂；分桶与 value 两问在每条臂上各答）

- **甲（归属 = 所属那棵树的树 ID）**：key = 归属树 ID 8 + 中央映射 key 27 = 35，value 空。活头的 deadlist 用头的树 ID；建快照时活头的条目改键到新快照的树 ID（逐条重写）。不动树表条目。
- **乙（归属 = deadlist 号，住树表条目预留的 8 字节）**：每个头 / 快照的树表条目带一个 deadlist 号；key = deadlist 号 8 + 中央映射 key 27 = 35。建快照时新快照拿走活头的号、活头换一个新号（O(1)，与 ZFS 换对象同形）；销毁级联把条目改键到下一侧的号。用掉前提八里点名给 deadlist 的那 8 字节；第一个事务里现有的头写不写号，要定。
- **丙（归属 = (头的树 ID, 块被杀那一刻头的 `previous_snapshot_txg`)）**：key = 头的树 ID 8 + 纪元 txg 8 + 中央映射 key 27 = 43。建快照时活头的 `previous_snapshot_txg` 变成新快照的 txg，之后被杀的块自然落进新纪元 ⇒ 交接不改写任何条目、不用树表字节；快照 S 的 deadlist = (头, `prev(S).txg`) 那一段；销毁级联把那一段并进下一侧的纪元、按 `birth > prev(S).txg` 过滤。
- **分桶问**：(i) 不另分桶——中央映射 key 里本来就有出生 txg（前提六），销毁级联本来就要把那一段逐条过一遍；(ii) 在映射 key 之前再放一份 `birth` 8 字节，让条目按 `birth` 成段。
- **value 问**：空（落点与大小一律经映射取，前提十一），或带大小。
