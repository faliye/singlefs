- `src/atk-vw/`：上一轮攻方 vw 原型 `atk_vw_part1..8.rs`，我改了 `part2`（`AtkAsk::head` 认新成员、`atk_compare` 对盘表被拒的格照同一份坏盘表真走）、`part3`（盘表动作 `table-reversed|swapped|one|second|dup|more|stale|crossed`、`crash-remount`、`atk_set_table`）、`part5`（别的池的报那一测加真走比对），加了 `part9`（`sonnet_k13_foreign_report_matrix`、`sonnet_k13_two_mounts_of_the_same_crashed_image`、`sonnet_k12_push_entry_with_the_two_devices_reversed`）。拼法：冻结副本的 `raise_floor_takes_…table.rs` 后接 `atk_vw_part*.rs` 成新测试目标 `atk_vw_opus`（名字不带 layer0）。
- `src/atk-pqrs/`、`src/atk-tu/`：上一轮我的垫片版 pqrs / tu 原型（没改）；`atk-tu/part9_k14.rs`（K1-3 / K1-4 的量法，要量法副本 `tree-k14` 里 `unlink.rs` 的 `DeletionSwitches` 手写 `Clone` 带计数、`mounted_session.rs` 的 `VW_SKIP_REPORT` 开关，`src/patches/tree-k14-*.diff`）、`part10_k3b.rs`。
