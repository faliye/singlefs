## 三、格

### A1　I-4.1 与 I-8.4（重放后可遍历、重放幂等）
候选：R-独 checker 照 D23 已定项 14 的文字自己写一份完整的只读重放（锚点、断号即止、发布边界、点名单元验证），再走读，I-4.1 判重放之后那一版全树可遍历，I-8.4（重放幂等） 判施加两次与一次得同一个根；R-换 改写 I-8.4 的对象为「恢复 + 写行」那一整段（盘上状态），在崩溃注入的二次崩溃上判，不在单份镜像上判；R-形 I-8.4 交给七（形式化验证）的 M3，checker 这边不判、状态列写明。每条答：要写多少行、与 core 的 `replay_journal` 独立不独立、一份只红它的坏镜像能不能造出来（施加按值覆写时 I-8.4 在单份镜像上是不是恒真）、I-4.1 的措辞「系统配置指向的树」改成什么。

### A2　I-8.1（环几何够大，C28（环几何不变量未实现））
改写候选：把三个字段的自洽写成不变量（在飞上限 = ⌊环长 ÷ 4096 ÷ F⌋、最坏占用 = 在飞上限 × 4096、F ≥ 2），mount 时复算比对，不等拒挂；「任一事务的最坏占用 ≤ 在飞上限」这一半落在发布时的拒绝（`transaction.rs:5383-5407` 已有）而不在镜像上。答：这个改写是不是把 I-8.1 缩成了同义反复（门槛能不能从定义直接推出来，`.claude/singlefs-ai-sop/rules/test-discipline.md`「门槛不能是臂定义的同义反复」）；D28（挂载期承诺量） 已定项 4 口径注那一格（mkfs 取上界还是挂载期内复算）怎么定；checker 判什么。

### A3　I-7.5（根槽按判定宽度对齐，C47（根槽没按判定宽度对齐））
答：checker 的判定宽度取什么（系统配置声明的 pbs、声明的 io_min、两者取大；探测不到时怎么办——C388）；逐槽判的式子；异构池取 max；mkfs 要不要同时加拒绝（推的那一格 io_min 3072 / pbs 4096 先在冻结副本上核成不成立）。

### A4　I-8.5 改写与系统配置冗余（C367、C461、C466）
候选：V-盘 每块盘非空（C367 的改写，一块盘全废判违例，与 core 能挂冲突）；V-池 全池至少一块盘有自证槽为不变量，一块盘全废不判违例、另开一个出口报「盘 X 系统配置全废」（C461 欠的那一半）；V-报 同 V-池，但报的出口是 checker 返回里一类「降级」判定而不是违例。C466：写一条新不变量「各盘自证槽里的 device_count 相同、等于盘表」。答：取哪个、编号与措辞、checker 的出口形态、与二·4 那一轮 H6（C463（一块盘的系统配置两份全废之后静默成功））的条款对不对得上。

### A5　树 ID 水位（C147、I-7.8）
答：checker 只取根环水位、core 并上记录水位，两种取法在「根槽读不出而记录在」的合法镜像上会不会让 checker 误红（给一份具体镜像，或证明不会）；要不要改 I-7.8 的措辞把记录新根段并进来；「根轮出环」坏镜像的造法（连发 R + 1 个 checkpoint 各建一棵树，第一版能不能建树）。

### A6　指针 extent 偏移（C581）
