1. For P329, an I/O error during rows publish could leave partial rows, causing instances with no row to be marked published by F2 even if no root references them. For P330, an I/O error during rollback could leave instances between rollback target and new instance without rows, so F2 marks them published despite rollback intent. For Q330, journal ring wraparound might overwrite valid checkpoint records, causing new instance checkpoint to be too low, leading to missed roots and lost confirmed writes. For R, an I/O error during replay could leave incomplete journal application, but T_pub set to incorrect checkpoint, causing units with no root reference to be marked published.

2. R cannot mark a mounted root-referenced unit as unpublished because for i == i_now, published status depends only on b <= checkpoint. P330 (2) could mark an abandoned timeline unit as published if its row is missing (no row implies published by F2). Given one publish is atomic, W still matters for code-1 units as n <= W condition.

3. P329 costs extra row and chain rewrite at every mount and one more switch reserve share. P330 costs extra row and chain rewrite at every mount. Q330 costs a scan for max checkpoint. R costs no extra row or scan but avoids rewriting code-2/3 units. The first transaction bytes on first mount after format change for Q330 (checkpoint calculation) and R (T_pub setting), but not for P329 (first mount skips rows).

4. For P329, a check that all instances between chosen root and new instance have rows fails if removed; runs in image checker. For P330, a check that rollback instances between have (i,0,0) fails if removed; runs in multi-mount crash-point replay. For Q330, a check that new instance checkpoint equals max(superblocks, roots, journal records) + 1 fails if removed; runs in image checker. For R, a check that chosen root's T_pub equals replay checkpoint fails if removed; runs in multi-mount crash-point replay.

5. P329 contradicts the warm-up rule because it makes rows publish the first publish (non-empty), violating the requirement for empty roots until both devices are covered. No other package contradicts the admission rule, rollback rule, root tie-break, or rows uniqueness. Recommend P330, Q330, and R without P329.
