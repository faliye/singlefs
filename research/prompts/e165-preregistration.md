## 一、问题

英文名：replay_bounded_enumeration

主 agent 给的问题（逐字）：

> 在入库装置上、不装任何工具、直接调 `crates/singlefs-core/src/recovery.rs` 今天的 `replay_journal`（真 CRC、真 `JournalRecord::to_bytes` / `parse`、真反向链、读者用内存里的盘），在小界内穷举：
> (a) 合法历史域（一段合法历史的任意记录落盘子集；每次发布几条记录、提交标记怎么摆全扫）与对抗域（自证过、字段任取的记录）里，照条款文字手写的每条判据各报多少违例；
> (b) `crates/mutations.tsv` 里锚点落在 `replay_journal` 与它直接调的判定函数里的每条变异，加上登记里自造的几条（至少「一条都不施加」「不看在飞上限」「不验点名单元」），各自在哪个域、哪条判据、几条记录时第一次红（最小杀伤界），扫描上沿要让极值不落在端点。

读法写死：

- **被测对象**：`replay_journal(reader, root, ring_bytes, records, verify_named_units)` 这一个函数的返回值（`Result<(JournalScanReport, RootRecord), RecoveryFailure>`）。择根、择系统配置、扫环不在被测范围；`records` 由装置把内存盘上每个记录槽的字节过一遍 `JournalRecord::parse` 建出来（读得出的才进表）。
- **分母**：每个域的分母是那个域的状态数（第五节逐域给定义，第七节给闭式值）；单调那两条判据的分母是状态对数。违例数是「判据为假的状态（或状态对）数」，每条判据各数各的，不合成一个真假。
- **「几条记录」**：合法历史一族里指整段历史的记录总数 N（含所选根那次发布的记录）；对抗域里指锚点之后自由取值的记录槽数 n。
- **最小杀伤界**：一条变异在某个域、某条判据上，按 N（或 n）从小到大扫，违例数第一次与原实现不同的那个 N。一个域里扫到上沿都与原实现逐判据相同，记「界内不红（上沿 N = …）」，不记成等价。
- **判据只照条款文字写**，不照 `replay_journal` 的循环写；条款有两种读法的（K3、K6、K7、K9 的候选），每种读法一条判据、各报各的。
- **实现锚点与条款判据分开**：条款没写、只在实现的文档注释里写了的行为（所选根 txg 是 u64 最大值时报错、关掉点名验证时 `verification_passed` 不加）另起「实现锚点」一栏，不算条款判据；变异只被实现锚点抓到的，条款判据那一栏照记「界内不红」。

#### 已定项 7：发布的持久顺序

**定案**：一次发布的持久顺序恒为 COW 单元 / 节点 → 屏障 → journal 记录 → 屏障 → 根槽（FUA）→ 系统配置槽 → 屏障；fsync 等系统配置轮换持久之后才返回。恢复重放在施加任何记录之前，必须逐项验证点名单元的校验和。**系统配置槽在根槽持久之后再更新，每个 checkpoint 一次**，它是发布序列的最后一步、进层 0 枚举，一次发布的段序列因此唯一。**抬 F 那一串（准入与卸载）在它的第一次发布之前多一步**：先把新 F 写进每块盘的系统配置、过一道屏障（已定项 1「抬 F 那一串」）；这一次系统配置写不属于任何一次发布，每次发布内部的顺序照旧。**fsync 返回条件多一句**：新实例在本实例写成的根覆盖两块盘之前，fsync 不返回（做法与次数在已定项 8）；管理员回退是挂着时的一次向前发布（D23（journal 的角色与格式） 已定项 14），它的根持久之后才向管理员确认，与 fsync 同一个返回条件；实现待派，排在实审 A3c 之后（同在 `transaction.rs`），代价另登记一个小实验量。

**射程**：定的是一次发布内部这几步的先后与 fsync 什么时候返回，不定屏障的真机代价、也不定根槽本身的冗余形态（D22（单元原子性怎么合成） 已定项 2）。三样已知边角：

- **「fsync 等系统配置轮换持久之后才返回」的射程**：返回之后这一代的根只由那一个根槽罩着（根槽不镜像），见证它的系统配置已落盘。同一实例里退一代，靠 journal 重放追得上；**每个新实例（每次可写挂载、恢复、切换）的第一个根在下一次发布之前是单点**——那个槽读不出或它所在的盘掉了，恢复退到上一个实例的根，重放按严格前缀停在实例边界（D23（journal 的角色与格式） 已定项 14 的注 1），这次挂载里 fsync 已返回的事务丢，一个故障就够。要不要让新实例先把根写到两块盘上再确认，是已定项 8。
- **屏障口径**：两道 FLUSH + 根槽 FUA + 系统配置轮换之后一道屏障 = 每次发布四个序点，比 D25（目标负载优先级） 推导的两个多两个——多的两个是第二道屏障与「发布返回前加屏障」的价钱，知情接受（后者用户 2026-09-27 定，起因是 C577（系统配置没见证到的最新根，乙罩不到） 那条用例在抬 F 之前更早红：发布路径根槽 FUA 之后轮换系统配置就返回，没有屏障）。
- **第二道屏障买的是记录流完整性**，不是数据完整性：数据完整性的必要屏障恰一道（根槽之前）；不上第二道有 7 类「根在案而记录缺席」的状态，记录核对器与反向链的输入有洞。用户定案「需要」，两道都上。

## 五、臂、阳性对照、真实基线

这个实验的「臂」有三层：被判的实现（原实现是真实基线；第二段每条变异各是一条臂）、输入域、判据的读法。每层都写死。

### 5.1 合法历史怎么生成（生成器是可信件，K4 的合法历史域照它定义）

一段合法历史 = 实例 g 的 p 次发布 P_0 … P_m（p = m + 1 ≥ 1），照 D23（journal 的角色与格式） 已定项 4、7、8、14、15 与 I-8.9 的字面写：

- 第 i 次发布有 k_i ≥ 1 条记录，共享 `checkpoint_txg` = t_0 + i；计数器从 c_0 起全历史连续；本次发布内序号 1..k_i；只有第 k_i 条带末条标志。
- 提交标记：一次发布由一个或几个事务组成，每个事务占连续的几条记录、只有它的最后一条带提交标记，发布的末条必带 ⇒ 每次发布 2^(k_i − 1) 种摆法，全扫。事务号从 1 起、全历史每个事务加一。
- 每条记录带它那次发布的新根段（树表指针、映射根指针、树 ID 水位、F 四个字段）；各次发布的四个字段两两不同（树 ID 水位取 1000 + i，F 取 10 + i，两条指针取过得了 `to_bytes` / `parse` 往返、两两不同的值）。时间线上第 j 版 R_j = 所选实例 g、txg t_0 + j 与 P_j 的新根段；`instance_table` 等不在新根段里的字段全历史相同。
- 反向链取真值：`back_chain_of(全历史里前一条记录的字节)`，不管前一条落没落盘（写的人知道它）；P_0 的首条前面没有记录，链取一个固定的非 0 值（它的前一条不在盘上，不判）。
- 每条记录经 `JournalRecord::to_bytes` 成 4096 字节，写在内存盘 0 号盘的 `record_offset(计数器, 环长)`；「没落盘」的槽是 4096 个 0。`records` 表 = 按盘号升序、逐槽 `JournalRecord::parse`，读得出的按 `(实例, 计数器)` 先到先得。
- 固定值：g = 3；t_0 = 100（E 域除外）；大环 64 槽（在飞上限 21）、c_0 = 7；小环 S 槽时 c_0 = S（历史的第二条记录落回槽 0，回绕在历史中间）；所选根 = R_0（C 域除外）。这些取值不是条款给的，几何那一维的敏感性见第八节。

不罩的（写明，不当罩了）：空发布记录（事务号 0）、一条记录点名多个单元、单元类别认不出那一支、记录的两份镜像不一致（R 域那一条残留除外）、跨环一圈以上的覆盖、多于两个实例、实例表与分配记录树根那几个不在新根段里的字段。

S 的定义（括号里是出处；(j) 之外三种读法相同）：

1. 表里与所选根同实例、同 txg、带末条标志的记录多于一条 ⇒ 期望「报错、一条都不施加」（D23 已定项 14「这一版的失败处置」末句）。

3. 前缀从链首起逐条往后取，遇到下面任一情形停（该条与之后的都不进前缀）：(a) 计数器缺号（第一条：jsn 严格连续）；(b) 该条不在水位之上（定案首句「只施加严格大于所选根的记录」；⚠️ 条款没逐字写「链上遇到水位之下的记录怎么办」，这里取「停」，设计时定的）；(c) 已取满在飞上限条（I-8.3 补句）；(d) 该条的反向链不等于盘上前一条的 311 字节头算出的链值，前一条不在盘上不判（I-8.6）；(e) 序号 0；(f) 该条是一次发布的首条而序号不是 1；(g) 该条不是首条，而 txg 与本次发布前一条不同、或序号不是前一条加一（(e)–(g)：已定项 4 读者规则前三格与「序号依次 1..N」）；(h) 本次发布前一条不带提交标记而该条换了事务号（已定项 7「丢掉提交标记还没出现的那个事务的全部记录」）；(i) 该条带末条标志而不带提交标记（第三条）；(j) 该条带末条标志，且按所取读法「之后还有同 (实例, txg) 的记录」（已定项 4 读者规则第四格）；(k) 验点名单元开着而该条有一份点名单元读不出或校验和不对（第四条）。「一次发布的首条」= 链首，或紧跟在一条带末条标志的记录之后的那条。

#!/usr/bin/env python3
"""E165 登记用的状态数锚点：闭式 + 小界暴力枚举互核。只数装置的输入域与照条款文字写的 j*，不碰 crates 的实现。"""
from itertools import product
from math import comb

def compositions(n, kmax=None):
    if n == 0:
        yield (); return
    for k in range(1, n + 1):
        if kmax and k > kmax: break
        for rest in compositions(n - k, kmax):
            yield (k,) + rest

def patterns(shape):  # 每次发布的提交标记摆法：末条必带，其余 k-1 条任取
    n = 1
    for k in shape: n *= 2 ** (k - 1)
    return n

def L_brute(N, kmax=None):
    return sum(patterns(s) * 2 ** N for s in compositions(N, kmax))

# --- L：合法历史任意记录子集 ---
for N in range(1, 8):
    assert L_brute(N) == 2 * 6 ** (N - 1), N

print("L per N:", L); print("L total N<=10:", sum(L.values()), "N<=8:", sum(L[n] for n in range(1, 9)))
assert sum(L.values()) == 2 * (6 ** 10 - 1) // 5

# --- L 小环：每次发布不超过在飞上限条，N <= S ---
for S in (6, 9):
    lim = S // 3
    per = {N: L_brute(N, lim) for N in range(1, S + 1)}
    print(f"Lsmall S={S} lim={lim} per N:", per, "total:", sum(per.values()))

def U_brute(N):
    return sum(patterns(s) * 6 ** N for s in compositions(N))

U = {N: 6 * 18 ** (N - 1) for N in range(1, 7)}
print("U per N:", U, "total N<=6:", sum(U.values()), "N<=5:", sum(U[n] for n in range(1, 6)))

def X_brute(N):

for N in range(2, 7):
    assert X_brute(N) == 4 * (N - 1) * 6 ** (N - 2)
X = {N: 4 * (N - 1) * 6 ** (N - 2) for N in range(2, 8)}
print("X per N:", X, "total N<=7:", sum(X.values()), "N<=6:", sum(X[n] for n in range(2, 7)))

# --- E：txg 顶格 ---
def Lp_brute(N, p):

E1 = {N: Lp_brute(N, 1) + Lp_brute(N, 2) for N in range(1, 5)}

def C_brute(Np, kmax=None):

        states += patterns(s) * 2 ** (Np + len(s)); pairs += patterns(s) * 3 ** (Np + len(s))
    return states, pairs

    assert C_brute(Np) == (8 ** Np // 2, 9 * 15 ** (Np - 1))
Cw = {Np: (8 ** Np // 2, 9 * 15 ** (Np - 1)) for Np in range(1, 7)}
print("C wide (states,pairs) per N':", Cw, "total:", tuple(sum(v[i] for v in Cw.values()) for i in (0, 1)))
print("C wide small ring S=6 (k<=2, N'<=5):", {Np: C_brute(Np, 2) for Np in range(1, 6)})

def legal_states(shape, cut):
    """cut='own'：根槽自成一段；cut='with'：根槽与本次发布的记录同段。返回持久集合（frozenset）列表。"""
    writes, segs, base = [], [], 0
    for i, k in enumerate(shape):
        recs = [("rec", i, j) for j in range(k)]; root = ("root", i)
        segs += [recs, [root]] if cut == "own" else [recs + [root]]
    out, done = set(), []
    for seg in segs:
        for bits in product((0, 1), repeat=len(seg)):
            out.add(frozenset(done + [w for w, b in zip(seg, bits) if b]))
        done += seg
    return out

    st = pr = same = 0
    for s in compositions(Np):
        L_ = legal_states(s, cut); pat = patterns(s)
        st += pat * len(L_); pr += pat * sum(1 for a in L_ for b in L_ if a <= b)
    return st, pr

# --- 域非空见证：L 大环里照条款文字的 j*（从 c+1 起连续完整的发布数；大环上限咬不到） ---
def jstar_counts(N):
    ge1 = ge2 = 0
    for s in compositions(N):
        if len(s) < 2: continue
        offs = [sum(s[:i]) for i in range(len(s) + 1)]
        for mask in range(2 ** N):
            j = 0
            for i in range(1, len(s)):
                if all(mask >> r & 1 for r in range(offs[i], offs[i + 1])): j += 1
                else: break
            ge1 += patterns(s) * (j >= 1); ge2 += patterns(s) * (j >= 2)
    return ge1, ge2
print("L witness (j*>=1, j*>=2) per N<=7:", {N: jstar_counts(N) for N in range(1, 8)})

def seg_states(shape, cut):
    segs = []
    for i, k in enumerate(shape):
        recs = [("rec", i, j) for j in range(k)]; root = ("root", i)
        segs += [recs, [root]] if cut == "own" else [recs + [root]]
    out, done = [], []
    for seg in segs:
        out.append({frozenset(done + [w for w, b in zip(seg, bits) if b]) for bits in product((0, 1), repeat=len(seg))})
        done = done + seg
    return out
def same_seg_pairs(Np, cut, kmax=None):
    total = 0
    for s in compositions(Np, kmax):
        pairs = set()
        for states in seg_states(s, cut):
            pairs |= {(a, b) for a in states for b in states if a <= b}
        total += patterns(s) * len(pairs)
    return total
for cut in ("own", "with"):

## 八、轨迹与几何敏感性

**轨迹**：这是确定性枚举，没有轮次，「峰值、为正轮数、期末值」三样里轮数与期末值不适用。被谓词消费的量有两个，照「不只报一个端点」的意思各报分布：

- 在飞上限被主循环 `take(上限)` 消费，也被 J6 的前提消费。每个域报「表里所选根之上的记录条数」的最大值、它大于上限的态数、等于上限的态数。大环上大于上限的态数预期为 0（界内 N ≤ 10 小于 21）；那一格只写「上限在大环上咬不到」，不写成「不动点恒成立」。
- 重放跑多少遍：装置固定两遍（J6）。「第 k 遍（k ≥ 3）还动不动」不量——J6 为假的态上另报「第三遍与第二遍相不相等」的态数，只报不判（附带，够判后不跑）。

**几何敏感性（`.claude/rules/mutation-sampling.md` 第六类）**：判决依赖的旋钮有四个，逐个写取了哪几个点、哪个方向相反。
