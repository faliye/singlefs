# 背景：singlefs 的加密设计现状（用于判定「AEAD 的关联数据里必须放什么」）

singlefs 是一个从零设计的 COW 文件系统（Rust，尚无代码，处于格式设计阶段）。
下面每一条都出自本仓 `.claude/kb/decisions.md` 的**已定条款**，是本工程自己的设计事实，
不是对别家实现的转述。

## 已定的加密骨架

|---|---|---|
| A1 | **整卷 AEAD**，加密边界与校验和边界重合：父指针里那个校验和字段在开加密时**就是 MAC** | D9 方向 |
| A2 | **除超级块外全部加密**，元数据留最小明文头 | D9 方向 |

## 已定的那笔取舍——本轮问题的来源

D9 未答项 5 已定：**把「一个块的物理地址的权威记录点」移出加密结构**，
采用「明文的逻辑身份 → 物理地址映射层 + 明文反向索引」。

理由：无密钥（锁盘）状态下 GC / balance / copygc 要能搬块，
而搬块必须改「位置」，被 MAC 覆盖的东西无密钥改不了。这是**互斥取舍**，选了性能。

该条款自己写明失去了什么：

- 「哪个块该出现在这个位置」不再有密钥保护。**块内容仍被 MAC 认证**（改内容会被发现），
  **但换位置不会**。
- 父指针里可以放一个明文的「期望代号」补回**检测**能力（纯整数比较、不要密钥），
  但代号是明文，**攻击者可以连块头带代号一起伪造**。

该条款还写明一条必须守住的范围线：**只把「逻辑身份 → 物理地址」这一层扁平映射放明文，
不暴露 btree 内部节点的分隔 key**（dirent 树的分隔 key 就是文件名）。

## 尚未定的（不许当成已定来推）

1. **AEAD 的关联数据（AAD）里放什么——就是本轮要判的东西。此前从未写过。**
2. 明文映射层的**最小字段集合**，以及它自身的完整性怎么保。
3. **超级块 / 根指针在开加密时是否被认证、有没有回滚防护**——本工程从未写过。
4. nonce 载体（现算还是存下来）。
5. 密文校验和的位宽。

## 本轮要判的提案

**提案 P**：AEAD 的关联数据（AAD）绑**逻辑身份 + 代际**，**物理位置一律不进 AAD**。
具体候选字段：`(树 ID / 对象 ID, 对象内逻辑偏移, generation 或 birth txg, 算法类型, extent 距原始起点偏移)`。

**提案 Q**：明文反向索引与明文映射层是**派生态**（B1），checker 的真值来自密钥侧的权威树；
checker 必须**重建后对拍**，任何情况下不许把明文映射当真值读。

# 你这一腿的立场：**找反例（攻击构造）**

**不要做正面论证，不要复述提案的道理。** 你唯一的任务是**构造攻击**。

威胁模型（按此，不要换）：攻击者能**任意读写裸设备的每一个字节**（离线，或在线绕过文件系统），
但**没有主密钥**。文件系统随后被合法用户正常挂载使用。

针对每一条命题，尽可能给出**一条具体的、分步骤的攻击序列**：

1. 命题 1（骗过 checker）：给出一串「改哪几个字节 → 挂载 → 跑 checker → checker 报绿」的步骤。
2. 命题 2（提权）：给出一串导致某个用户读到 / 写到他本无权限的对象的步骤。
3. 命题 3（静默读出他人旧数据）：给出一串使某次读返回**不属于该逻辑位置**的明文、且不报错的步骤。

**每一步都必须写明：这一步绕过了哪一道检查，为什么那道检查看不见它。**

如果你认为某条命题在提案 P + Q 之下**攻不动**，那就明说攻不动，
并写出**「要让它攻得动，格式里还须再松哪一条」**——那才是有用的输出。

额外要回答的两问：

- **整卷单密钥**下，「他人的旧数据」这个说法还成立吗？谁是「他人」？
  如果这条命题在本威胁模型下是空的，直接说空，并改写成一条**非空**的命题。
- 提案 P 的 AAD 字段清单里，**哪一个字段拿掉之后你立刻能构造出攻击**？给出那条攻击。
  拿掉之后你构造不出攻击的字段，也明说——那意味着它在为别的理由服务，不是为这三条命题。

输出用中文，结构化，直接给攻击序列，不要开场白。
