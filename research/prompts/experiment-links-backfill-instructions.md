# 实验页回填「影响的决策」表：共用步骤

仓在 /home/fy5090/code/singlefs（Rust COW 文件系统，kb 全中文）。你负责给派发点名的实验页写全「### 影响的决策」表，把它们从 `.claude/decision-links-pending` 里删掉。报告与回复用中文。

## 先读

1. 规则：`.claude/rules/format-evolution.md`「决策正文只写现状，依据写成指针；决策与实验双向登记」整节里**「实验页的『影响的决策』」**那一段（表的形状、四种关系、回看怎么写）。
2. 门禁：`.claude/gate.d/75-decision-experiment-links.sh` 的文件头（它判什么、报什么）。
3. 范例：`.claude/kb/experiments/96-混合架构的一致性.md` 末尾那张表（五行，四种关系齐了，回看理由写得具体）。

## 每页的步骤

1. **读这一页的正文**（「## 历史版本」与「### 影响的决策」之外的全部），列出它提到的每一条决策编号。`grep -oE 'D[0-9]+（[^）]*）' <页> | sort -u` 起个头，但**要读正文判**，不能只按 grep 的计数写。

2. **逐条判关系**，四选一：

   | 关系 | 什么时候写 |
   |---|---|
   | **支撑** | 这个实验的结果撑着那条分项的定案 |
   | **推翻** | 这个实验的结果推翻了那条分项原来的定案（那条分项因此改过） |
   | **备料** | 量的是那条决策将来要用的料，今天还没有哪条分项靠它定案 |
   | **不影响** | 正文只把它当输入、当背景、当出处引一句，判据与结论都不落在它上面 |

3. **写支撑 / 推翻之前，先查那条分项的依据段引没引这个实验**：`sed -n "/^#### 已定项 N/,/^#### /p" .claude/kb/decisions/<文件> | grep -A20 '^\*\*依据\*\*'`。
   - **引了** ⇒ 写支撑 / 推翻，分项号写准。
   - **没引** ⇒ 判它是不是真依据。是（那条定案确实压在这个实验的结果上）⇒ **把它补进那条分项的依据段**（一行，`E<号>（简称）：证明了什么`，实验页上已有的数不抄），并在 `.claude/kb/decisions-history/2026-09.md` 记一条；不是 ⇒ 关系改成备料或不影响。
   - ⚠️ 只写实验页这一边会让门禁 75 号判「双向不对称」，两边必须一起动。

4. **决策没有分项的**（D8、D16、D19 这三条今天可能还没瘦身，正在被别的 agent 改）：关系写到决策级 `D<n>（简称）`，不写分项号；那三条瘦身完之后由主 agent 统一回来补分项号。**它们的决策文件你一个字不动。**

5. **写表**，放在「## 历史版本」之前：

   ```markdown
   ### 影响的决策

   | 决策分项 | 关系 | 回看 |
   |---|---|---|
   | D3（空间分配） 已定项 5 | 支撑 | 2026-09-20 不受影响：<具体理由，说清为什么这次没改那条决策> |
   ```

   - 表里**至少一行**关系是支撑、推翻或备料（实验必须对应决策）。一行都写不出来的，看这一页正文里有没有「**备料**：」那一行——没有就补一行，点名它等着的决策或欠账。
   - 标题里写着「作废」「退役」的页不判这一条。
   - 回看写 `2026-09-20 不受影响：理由` 或 `2026-09-20 改了`（只有这次真改了那条决策才写「改了」）。
   - 回看格与理由里提到本页实验写 `E<号>（简称）`，不写「这个实验」「本实验」（doc-lint 会红）。
   - **插之前在同一条命令里再查一次这一页有没有「### 影响的决策」**——别的 agent 可能刚建了。已经有表的，只插你那几行（`replace-once.py` 以表头下的分隔行或某一行整行为锚），不重写整张表。

6. **页上发现现状句腐烂**（数与今天对不上、引了一句决策里没有的话）：能现查坐实的直接改，在 `.claude/kb/experiments-history.md` 的「## 历史版本」下加一条（标题 `### 2026-09-20（其N）：E<号>（简称） ……`，N 在写入的那一条命令里现查当日最大号 + 1，**中文序号**）；**实验的结论、判据、产物与跑前登记一个数都不动**。拿不准的列进报告。

7. **待回填清单** `.claude/decision-links-pending`：这一页写全了（正文提到的每条决策都有一行，且至少一行支撑 / 推翻 / 备料）就删掉那一行。只删不加。

8. **门禁**：跑 `.claude/gate.d/75-decision-experiment-links.sh`、`10-kb-rot.sh`、`26-number-name-sync.sh`、`25-kb-deictic.sh` 与 `bash .claude/scripts/doc-lint.sh "$PWD"`。红的是你这几页的修到绿；红的是别的 agent 或别的会话的，写进报告、不去改。

## 约束

- 只改你被点名的实验页、`.claude/kb/experiments-history.md`、`.claude/decision-links-pending`，以及第 3 步要补依据的那条决策分项（连同它的变更史条目）。**`.claude/kb/checks-owed.md` 不改**，要立的账列进报告。
- 实验页、实验变更史、待回填清单一律用 `python3 research/scripts/replace-once.py 文件 旧串 新串` 定点改，不许整份重写。⚠️ 传多行内容时别用 `$(cat 文件)`——命令替换吃掉末尾换行，会把下一行粘到你这段的行尾。
- 不提交、不暂存、不建分支；不用 `git checkout` / `git restore` / `git stash`。
- 长命令放后台（Bash 的 `run_in_background`），不写 sleep 轮询。

## 交付

**报告直接写在最后的回复里**：每页一行（页号、正文提到几条决策、表写了几行、四种关系各几行、有没有补决策依据、有没有改腐烂、移没移出清单、没移出的为什么）；末尾列要立的账、每道门禁的退出码。
