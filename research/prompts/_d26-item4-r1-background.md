## 三、E95 这一轮实际做了什么（主 agent 自陈，源码在 `research/e7-index-bench/src/bin/e95_node_layout_arms.rs`）

产物：`research/results/e95-node-layout-arms-2026-09-09.out`（86 行，确定性模型，四轮逐字节一致——
按 `.claude/singlefs-ai-sop/rules/test-discipline.md`，这只说明没有隐藏状态，不说明统计上稳定）。
18 单测 / 18 条变异全抓（`research/mutations/e95_node_layout_arms.tsv`）。

**等预算的口径（本轮定的，判据原文只写「额外写倍数取 1.5× / 3× / 5× 三档」）**：
每 checkpoint 允许的额外写数 = D × (X − 1)，四条臂逐轮花同一个数，花了多少报在 `budget_spent_pct` 里。
1.5 / 3 / 5 三档 ⇒ extra = 32 / 128 / 256，而 E93 的 bump_cp_b32 / b128 / b256 逐字报
write_amp = 1.500 / 3.000 / 5.000 ⇒ 政策臂那一格与 E93 入库产物是同一个东西。

**四条臂**：

| 臂 | 家族 | 机制 | knob |
|---|---|---|---|
| `pol_compact` | 政策 | E93 的 bump_compact(B)，B = 预算 | — |
| `pol_neighbor` | 政策 | E93 的 bump_neighbor，半径一圈圈加到预算花完 | — |
| `fmt_group_gN` | 格式 | 组是固定的 key 区间 [i·N, (i+1)·N)；组内任一对象脏 ⇒ 整组连续重落；预算有剩就按组轮转主动整落 | N ∈ {2, 8, 32} |
| `fmt_gensep_h1_h2` | 格式 | 按「自上次重写以来的 checkpoint 数」分三代，代不同不共用段；整理只挑现在住在热代里的对象 | (h1,h2) ∈ {(16,128),(64,512),(256,1024)} |

**跨装置闸**：本二进制抄了一份 E93 的模型，所以逐行复现了 E93 入库产物里的 14 个 aging_median
（first_fit 8186/7997、bump_seg 8186/7312、bump_nb_r1 5497/5181、bump_nb_r2 5460/5111、
bump_cp_b32 7502/6073、bump_cp_b128 6095/3922、bump_cp_b256 4791/1339），对不上判红。全部对上。

## 五、主 agent 自己已经看出来的三处，腿要判它们成不成立

⚠️ 这三处是**主 agent 的推论**，不是产物里的数。腿的任务包括判它们对不对。

1. **格式臂赢的那个机制，在这个模型里不需要任何格式位。**
   `fmt_group_gN` 的组是 `key / N` 算出来的，模型里 key 到对象是静态一一对应、没有节点分裂合并
   ⇒ 放置器不查任何盘上字段就知道组身份。E95 注册的臂逐字是「节点头带组身份（G 个 key 相邻的
   16 KiB 节点构成一个放置与重写单元）」——**按节点数分组**才需要存字段，**按 key 区间分组**不需要。
   ⇒ 这一轮量到的是「固定边界的整组重落 打赢 滑动窗口与轮转整理」，
   **不是**「节点头里那个组身份字段是必需的」。
2. **runs8 那一列的赢面可能被口径放大**：负载的重写段长逐字是 8，而赢得最多的臂是 `fmt_group_g8`。
   uniform 那一列格式臂只赢 1.15–1.40 倍，一格都没到两倍。
3. **判据 5 的措辞是「任一等预算格」**，而实际是「runs8 三格全中、uniform 三格全不中」。
   按字面判据 5 = 中；按「这条结论能不能拿去改决策」则要先答第 1、2 条。
