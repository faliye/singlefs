### 第一段要做的（入库装置，没有臂）

每个几何（S ∈ {4, 8, 16} × 池大小 G-min、G-1、G-4，第一节「读法写死」）上走同一条历史，空间准入开着（产品路径 `mount_writable`），用只存写过的块的设备（E181、E183 那一类做法，执行员照它们的设备包装写，不起几 GiB 的真文件）：

1. mkfs（这个 S），可写挂载（写行 + 暖机），顺序写一个 64 块（32 个数据单元）的文件；
2. 覆盖写 4 × 3S 次，每次一个数据单元（`UserChange::Overwrite`）；
3. 正常卸载（抬 F 那一串空发布）；
4. 再可写挂载，回到第 2 步；第 2–4 步共走 3 圈。

每一次核心层交回了 `TransactionOutput` 的发布记一行：发布种类（写行、暖机、顺序写、覆盖写、卸载那一串）、txg、发布之前那一版上核心层的 κ（`checkpoint_cost_of_the_version_to_build_on`）与本地照 D28 已定项 4 重算的 κ、这次新占的固定点两条路各逐盘的槽数、普通分配槽数。拿不到某一次发布的 `TransactionOutput`（公开入口只交回最后一次）的，那一次记「取不出」，不当 0；每个几何上空发布（暖机、卸载那一串）至少要有 6 次取得出，不够就那个几何作废（V6）。另记每块盘的单元区 [s, e)、分配记录树根层级、K1 那一项的本地值。附带（够判后不跑）：最后一次发布前准入读数里每块盘的环窗口与切换预留（X6）。

G-min 的找法：每个 S 上按 32、64、128、256、512 MiB（每块盘，两块等大）依次试，第 1–4 步三圈全部发成（没有一次被准入或落点拒）的第一个取作 G-min；512 MiB 也做不完的，那个 S 的 G-min 记「找不到」交回，不往上加。

### 第二段的两条臂（③要比的两种读法）

| 臂 | 怎么做 | 做完会怎样（由「怎么做」推出） |
|---|---|---|

支持各臂的人认的样子：代码读法——保留池只保证 checkpoint 自己的固定点写得出去（D28 已定项 4「射程」：`reserve ≥ ckpt_cost`，E19「预留恰等于 ckpt_cost 时 checkpoint 就不卡死」），κ 本身已是按整棵分配记录树取的最坏上界，常常装得下好几次真实的空发布；再乘 7 是拿用户的空间买一个按最坏上界算了七遍的余量（`df` 少报）。条款读法——推空与抬 F 那一串在近满时只能从保留池里出，一次准入最多推 B − 1 = 7 次，每次最坏按 c_max 算；只留一个 ckpt_cost，真实空发布的量一旦逼近上界，一串抬 F 都落不了点，准入就只能报 ENOSPC。

```python
# k1_positions.py
# 设计员算锚点用（独立于 crates 与装置）：D28 已定项 4「分配记录树这一项按 K1 算」的式子，
# 1 + Σ_盘 Σ_{L = 0 … 根层级 − 1}（⌊(e − 1) ÷ S_L⌋ − ⌊s ÷ S_L⌋ + 1），S_L = 812 × 169^L。
# 用法：python3 k1_positions.py <根层级> <s1>:<e1> [<s2>:<e2> …]；不带参数时算两组写死的例子。
import sys
def span(level): return 812 * 169 ** level
def k1(root_level, areas):
    assert root_level >= 1
    total = 1
    for s, e in areas:
        assert e > s
        for level in range(root_level):
            total += (e - 1) // span(level) - s // span(level) + 1
    return total
if len(sys.argv) > 1:
    root = int(sys.argv[1]); areas = [tuple(int(x) for x in a.split(':')) for a in sys.argv[2:]]
    print(f"root_level={root} areas={areas} k1={k1(root, areas)}")
else:
    print("two 4GiB [50176,262144) root2:", k1(2, [(50176, 262144)] * 2))
    for width in (240, 256, 384):
        print(f"two narrow [50176,{50176+width}) root1:", k1(1, [(50176, 50176 + width)] * 2))
```

# first_request.py
# 设计员算锚点用（独立于 crates 与装置）：原登记 anchors2.py 的 B5 那一格改成带参数（S、c、d、P），H1、近满 k = 0、不注读故障，
# 挂载之后第一次请求的前几步。参数取 S=4 c=5 d=8 P=45 时必须逐字复现原登记第七节 anchors2.py 的两行输出。
# 用法：python3 first_request.py <S> <c> <d> <P>
import sys
S, c, d, P = (int(x) for x in sys.argv[1:5])
L = 3 * S
dev = {0: 0, 1: 1, 2: 0}
last_O = 2 + 4 * L
N = last_O
row = N + 1
cov = {dev[row % 3]}; t = row; w = 0
while len(cov) < 2: t += 1; cov.add(dev[t % 3]); w += 1
cur = row + w
ring = list(range(cur - L + 1, cur + 1)); oldest = min(ring)
def rel(t): return d + c if 3 <= t <= last_O else c
pending = {t: rel(t) for t in range(oldest + 1, cur + 1)}
free = P + 0
print(f"N={N} row={row} warmup={w} ring=[{ring[0]},{ring[-1]}] oldest={oldest} pending_total={sum(pending.values())}")
newest_dev = {}
for t in ring: newest_dev[dev[t % 3]] = max(newest_dev.get(dev[t % 3], 0), t)
nonempty = [t for t in ring if 3 <= t <= last_O]
C = min(min(newest_dev.values()), sorted(nonempty)[-4])
seq = []; t = cur; cov = set()
while len(cov) < 2 and len(seq) < 3: t += 1; cov.add(dev[t % 3]); seq.append(t)
lowest_free_during_the_chain = free
landed = True
for s in seq:
    if free < c: landed = False; break
    free -= c
    lowest_free_during_the_chain = min(lowest_free_during_the_chain, free)
if not landed:
    print(f"ceiling={C} seq={seq} chain_lands=False free_before_chain={P} c={c}")
    sys.exit(0)
for s in seq: pending[s] = c
cur = seq[-1]; ring = list(range(cur - L + 1, cur + 1)); oldest = min(ring)
gate = max(C, oldest)
rec = sum(v for t, v in pending.items() if t <= gate)
free += rec
print(f"ceiling={C} seq={seq} F={C} gate={gate} reclaimed={rec} free_after={free} user_room=free-P={free-P} need={d+c}")
