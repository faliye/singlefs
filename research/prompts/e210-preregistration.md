### 读法（写死）

1. **「段」的两个意思**：岔路单行 1 的「试了几段（分母）」的「段」读作「一条历史」（下文历史元组）；D13（验证路线） 已定项 4 崩溃点重放的「段」下文一律写「持久段」。
2. **池与表**：两块盘（设备身份 0、1），每盘恒 2 个系统配置槽（D22（单元原子性怎么合成） 已定项 16）。盘大小与容量表都以整槽计（16 KiB 一槽，`crates/singlefs-format/src/lib.rs:14` 的 `SLOT_BYTES` = 16384）；容量表 = 按设备身份排的两项，每盘一项（定乙，记录 `records/2026-11-17-里程碑四收口续做.md` 批 3 那一行写的「每项 8 字节整槽数」）。装置里一个槽的内容只有两种：**无效**（撕裂或全零，不自证）、**有效**（槽世代号、表、意图标记）；读者只认自证过的槽。表之外的字段（实例代号、tail、F）不进任何读者规则，装置不带。
3. **盘面与探测值**：盘面 = 两块盘各两槽的内容；探测值 `s` = 用户动作之后每块盘的整槽数。「每块盘至少一个有效槽」是模型的前提（同一盘同一持久段至多写一槽，一次断电至多撕那一槽；换盘换进来的镜像两槽都有效），装置对每个盘面断言它，不成立记「出模型」并计数（预期 0）。
4. **历史** = （族，形状，已用落点点位，断电点，用户动作，之后挂载的种类）的一个元组，每一维写死如下。
   - **族 D（主格）**：池 mkfs 在早尺寸，变大到前尺寸并写入过（前尺寸里每盘写到盘尾），用户又把盘变大到后尺寸，**这一次**变大的可写挂载取号写途中断电。变大前的盘面：两盘各两槽都有效、都装前表（`T_前`）。
   - **族 S（几何敏感性方向相反的一点）**：池 mkfs 在早尺寸（= 前尺寸）从没变大过，变大到后尺寸，取号写途中断电；变大前盘面两盘各两槽都装 `T_前`（= `T_早`）。
   - **形状**（整槽数，两项依设备身份 0、1；表项就是该尺寸的整槽数）：D-同变：早 (100, 100)，前 (200, 200)，后 (300, 300)；D-单变：早 (100, 100)，前 (200, 200)，后 (300, 200)；D-交叉：早 (100, 100)，前 (200, 100)，后 (200, 300)；S-同变：早 = 前 = (100, 100)，后 (200, 200)；S-单变：早 = 前 = (100, 100)，后 (200, 100)。数值取小整数是因为读者规则只比大小次序；根层级边界另在第 3 行那一组量里用真实槽数算。
   - **已用落点上界 `L`**（每盘一个整槽数，「有单元的落点越过盘尾」的单元落点就是它）：点位「满」：`L` = 前尺寸（池写到变大前那份记录的盘尾），例外是断电点「终点已用」（见下）取 `L` = 后尺寸；点位「少」（只在族 D）：`L` = 早尺寸（单元只在最早那一段）。族 S 里前 = 早，点位「少」与「满」同值，只取一个。
   - **断电点**：按臂的写序（第五节：四写序 = 取号写两轮；六写序 = 标记轮加取号写两轮）生成写表与屏障，按 D13（验证路线） 已定项 4 切持久段：池屏障 = 每块盘各一道屏障，两块盘的屏障都放行才关段，同一块盘上前面没有写的屏障不记；一个崩溃状态 = 前面各持久段全持久、当前持久段里每次写各取「没持久 / 持久 / 新旧都读不出」三态之一（系统配置槽写是原地覆写、长于一个扇区，该项点名它取第三态；槽 4096 字节，`crates/singlefs-format/src/lib.rs:286`）、之后各持久段全没持久。「新旧都读不出」= 那一槽无效，旧内容也没了。原始状态数 = 各持久段 3^(本段写数) 之和：四写序 9 + 9 = 18，六写序 9 + 9 + 9 = 27；此外加一个点「终点已用」：全部写与屏障都完成、变大做成、之后的发布已把单元写进新增的盘区（`L` = 后尺寸）。盘面相同的状态不去重（去重后是 17 与 25，只作附带数）。
   - **槽世代号奇偶**：变大前每盘两槽的世代号决定取号写落哪一槽（`transaction.rs:686`–`:694` 取世代号 = 本盘自证槽最大世代号 + 1，`:742` 槽 = 世代号 mod 2）。主格取每盘「世代号最大的槽在槽 1」（槽 0 世代号 2、槽 1 世代号 3）；另三个组合（两盘都在槽 0、盘 0 在槽 0 盘 1 在槽 1、反过来）只在几何敏感性里重跑。读者规则不看槽号与世代号，所以预期四个组合的全部计数逐项相同（第八节核这个预期，不同则装置作废）。
   - **用户动作**（五类，D 族十一个变体、S 族七个变体；动作之后盘大小 = 探测值 `s`）：
     1. 不动：`s` = 后尺寸。
     2. 缩回：缩全部盘到前尺寸；只缩盘 0 到前尺寸；缩全部盘到早尺寸；只缩盘 0 到早尺寸（S 族前 = 早，只取到早尺寸的两个）。已在目标尺寸的盘不动，两个变体同值时不去重（分母按元组数）。
     3. 再变大：每盘各加 100 整槽；只盘 0 加 100。
     4. 把一块盘换回变大之前的整盘镜像（「早镜像」）：盘 j（j = 0、1）整盘换成该盘在早尺寸时的镜像：两槽都有效、都装 `T_早`，盘大小 = 早尺寸 j 项；`L` 不变（单元的落点是版本的性质，不随镜像回退）。
     5. 把一块盘换回变大并写入之后的整盘镜像（「前镜像」，只在族 D）：盘 j 整盘换成该盘在前尺寸写入之后的镜像：两槽都有效、都装 `T_前`，盘大小 = 前尺寸 j 项。族 S 没有这一种。
     岔路单行 1 写的「变大之前」「变大并写入之后」是相对池里更早的那一次变大说的：只有族 D 里存在「变大并写入之后、本次变大之前」的时点，所以本格用族 D 实现这两种镜像（第一节末「未定项」第 4 条）。
   - **之后挂载**：可写、只读各一次（同一元组两种，分母各算）。挂载只判「放行或拒、点名哪几块盘」，不模拟它之后的写。
5. **每个盘面的读法（所有臂共用外壳）**：臂按有效槽的表给出生效表 `E`、与探测值比的表 `Q`（可能 ≠ `E`）和例外；`D` = {盘 i：`s_i` < `Q_i`}（变小的盘）。可写挂载：`D` 空则做成（若有盘 `s_i` > `E_i` 则这次做成的挂载走变大的写序），`D` 非空则拒（D12（目标介质） 已定项 4：设备容量变小 ⇒ 拒绝，变大 ⇒ 放行并记；用户定案「容量变小时只读挂载放行并点名该盘，可写拒」见记录 `records/2026-11-17-里程碑四收口续做.md` 批 3 的用户定案那一条）；只读挂载做成并点名 `D`。臂另有规定的（甲的整池拒、丁的放弃）写在第五节。
6. **判定谓词（可机判，写死）**。对一条历史 `h`（`L` 与探测值 `s` 都是 `h` 的性质）：
   - `越界(h)` = {盘 i：`L_i` > `s_i`}（有单元的落点越过这块盘此刻的盘尾；严格大于，落点正好在盘尾的整槽内不算越界）。
   - **漏放行（可写）**：可写挂载做成 ∧ `越界(h)` ≠ 空。**漏放行（只读）**：只读挂载做成 ∧ （`越界(h)` ∖ 点名集）≠ 空。
   - **误拒（字面读法）**：可写挂载被拒 ∧ `越界(h)` = 空。「永久」的判法：拒不写盘，决定只依赖（盘面，探测值），所以同一盘面同一探测值下每次重挂都同一结局；用户改盘大小或换盘是另一条历史。
   - **观测类**：键 = （盘面的规范形：每块盘两槽内容的无序对，槽内容取（无效 / 表加意图标记），不含世代号与槽号；探测值）。同一条臂的写序生成的全部历史按键分类（含族 D、族 S、全部形状与点位）。**必点名集** `N*(键)` = 该类里全部历史的 `越界` 的并集。
   - **误拒（可避免读法）**：可写挂载被拒 ∧ `N*(键(h))` = 空，即这一类里没有任何一条历史越界，换一条读者规则（见按类判官臂）本可以放行。可避免读法回答的是「臂拒掉的多出了多少」；字面读法照岔路单原文。两读法都报、各占一行，判据都写死在第六节。
7. **分母**：每条臂、每种挂载的元组数（第六节给闭式；四写序可写 1487 条、六写序可写 2207 条，只读同数，闭式与算式在第四节）。
8. **确定性**：整个模型没有随机源、时钟与并发，是确定性计数；`test-discipline.md`「单次观测不算数」那条在这里的写法：同一份装置跑两次，标准输出逐字节相同，证据强度靠第七节的钉死数与第九节的变异，不靠轮数。

## 八、轨迹与几何敏感性

### 被谓词消费的量与轨迹（`test-discipline.md`「端点不是轨迹」）

读者规则里被谓词消费的量有两个：生效表 `E` 与比探测值的表 `Q`（`D` = {`s_i` < `Q_i`} 决定可写拒不拒、只读点谁），以及判官臂消费的必点名集 `N*`。它们沿写序的轨迹报成：对每条臂、每个读数（漏放行、字面误拒、可避免误拒、可写被拒），按断电点序号逐点各报一个计数（序号 0 = 没有任何写持久；四写序 18 + 1 个点，六写序 27 + 1 个点，次序 = 持久段先后、段内按三态的字典序，「终点已用」排在最后）。每个读数连报三样：

- **峰值**：各断电点计数的最大值，及它在哪个断电点；
- **为正的断电点个数**：计数大于 0 的断电点有几个、占几个；
- **期末值**：终点已用那一点的计数，与最后一持久段全持久那一点的计数（两者都报）。

只报期末值或只报合计的不写「从来」「恒」「任何时候」；正文要写这类词，需要为正个数 = 0（「在本历史空间的每个断电点上都没有」）或 = 全部断电点。

### 几何敏感性（`mutation-sampling.md` 第六类；判据一行一个）

主格 = 并集（两族、五个形状、两个点位、主格奇偶、全部动作与挂载）。每条臂的每个存在性判断（漏放行可写、漏放行只读、字面误拒、可避免误拒，各「读数 ≥ 1」）在下面这些取样点上各重判一遍，每点单独算分母：

| 取样点 | 与主格的方向关系 | 怎么取 |
|---|---|---|
| 族 D 单独 | 子格 | 只取族 D 的元组 |
| 族 S 单独 | **方向相反**：没有「变大并写入」的历史，没有前镜像动作，每盘只一次变大，前表 = 早表 | 只取族 S 的元组；类仍按并集分（`N*` 取并集里的类） |
| 五个形状各自 | 子格；D-单变、S-单变是「只一块盘变大」，与「两盘同变」方向相反 | 各形状单独 |
| 点位「满」与「少」各自 | 「少」是单元只在最早那一段（`L` 小）：方向相反 | 各点位单独 |
| 槽世代号奇偶四个组合 | 读者规则不看槽号世代号，**预期全部计数逐项相同**；不同说明模型把槽号带进了判定 | 四个组合各跑主格，逐项比；不同 ⇒ 装置作废（第十节） |
| 尺寸取另一组整数 | 读者规则只比大小；换一组保持每项大小次序的整数（早 (10, 90)、前 (20, 95)、后 (30, 99)；「再变大」每盘各加 100 的数不变），**预期计数逐项相同**；不同 ⇒ 装置作废 | 五个形状各按各自的次序换数 |

判法：同一条存在性判断在各取样点上的真值（读数 ≥ 1 与否）相同，记「稳定」，并写出它的真值；不同记「不稳定」，列出成立的点。**岔路单行 1 的状态更新只写「在哪些取样点上成立」，不写成该条臂的一般性质**。子格上读数为 0 而主格 ≥ 1 是预期会发生的（子格少了触发它的动作），也照报，不当翻面而当「触发它的动作在哪个子格」。

**判别力自证**：对每条臂每个存在性判断，取主格与族 S（或另一个读数不同的点）两点的读数 `c_大`、`c_小`（`c_大 > c_小` 才取），把门槛 `t` 挪到两点之间（`c_小 < t ≤ c_大`），检查「读数 ≥ t」必须在大点上绿、在小点上红（由绿转红）；`c_大 = c_小` 的臂这一项写「两点同值，无从自证」，不当通过。自证用的两点读数与 `t` 一并打印。

## 十、失败条款

每条紧跟「什么观测会让它触发」。分三类：**作废**（装置或谓词有错，这一轮的读数不当结果）、**条款可能错**（装置照条款字面建、读到的与条款字面不符，不作废、如实记）、**正当结果**（量出来就是这样，记下来，不当装置有问题；`test-discipline.md`「实验的失败条款不许让结论不可证伪」）。

1. **阳性对照不过 ⇒ 作废**。触发：在任一条臂的历史集上，放行一切臂的漏放行读数为 0，或一律拒臂的字面误拒读数或可避免误拒读数为 0。（装置分不出「该放的放了、该拒的拒了」的差别。）
2. **阴性对照不过 ⇒ 作废**。触发：按类判官臂在任一条臂的历史集上漏放行读数或可避免误拒读数不是 0。（谓词或类的算法有错。）
3. **臂不是观测的函数 ⇒ 作废**。触发：任一条臂（含三个对照读者）在任一观测类里，两条元组的（可写结局，只读点名集）不同。
4. **奇偶组合与换整数敏感 ⇒ 作废**。触发：第八节里槽世代号奇偶的四个组合，或另一组保序整数的五个形状，任一读数与主格不同。（读者规则不看槽号世代号与数值，只比大小次序；读数变了说明模型把它们带进了判定。）
5. **字面与可避免读数在每条臂上都相同 ⇒ 作废**。触发：每条臂的「字面误拒读数 − 可避免误拒读数」都是 0。（可避免谓词退化成字面谓词，类的算法没生效。）
6. **出模型 ⇒ 作废**。触发：任一历史里某块盘一个有效槽都没有（读法第 3 条的前提不成立），出模型计数 > 0。
7. **独立算出的数不符 ⇒ 作废**。触发：第七节第二张表任一行，装置读数与 `python3` 草稿算的数不等（层级跨度、边界、取样点、状态数、元组数、乙的变体）。
8. **条款钉死数不符 ⇒ 条款可能错，不作废**。触发：第七节第一张表任一行，装置按条款字面建的写序读到的数与条款句不同（例：四写序数出 5 次槽写，或每盘不是 2 槽）。处置：这一行的读数照报并标「与条款字面不符」，不改装置去迁就，交主 agent 判是条款错还是装置没按字面建。
9. **手推结局被推翻 ⇒ 先查装置，查完不改判据**。触发：第四节第 8 至 13 条里任一条的见证历史，装置读数与手推不同（例：甲在「换回早镜像」上漏放行读数为 0）。处置三步：打印那条历史的盘面、探测值与各臂决定；手算一遍；与装置不一致则装置有错、作废；一致则手推错了，记「手推被推翻」，读数照报。**要是量出相反的数，结论就按量出的写**（跑之前就写下的接受方式）：甲没有漏放行就写「本历史空间里甲没有漏放行（带分母）」，乙有漏放行就写乙在行 1 上出局，不为迁就第四节的手推改臂、判据或形状。
10. **基线臂没测出差异 ⇒ 正当结果**。触发：基线臂的漏放行读数与可避免误拒读数都是 0。记「现条款在这组历史上不多拒、不漏放」，行 1 照比；不当装置有问题。（对照已过的前提下。）

`states.py`：

```python
import itertools
def protocol(kind, parity):
    # start board per disk: slots [ (gen,table,mark) , ...], table 'O'
    # parity p: gens of slot0,slot1
    start=[]
    for p in parity:
        start.append([(4,'O',0),(3,'O',0)] if p==0 else [(2,'O',0),(3,'O',0)])
    rounds = [('M','O',1),('N','N',0),('N','N',0)] if kind=='p6' else [('N','N',0),('N','N',0)]
    # returns list of segments; each segment: list of writes (disk, slot, newcontent)
    board=[list(d) for d in start]
    segs=[]
    for (_,tab,mark) in rounds:
        seg=[]
        for d in range(2):
            g=max(s[0] for s in board[d] if s is not None)+1
            slot=g%2
            content=(g,tab,mark)
            seg.append((d,slot,content,board[d][slot]))
            board[d][slot]=content
        segs.append(seg)
    return start,segs
def states(kind,parity):
    start,segs=protocol(kind,parity)
    out=[]
    board=[list(d) for d in start]
    for si,seg in enumerate(segs):
        for outcome in itertools.product(('absent','done','torn'),repeat=len(seg)):
            b=[list(d) for d in board]
            for (d,slot,content,old),o in zip(seg,outcome):
                if o=='done': b[d][slot]=content
                elif o=='torn': b[d][slot]=None
            out.append((si,outcome,b))
        for (d,slot,content,old) in seg: board[d][slot]=content
    return out,board
for kind in ('p4','p6'):
    for parity in [(1,1),(0,0),(0,1),(1,0)]:
        out,fin=states(kind,parity)
        canon=set()
        for si,o,b in out:
            canon.add(tuple(tuple(sorted(( (s[1],s[2]) if s else ('X',0)) for s in d)) for d in b))
        print(kind,parity,"raw",len(out),"distinct boards",len(canon))
```

## 十四、并行与挂钟

- 独立单位：五条臂（甲、乙、丙、丁、基线臂）各自的历史集互相独立（臂按各自写序生成历史，四写序的四条臂共用同一份历史集的状态枚举也可以各算各的）；每条臂的三个对照读者各自独立；第八节每个取样点（族、形状、点位、奇偶组合、另一组整数）互相独立；行 3 的每个取样点互相独立；变异表每一条互相独立（各自一份副本、各自编译）。
- 线程：取登记值 `.claude/heavy-thread-default`（读到 31，用户定每台默认重活线程数）；装置主跑一个进程内按臂切片并行（臂 5 条 × 对照 3 条，合并按臂序相加，输出逐字节确定），变异与编译由任务服务按这个线程数分，命令里不写线程与内存参数。
- 串行：每条臂里「先把全部历史的观测类建完、再算必点名集 `N*`、再判可避免误拒与判官」这三步有先后（类要全集才能算），所以一条臂内部串行、臂与臂之间并行；写序生成器要先于历史枚举；变异要等装置与自证绿之后才起。没有靠计时或共享状态才成立的串行。
- 预计挂钟：第一段写序、层级算式、钉死数，编译一次加跑秒级，估 5 分钟内（推的：编译一个 Rust 目标，没量；三份草稿算术脚本各在一秒内出结果，量的）；第二段 2974 条 × 10 微秒 ≈ 0.03 秒，4414 条 × 10 微秒 ≈ 0.05 秒，加编译 5 分钟内（单态耗时 10 微秒是推的、没量，一条元组只做几十次比较与一次哈希查表）；第三段几何敏感性十来个取样点各重跑第二段，估 5 分钟内；变异 23 条 × 90 秒 ÷ 31 ≈ 1 分钟（每条一次增量编译加一次跑估 90 秒，推的、没量，最多 31 线程并行），串行最坏 23 条 × 90 秒 ≈ 35 分钟。全部加起来远不到 2 小时，不分片、不设续跑入口之外的专门机制：续跑入口就是同一条 `replay.sh` 命令重起，按行键只补没做完的行。
- 预计在用核数：第一段与第二段各 1 核（单进程计算）加编译时最多 31 个线程（编译由服务按登记值给）；第三段取样点重跑 1 核；变异最多同时 31 个编译、按服务分的内存额度排；峰值内存估几十 MiB 到几百 MiB 的跑加一次编译（推的，没量；元组与类表都在千条量级，装置不存盘面全文，只存规范形键与计数）。
