## 二、共用前提：挂着回退之后，扫盘重建选到被回退掉的那一版

攻方在副本上量到（`research/prompts/m3-tomb-r1-opus-model/run-e-lines.txt`，复跑逐字相同）：

```
E name=inode_leaf_versions identity(tree,container,birth)=(12, 1, 3) published_versions(birth,inst,txn,slot,inode1(size,nlink))=[(3, 1, 1, 50242, Some((3000, 1))), (4, 1, 2, 50254, Some((4100, 1))), (5, 1, 3, 50266, Some((2500, 1)))] p3_newest_birth=5 p3_newest_is_referenced_by_d=false d_references_birth=Some(3)
```

A（txg 3）→ B、C 覆盖写（4、5）→ 挂着回退到 A（D，txg 6）之后，同一个 inode 叶身份在盘上有三版，都过已发布谓词（同实例、诞生代号 ≤ 6），按择新键选中的是 C 那一版（诞生代号 5），D 引用的是 A 那一版（3）；数据单元同形（同一份产物 `E name=data_unit_versions` 行）。

主 agent 现查条款：管理员回退「不新增实例、不取号、不写实例表行、不施加也不删除任何记录」（`.claude/kb/decisions/23-journal的角色与格式.md:376`）；D23 已定项 14 的依据写「它的另一半「不写回退行时被回退抛弃的单元在全规则臂上复活」撑的是回退行，回退行删了，那一半不再承重」（`.claude/kb/decisions/23-journal的角色与格式.md:417`）。删回退行的依据（`.claude/kb/decisions-history.md:8036`）是回退实例永远不给自己写回退行、截断走不到这些结构事实，没有回答扫描重建怎么认「挂载根是一次回退」。所以 D23:417 那一句被打穿：回退行删掉之后，被回退掉的单元在全规则下照样被选中，只是没有条款再管它。I-1.9（清扫水位内无可读垃圾） 第二句「其外的可读垃圾每个 key 都被更大写序的可见版本或可见墓碑压住」（`.claude/kb/invariants.md:32`）在这张合法镜像上不成立（I-1.9 今天未实现，checker 不判）。

判：**成立，不分辨墓碑的臂**（不写墓碑也一样错；inode 叶、extent、数据单元同中）。正推腿也独立写到「这个洞不是墓碑独有」（它的报告 6.3 节末段）。照「打中不分辨臂」另立一笔账：扫盘重建对挂着时的回退没有输入。扫盘重建不在里程碑三的出口里（`.claude/kb/milestone/03-third-txn.md:23`），这一笔要不要在这一版修，与 W5 选哪条臂绑在一起（第三节 W5 行），交用户。
