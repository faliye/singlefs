## 记账是事务的副产品，不是事后的遍历

**线划在「谁消费这个数」，不划在「用什么机制算出来」。**

| 消费者 | 允不允许遍历 | 为什么 |
|---|---|---|
| **运行时决策路径**（分配、ENOSPC 准入、defer 窗口、生命周期判定） | **不许**，且代价不许随盘容量增长 | 不是慢，是**在被问到的那一刻没有答案**。准入控制要「进门前先算最坏情况」，而「释放空间这个操作本身不需要申请空间」也压在同一个数上 |
| **checker / 审计** | **必须**遍历 | 若运行时也用遍历算，checker 的遍历与运行时就是**同一次计算**，对照关系当场归零 |
| **后台、可续做、非决策路径**（销毁快照、整理、scrub） | **无戒律** | 它们走「写意图 → 分批 → 可续做」，不参与任何即时判定 |

**空间统计与配额落在第一格**：必须在事务提交时增量维护出来。

⚠️ **一个量落不落在第一格，按这一格自己的判据判：「被问到那一刻有没有答案」，不按名词清单判。**
「快照用量」就是这样判出第一格的：没有任何运行时判定读「每树独占 / 每树共享字节」，
那两个统计量因此撤回、第一版不提供每快照用量——普查、依据与将来做 per-snapshot 配额时怎么办，
权威记录在 `.claude/kb/decisions/05-快照-空间记账机制.md` D5（快照 / 空间记账机制） 已定项索引表第 8 行。

⚠️ **被禁止的不是「遍历」，是两件事**：
「在需要答案的那一刻还没有答案」，以及「审计与被审计用同一段代码」。
第二条不依赖任何关于性能的假设——它要求的恰恰是**运行时与 checker 必须用不同的算法**。

⚠️ **别拿第一格的禁令去否第三格的设计。** 本工程已经在第二、三格豁免过三次：
checker 的全盘遍历、无界删除的意图分批、代际增量 scrub。
**一条被三次豁免的规则，它的判据就不在它字面写的那个量上。**

## 五、臂、阳性对照、真实基线

装置是一个**确定性计数模型**：没有真实 I/O、并发、时序与随机源，跑 N 遍给的信息与跑 1 遍一样多；证据强度来自第七节钉绝对值的断言与第九节的变异，不来自轮数。模型建在 `research/` 下，**不与 `crates/` 共用代码**（`.claude/rules/implementation-first.md` 第 4 条）；与实现对不上时走第十一节停机条款 S1。

### 历史族、几何格与支线

记号：N = 3S；「工作负载段 L 次」= 连续 L 次发布，段内第 k 次（k 从 0 起）是 O ⟺ k mod m = 0，m 由几何格的 ρ 给（ρ = 1 ⇒ m = 1，ρ = 1/4 ⇒ m = 4）；每次挂载、切换、回退暖机之后 k 从 0 重新数。每族主历史都从 mkfs、首次挂载暖机（txg 1、2）开始，第一个工作负载段从 txg 3 起。

| 族 | 主历史（首次挂载暖机之后） |
|---|---|
| H1 | 工作负载段 6N 次 |
| H2 | 工作负载段 3N 次 → 普通挂载（恢复、W、暖机）→ 工作负载段 3N 次 |

## 八、轨迹与几何敏感性

### 轨迹

被谓词消费、或问题要轨迹的量都报轨迹，不只报期末值：

| 量 | 谁消费它 | 报什么 |
|---|---|---|
| Q5 多扣（D0） | 问题第二问；可再分配谓词的后果 | 每个 (臂, 族, 格)：主历史的峰值、「首次转满环（第 0 代根的槽被覆写，txg ≥ N）之后」的峰值、为正的发布数、期末值；支线汇总：峰值的最大值、为正的发布数之和、期末值不为 0 的支线条数 |
| Q6 隔离槽数（D0） | D28（挂载期承诺量） 已定项 1 第九项「被抛弃根独占量」进准入不等式 | 同 Q5 的七个数；另报每次回退之后第一次为 0 的那次发布离回退隔了几次发布 |
| Q11 环里最旧有效根的滞后 | 甲-T1 与基线的回收门槛 | 同 Q5 的七个数，另报「滞后 ≥ N」的发布数 |
| F_生效 与最新根带的 F | 回收门槛、候选集 | 原始产物里逐发布写出；汇总只报 Q12 |

- 原始产物里逐发布写一行（臂、族、格、支线、txg、实例、发布种类、多扣、隔离、滞后、F、F_生效、D0 第 1 / 2 / 5 项、候选引用并集、违例数），汇总从这份逐行产物现算，不另存一份手算的表。
- 期末值为 0 与「从来不为正」是两句话：只有为正的发布数也是 0 时，正文才许写「从来」「恒」这类说轨迹的词（`.claude/singlefs-ai-sop/rules/test-discipline.md`「端点不是轨迹」）。
- 「首次转满环之后」的峰值单列，是因为转满之前第 0 代根一直是最旧有效根，甲-T1 与基线在那一段按定义什么都不回收——那一段是初始供给，不是稳态。
