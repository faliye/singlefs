#### 已定项 14：一套 btree 实现 + 多个独立 keyspace + 两个前端，派生树可以异构

**定案**：**一套 btree 实现 + 多个独立 keyspace + 两个前端，管权威态的树与照分裂做的树；派生态的分配记录树与 extent 树（D21（权威态与派生态的分界） 已定项 5、9）可以另起按 key 空间寻址的结构，格式可以与码 2 btree 不同。**

| 层 | 做什么 |
|---|---|
| 独立 keyspace | 每类数据一棵树（extent / inode / dirent / 反向索引 / 空闲空间 / 记账 …），互不干扰 |
| 日志结构节点 | 节点内新 key 追加不插入，内存里定期重排；写顺序、可在只读锁下回写 |
| **write buffer** 前端 | 高频小更新（反向索引、LRU、记账）批量攒起来排序去重后批量插入 |
| **key cache** 前端 | 同一批 key 反复读写的（分配信息）走哈希表，不做全树查找 |

**两棵派生树的结构**：

- **分配记录树**：按绝对槽号按位置寻址。每片叶罩一段固定的槽 `[k × W, (k + 1) × W)`，W 取偶数（两槽数据单元永远不跨叶），且 W ≤ 叶条目容量 812（一条记录至少罩一个槽，叶永远装得下）；记录按起点槽落叶。往上各层按位置寻址，子节点罩哪一段由它在父节点里的位置算出。**没有记录的一段 = 全空闲**：那片叶不写，父节点那一格留空（用户 K1）。checker 逐节点核「这个节点罩的就是它的位置规定的那一段」与「记录的末槽不越过它所在叶的末槽」。
- **extent 树**：两段，都按位置寻址。上段按 inode 号的位置寻址；下段一个文件一棵，按数据单元号的位置寻址（叶罩 144 个单元，内部扇出 147），洞就是缺席。**只有一个数据单元的文件不建下段**：上段叶条目里直接放那个数据指针；条目带一个标签字节区分「没有单元 / 下段根指针 / 内联数据指针」（用户 K2）。
- **挂载怎么读**：分配记录树挂载时整棵读进挂载态（分配器本来就要）；extent 树按需，打开文件时按位置走下去（用户 K4）。

def slots_of(device_bytes):
    return device_bytes // SLOT


def root_level(per_device_slots):
    level = 1
    while sum(-(-slots // (W * FANOUT ** (level - 1))) for slots in per_device_slots) > FANOUT:

    return level

def segments_of(stream, fua_is_boundary):
    writes, segments, current = [], [], []
    for item in stream:
        if item == "B":
            if current:
                segments.append(current)
            current = []
            continue
        if fua_is_boundary and item[1] == "root":        # D13 已定项 4：FUA 写自成一段
            if current:
                segments.append(current)
            segments.append([len(writes)])
            writes.append(item)
            current = []
            continue
        current.append(len(writes))
        writes.append(item)
    if current:
        segments.append(current)
    return writes, segments


def closed_form(segments):
    return 1 + sum((1 << len(s)) - 1 for s in segments)


def states(segments, skip_segment=None):
    """D13 已定项 4 的枚举域：前若干段全持久、当前段任一非满子集、之后全不持久；最后加全部持久一个。"""
    before = set()
    for index, segment in enumerate(segments):
        if index != skip_segment:
            for size in range(len(segment)):
                for subset in combinations(segment, size):
                    yield index, before | set(subset)
        before |= set(segment)
    yield len(segments), before


def predict(writes, persisted, units, reading_identity_changes):
    """逐态预言：只看写的种类与持久掩码。返回 (类, 所选根 txg, 施加后的有效 txg, 查 journal 与不查是否不同)。"""
    def unit_ok(name):   # 至少一份持久（两盘时）；一盘时就是那一份
        return any(i in persisted for i, w in enumerate(writes) if w[1] == "unit" and w[2] == name)
    def record_ok(txg):
        return any(i in persisted for i, w in enumerate(writes) if w[1] == "journal" and w[2] == txg)
    roots = [w[2] for i, w in enumerate(writes) if w[1] == "root" and i in persisted]
    selected = max(roots, default=0)                       # 0 = mkfs 的根
    newest = max(w[2] for w in writes if w[1] == "root")
    effective = selected
    for txg in sorted({w[2] for w in writes if w[1] == "journal"}):
        if txg <= selected:
            continue                                        # D23 已定项 14：严格大于所选根才施加
        if not record_ok(txg):
            break                                           # 断号即止
        named = units if txg == newest else []              # 空发布的记录不点名单元
        if not all(unit_ok(u) for u in named):
            break                                           # D16 已定项 7：验证点名单元不过就不施加
        effective = txg
    has_file = effective == newest
    if selected == newest and not all(unit_ok(u) for u in units):
        return "violation", selected, effective, False
    differs = has_file != (selected == newest) or (reading_identity_changes and effective != selected)
    return ("legal_file_read" if has_file else "legal_no_file"), selected, effective, differs


def tally(stream, units, fua_is_boundary, skip_segment=None):
    writes, segments = segments_of(stream, fua_is_boundary)
    newest_root = max(i for i, w in enumerate(writes) if w[1] == "root")
    out = {"segments": [len(s) for s in segments], "closed_form": closed_form(segments), "states": 0, "root_persisted": 0,
           "violation": 0, "legal_file_read": 0, "legal_no_file": 0, "differ_J_jia": 0, "differ_J_yi": 0}
    for _, persisted in states(segments, skip_segment):
        cls, _, _, differs = predict(writes, persisted, units, False)
        _, _, _, differs_yi = predict(writes, persisted, units, True)
        out["states"] += 1
        out["root_persisted"] += newest_root in persisted
        out[cls] += 1
        out["differ_J_jia"] += differs
        out["differ_J_yi"] += differs_yi
    return out, writes, segments
