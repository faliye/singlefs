# 变异表

**每个实验二进制一张表。** `research/scripts/mutate.sh <bin 名> <源文件> <本目录下的表>`
逐条注入一个已知破坏、跑该 bin 的单测、记下红了哪几个、然后还原。

表的格式：每行三段，**制表符**分隔——`变异名 <TAB> 原文 <TAB> 替换文`。
替换必须**恰好命中一次**，命中 0 次或多次直接报错退出：
静默失效的替换会让整份「证明会红」变成假的
（`.claude/singlefs-ai-sop/rules/command-safety.md`「脚本改文件之后要回读确认」）。

## 为什么要存下来

`.claude/kb/experiments/` 里多处写着「N 个单测，M 条变异全部被抓」，
而在 2026-08-29 之前**这些表一张都没存过**——`mutate.sh` 在，它要的第三个参数不在。
⇒ 那些「M 条变异全部被抓」的句子当时**一条都复现不了**。

这与 `.claude/kb/checks-owed.md` C38（外部文献不可复核）是同一个失败模式：
**结论留下了，产生结论的那个装置没留下。**
而 `.claude/singlefs-ai-sop/rules/show-me-test.md` 要求的恰恰是这一步——
「不能证明会红的测试等于没写」。**证明本身也要能被第二个人重跑。**
