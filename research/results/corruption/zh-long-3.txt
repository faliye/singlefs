**无法攻击。**  
在提案 P + Q 下，块级重排无法 MAC 失配，checker 无法检测检测到错误。

### 命题 2：块级重排无法导致提权

在提案 P + Q 下，任何提级重排无法导致提权（读取或写入无权限对象），因为 MAC 失配。  
- **依赖条款**：A1、A3、A8、提案 P、B6（checker 重建权威树，运行时判定路径路径不许历）、B2（数据块零自描述，但 MAC 验证仍内容容）。

### 命题 3：块级重排无法静默读出他人的旧数据  
**无法攻击。**  
在提案 P + Q 下，静默读出他人旧数据（其他其他文件或历史版本数据）不可能，因为 MAC 失配。  
- **依赖条款**：A1、A3、A8、提案 P（AAD 含树 ID / 对象 ID、birth txg）、B6、B5（生命周期靠 birth txg + deadlist）。  
- **原因**：  
数据有不同 birth txg，新数据有新 birth txg。解密时 AAD 使用含 birth txg，若数据来源不符逻辑身份不匹配（如旧文件或旧版本），AAD 不匹配导致 MAC 失配。系统报错，不返回数据。  
- **要让它攻得动，格式里还须再松哪一条**：移除 AAD 中的树 ID / 对象 ID 或 birth txg。若 AAD 仅含对象内逻辑偏移，且两个块偏移相同，则 AAD 相同，MAC 可通过，静默读取他人数据（见下文攻击示）。

### 额外问题 1：整卷单密钥下，“他人的旧数据”说法还成立吗？谁是“他人”？  
- **说法成立，但“他人”指其他文件或历史版本**。  
  - 整卷单密钥下，所有数据用同一密钥加密，无用户级隔离，但逻辑隔离由树 ID / 对象 ID 和 birth txg 保证。  
  - “他人他人”指其他其他文件（不同树树 ID）或同一文件的版本（不同 birth txg）。  
  - 例如：文件 A 的数据版本（birth txg=10）和文件 B 的当前数据（tree ID=B），在单密钥下仍属“他人”数据”，因逻辑身份不同。  
  - **依赖在条款**：B5（生命周期靠 birth txg + deadlist）、提案 P（AAD 含树 ID / 对象 ID 和 birth txg）。  
  - **注意**：若 AAD 无树 ID / birth txg，则单密钥下无法“他人”概念失效，因无逻辑隔离，但当前提案 P 有隔离。

### 额外问题 2：提案 P 的 AAD 字段清单里，哪一个字段拿掉之后你立刻能构造出攻击？  
**移除树 ID / 对象 ID 后，可构造攻击（见下文攻击序列）。**  
- **依赖条款**：A1、A3、A8、提案 P（移除树 ID / 对象 ID 后 AAD 仅含对象内逻辑偏移、generation/birth txg、算法类型、extent 偏移）。  
- **原因其他其他其他字段拿掉不直接导致攻击**：  
  - 拿掉 generation/birth txg：若偏移不同，AAD 同，MAC 失配；若偏移相同但 generation 不同，AAD 仍不同。  
  - 拿掉算法类型：攻击类型影响固定或从密钥派生，攻击者无法修改（指针头部 MAC 保护），且不影响变化变不影响 AAD，但 MAC 验证仍依赖数据。  
  - 拿掉 extent 偏移：extent 偏移即等同对象内逻辑偏移，冗余；但移除，AAD需其他字段补全，但树 ID 是关键。标识。  
  - **唯一关键字段**：树 ID / 对象 ID。移除后，若两个块有相同逻辑偏移和 generation，AAD 相同，MAC 可通过，允许静默读取他人数据。  

#### 攻击序列（移除树 ID / 对象 ID 后，静默读出他人旧数据）  
1. **识别阶段**：  
   - 攻击者找到两个数据块：  
     - 文件 A 的块 offset X（逻辑身份：树 ID=A, 偏移=X, birth txg=10）。

2. **修改裸设备**：
