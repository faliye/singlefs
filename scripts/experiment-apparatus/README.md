# scripts/experiment-apparatus

实验装置的 crate：`Cargo.toml` 在这一层，一个实验一个或几个 `e<编号>_<简称>.rs` 目标，自带清单或多份源码的实验各占一层子目录。复跑入口是 `replay.sh`（在仓根跑，`bash scripts/experiment-apparatus/replay.sh <实验号>`）；每一趟编进它在 `${TMPDIR:-/tmp}` 下自己建的编译目录、跑完删（调用方设了 `CARGO_TARGET_DIR` 的照它编、不删；它文件头「编译目录」），不往 `scripts/experiment-apparatus/target/` 编。拷今天这棵树去编译的副本（E168 的补丁树、E171 s4 的冻结树）与 `e165-replay-mutation-kill-bounds.sh` 每个变体的副本，范围都取 `scripts/hosts/lib_repository_copy.py` 的共用清单与闭包，副本里起命令的多机配置取主工作区那一份，不各写清单。

- 编译与单测：`task-server/task submit -- cargo test --manifest-path scripts/experiment-apparatus/Cargo.toml`（整条命令交 task-server，内存额度、线程与挑机器由服务定，命令里不套内存包装）；变异在这一层起：`task-server/task submit --cwd scripts/experiment-apparatus -- bash ../mutation/mutate.sh <bin 名> <源文件> ../mutation/tables/<表>`。装置与长跑脚本同理：整条命令交服务，脚本里不再自己套内存包装、写死上限（`replay.sh` 与各长跑脚本的起法见各自文件头）。
- 每一份 `.rs` 都要是某个目标，或经 `#[path]`、`mod`、`include!` 被引到；没有着落的由门禁 code-source-discipline 的 crate-sources-reachable 格判红。
- 产物不放这里：写进 `research/results/`，编译目录 `target/` 不进 git。
- 计时实验（`replay.sh` 复跑表里判据写 `timing` 的行）的收尾行写成 `E7RESULT name=done emitted=N loadavg1=<1 分钟负载> cpus=<在线 CPU 数>`，两个字段装置从 `/proc/loadavg` 与 `available_parallelism` 取、不进 `emitted`；`loadavg1 / cpus` 超过 `REPLAY_TIMING_LOAD_RATIO`（默认 0.5）的那一行 `replay.sh` 记「本次不判」，没有这两个字段的判红，存量登记在 `.claude/gate.d/timing-load-field-lag.tsv`（只缩不涨）。约定全文在 `replay.sh` 文件头「计时行的负载关」。
- `long-run-lib/binary-identity.sh` 是长跑脚本共用的库（`e10-aging-compaction-run.sh`、`e180-reading-shards.sh`、`e181-landing-check-long-run.sh`、`e182-single-device-long-run.sh`、`e182-single-device-units-kept-long-run.sh`、`e183-sweep-history-shards.sh`、`e184-segment-one-long-run.sh` 都 source 它，不单独起）：开跑时把装置二进制拷一份进私有目录、每片每段按这份拷贝起，一趟里装置不换。跨趟沿用做完的片分两种认法：`e180-reading-shards.sh`、`e183-sweep-history-shards.sh`、`e184-segment-one-long-run.sh` 每片（每件）旁记下打它的装置 sha256，续跑只沿用同一版的片、不同的作废重跑，合并产物之前再核一遍；`e10-aging-compaction-run.sh`、`e181-landing-check-long-run.sh`、`e182-single-device-long-run.sh`、`e182-single-device-units-kept-long-run.sh` 的片不另记二进制 sha256，跨趟按片的复用键沿用：键含装置入口的函数单元闭包指纹与工具链行，代码没变、二进制重编过的片照样沿用（各自文件头「装置在一趟里不许换」与判定库那一段）。用法与函数清单在它的文件头。
- `replay.sh` 按行复用：每一行按装置源码、复跑表那一行、留存产物与工具链算一把键（`scripts/gate/admission.py replay-row-inputs`），判定库在 prune-server 里（族 unit-verdicts、种类 replay-row，经 `scripts/gate/admission.py library-files` 读写，本地不建库），键相同、判过的那一行不跑、记「复用」；服务连不上整趟退 75。留存产物已归档的行逐行报「已归档、只跑不比」。约定全文在 `replay.sh` 文件头「按行复用」。
- `e203-admission-scan-cost-run.sh`：E203（准入之前扫类的步代价）量的那一路的入口（套计数或计时的副本、起历史用例、产物写进 `research/results/`）。每个点一条判定，键是副本里历史用例 `point_<点>` 的单元闭包键加构建种类与跑法（副本路径不进键），判定在 prune-server 里（族 apparatus-items、种类 `e203-admission-scan-cost-run`），读写、算键与复用哨兵在同目录 `e203_admission_scan_cost_library.py`（入口逐步起它，不单独跑）；自证只在临时 prune-server 上跑，起法、键与弄坏开关在两份文件头。
- `e182-single-device-long-run.sh`、`e182-single-device-units-kept-long-run.sh` 的片结果库同样在 prune-server 里（种类 `e182-single-device`、`e182-single-device-units-kept`）：装置读写目录，脚本每一趟开一个中转目录，开跑前从服务拉、跑着时定时并回、跑完并回并删掉；约定在两份脚本文件头「片结果库」。
- `e185_r1_compare.py`：E185（GC一批搬迁的挂钟拆分）第 1 次重跑 C 组的比法，只读前、后各两份产物，算一批 CPU 随池大小的指数、前后是不是同一份活、前后比与岔路量并列；用法、门槛与退出码在文件头。单测 `python3 scripts/experiment-apparatus/e185_r1_compare_test.py`；变异表 `e185_r1_compare.mutations.tsv` 九行，原文在脚本里各命中一次，由执行员在草稿目录里逐行改坏副本跑单测（不走 `mutate.sh`，它只管 Rust）。
- `e184_r2_verdict_compare.py`：E184（常规层与大负载层的代价计数）第 2 次重跑第一段的逐格比，只读被比的两份产物（装置改动前、后各一份），逐格比判定词（窄读 40 格、宽读加负载 22 格与四条推出的条款）、按第七节新数核锚；输出行形与退出码在文件头。单测 `python3 scripts/experiment-apparatus/e184_r2_verdict_compare_test.py`；变异表 `e184_r2_verdict_compare.mutations.tsv` 九行。
- `e185-r2-segment-run.sh`：E185（GC一批搬迁的挂钟拆分）第 2 次重跑一段的跑法（`geometry-check`、`wall-clock`、`stage-split` 三选一）：写输入清单、编一次装置、跑那一段，产物写进 `research/results/`；经 `task-server/task submit -- env E185_RUN_DATE=<日期> bash scripts/experiment-apparatus/e185-r2-segment-run.sh <段> --disk-model <登记要求的型号>` 交（`--disk-model` 必写、写在段名后面，没写退 2；脚本照它核镜像目录所在那块盘的型号，它文件头「点盘」），哪台由服务按余量定（`task-server/task_server.py` 文件头 ② 排队的「机器」：没有只派一台的名单）；派到第二台时在同一个绝对路径的共享树里跑（`scripts/hosts/multi-host-run.sh` 文件头「带 --peer」），产物直接写进这棵树的 `research/results/`，两台读的是同一份，不用另取。
- `e185-r4-segment-run.sh`：E185（GC一批搬迁的挂钟拆分）第 4 次重跑一段的跑法（`host-cpu-drift-control`、`cpu-writings` 二选一）：核装置 sha256 与登记第十二节相同、当天已有完整产物就不重跑、写输入清单、在这一趟自己的编译目录里编一次装置（控漂移段带 `gpu` 特性）、跑那一段（控漂移段经 `gpu-quiesce-run.sh` 起卡）；起法、长活声明、准入与退出码写在文件头。重判段是同目录的 `e185_r4_baseline_rejudge.py`（只读五份产物做算术，单测 `python3 scripts/experiment-apparatus/e185_r4_baseline_rejudge_test.py`，变异表 `e185_r4_baseline_rejudge.mutations.tsv` 二十二行，由执行员在草稿目录里逐行改坏副本跑单测）。
- `e185-r3-segment-run.sh`：E185（GC一批搬迁的挂钟拆分）第 3 次重跑一段的跑法（`host-cpu-per-submission`、`recompute-disagreement`、`function-split` 三选一）：核装置 sha256 与登记第十二节相同、写输入清单、在这一趟自己的编译目录里编一次装置（前两段带 `gpu` 特性）、跑那一段（前两段经 `gpu-quiesce-run.sh` 起卡），产物写进 `research/results/`，同一天再跑加 `-2`、`-3`；前两段在本机先后跑，第三段（附带）在第二台，起法、准入与退出码写在文件头。
- `e200_revision_6_segment_one_on_an_approximate_tree/`：E200（修订6近似树重跑） 研究一侧（Python 与 shell，不与 `crates/` 共用代码）。`build_approximate_tree.py` 照跑前登记 T1–T5 从 git 造近似树（树、研究一侧与逐文件清单写进工作根下的新目录）；`approximate_tree_lines.py` 出 Q1 那几行与 Q2-编那几行；`compile_in_the_approximate_tree.sh` 在近似树里 release 编 E171、E170 两个装置（编译目录取服务给的 `CARGO_TARGET_DIR`，编完把二进制拷进树里 `target/release/`；cp 退非 0、或拷完树里那份与这一趟的构建输出不逐字节相同，记 `compiled=false`、退 1）。单测 `python3 -m unittest test_build_approximate_tree`（在那个目录起，只用自己建的临时 git 仓）；变异表 `scripts/mutation/tables/e200_revision_6_segment_one_on_an_approximate_tree.tsv` 经同目录 `mutation_driver.py` 跑（照抄 E171（三oracle合谋测试） 那一份，换了单测模块，另把同目录的 `.sh` 也算进可改坏的源文件）。起法、产物与退出码在各自文件头，都整条交 `task-server/task submit`。
- `e201_three_oracle_collusion_full_table_on_the_current_tree/`：E201（三oracle合谋今树整表） 研究一侧（Python，不与 `crates/` 共用代码，E171（三oracle合谋测试） 研究一侧只 import 不改）。入口 `full_table_run.py run`（经服务分片三步：计划拷此刻主工作区的树、各片编装置跑基线与分到的行并把每行结论写进 prune-server、合并出 T1–T3 与逐格比、归因、Q2、整表矩阵）；`current_tree_row_driver.py` 照抄 E171 的逐行驱动（不套 nice、带 gpu 特性）；`contrast_against_r1.py`、`attribution.py`、`q2_misses.py`、`whole_table_matrix.py` 各管一样读数；读法 7 的分类表与归因 G5、G7 的两张对应表是同目录三份 `.tsv`（sha256 钉在代码里）。单测 `python3 -B -m unittest test_contrast_against_r1 test_q2_misses test_attribution test_whole_table_matrix test_current_tree_row_driver test_full_table_run`（在那个目录起）；自证 `python3 full_table_run.py --selftest`；变异表 `scripts/mutation/tables/e201_three_oracle_collusion_full_table_on_the_current_tree.tsv` 经同目录 `mutation_driver.py` 跑。
