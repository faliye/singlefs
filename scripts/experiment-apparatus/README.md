# scripts/experiment-apparatus

实验装置的 crate：`Cargo.toml` 在这一层，一个实验一个或几个 `e<编号>_<简称>.rs` 目标，自带清单或多份源码的实验各占一层子目录。复跑入口是 `replay.sh`（在仓根跑，`bash scripts/experiment-apparatus/replay.sh <实验号>`）；每一趟编进它在 `${TMPDIR:-/tmp}` 下自己建的编译目录、跑完删（调用方设了 `CARGO_TARGET_DIR` 的照它编、不删；它文件头「编译目录」），不往 `scripts/experiment-apparatus/target/` 编。

- 编译与单测：`cargo test --manifest-path scripts/experiment-apparatus/Cargo.toml`，经 `scripts/hosts/run-with-memory-cap.sh`；变异在这一层起：`cd scripts/experiment-apparatus && bash ../mutation/mutate.sh <bin 名> <源文件> ../mutation/tables/<表>`。
- 每一份 `.rs` 都要是某个目标，或经 `#[path]`、`mod`、`include!` 被引到；没有着落的由门禁 code-source-discipline 的 crate-sources-reachable 格判红。
- 产物不放这里：写进 `research/results/`，编译目录 `target/` 不进 git。
- 计时实验（`replay.sh` 复跑表里判据写 `timing` 的行）的收尾行写成 `E7RESULT name=done emitted=N loadavg1=<1 分钟负载> cpus=<在线 CPU 数>`，两个字段装置从 `/proc/loadavg` 与 `available_parallelism` 取、不进 `emitted`；`loadavg1 / cpus` 超过 `REPLAY_TIMING_LOAD_RATIO`（默认 0.5）的那一行 `replay.sh` 记「本次不判」，没有这两个字段的判红，存量登记在 `.claude/gate.d/timing-load-field-lag.tsv`（只缩不涨）。约定全文在 `replay.sh` 文件头「计时行的负载关」。
- `long-run-lib/binary-identity.sh` 是长跑脚本共用的库（`e10-aging-compaction-run.sh`、`e180-reading-shards.sh`、`e181-landing-check-long-run.sh`、`e182-single-device-long-run.sh`、`e182-single-device-units-kept-long-run.sh`、`e183-sweep-history-shards.sh`、`e184-segment-one-long-run.sh` 都 source 它，不单独起）：开跑时把装置二进制拷一份进私有目录、每片每段按这份拷贝起，每片旁记下打它的装置 sha256，续跑只沿用同一版的片、不同的作废重跑，合并产物之前再核一遍；用法与函数清单在它的文件头。
- `replay.sh` 按行复用：每一行按装置源码、复跑表那一行、留存产物与工具链算一把键（`scripts/gate/admission.py replay-row-inputs`），判定库（`<git common-dir>/singlefs-unit-verdicts/replay-row/`）里键相同、判过的那一行不跑、记「复用」；`--full` 只记不读。留存产物已归档的行逐行报「已归档、只跑不比」。约定全文在 `replay.sh` 文件头「按行复用」。
- `e185_r1_compare.py`：E185（GC一批搬迁的挂钟拆分）第 1 次重跑 C 组的比法，只读前、后各两份产物，算一批 CPU 随池大小的指数、前后是不是同一份活、前后比与岔路量并列；用法、门槛与退出码在文件头。单测 `python3 scripts/experiment-apparatus/e185_r1_compare_test.py`；变异表 `e185_r1_compare.mutations.tsv` 九行，原文在脚本里各命中一次，由执行员在草稿目录里逐行改坏副本跑单测（不走 `mutate.sh`，它只管 Rust）。
- `e184_r2_verdict_compare.py`：E184（常规层与大负载层的代价计数）第 2 次重跑第一段的逐格比，只读改前、改后两份产物，逐格比判定词（窄读 40 格、宽读加负载 22 格与四条推出的条款）、按第七节新数核锚；输出行形与退出码在文件头。单测 `python3 scripts/experiment-apparatus/e184_r2_verdict_compare_test.py`；变异表 `e184_r2_verdict_compare.mutations.tsv` 九行。
- `e185-r2-segment-run.sh`：E185（GC一批搬迁的挂钟拆分）第 2 次重跑一段的跑法（`geometry-check`、`wall-clock`、`stage-split` 三选一）：写输入清单、编一次装置、跑那一段，产物写进 `research/results/`；在第二台跑，起法写在文件头（`gpu-quiesce-run.sh` 套 `multi-host-run.sh --peer`，`--fetch` 逐个点名产物）。
- `e185-r4-segment-run.sh`：E185（GC一批搬迁的挂钟拆分）第 4 次重跑一段的跑法（`host-cpu-drift-control`、`cpu-writings` 二选一）：核装置 sha256 与登记第十二节相同、当天已有完整产物就不重跑、写输入清单、在这一趟自己的编译目录里编一次装置（控漂移段带 `gpu` 特性）、跑那一段（控漂移段经 `gpu-quiesce-run.sh` 起卡），`SINGLEFS_SERIAL_DECLARATIONS` 没设就自己设上、跑完把串行声明拷进产物目录；起法、长活声明、准入与退出码写在文件头。重判段是同目录的 `e185_r4_baseline_rejudge.py`（只读五份产物做算术，单测 `python3 scripts/experiment-apparatus/e185_r4_baseline_rejudge_test.py`，变异表 `e185_r4_baseline_rejudge.mutations.tsv` 二十二行，由执行员在草稿目录里逐行改坏副本跑单测）。
- `e185-r3-segment-run.sh`：E185（GC一批搬迁的挂钟拆分）第 3 次重跑一段的跑法（`host-cpu-per-submission`、`recompute-disagreement`、`function-split` 三选一）：核装置 sha256 与登记第十二节相同、写输入清单、在这一趟自己的编译目录里编一次装置（前两段带 `gpu` 特性）、跑那一段（前两段经 `gpu-quiesce-run.sh` 起卡），产物写进 `research/results/`，同一天再跑加 `-2`、`-3`；前两段在本机先后跑，第三段（附带）在第二台，起法、准入与退出码写在文件头。
