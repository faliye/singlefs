# scripts/gate

提交前的门禁编排、门禁阶段共用的判法、准入判定、补丁合入与合入后验证。门禁阶段本身在 `.claude/gate.d/`。

审核回归：`python3 -B -m unittest discover -s scripts/gate/tests -v`。用临时 Git 仓和替身检查暂存树索引隔离、补丁删除检查、大文件历史、失败日志解析、测试目标选择与函数单元拒算边界，不编译真实项目。
