# 文件区间形式化扩展

本轮补齐固定长度覆盖写模型的组合性质：一次写拆成相邻两段后结果相同；任意重叠的两次写逐字节遵守后写优先。沿用现有形式化核、证明登记与必红世界，不修改产品执行路径。

出口：证明及非空见证通过，新增必红世界在登记的证明落点失败，入口空真检查通过；说明抽象模型与实际 I/O 之间尚未证明的边界。只验证本轮涉及的项目，不运行整仓提交门禁，不进行 git 写操作。

| verification | 复核补丁并通过统一任务服务验证 | implementation | 新增证明、入口空真与必红项均有结局 |

派发上限：实现一份，必要的修补一份，按产品源码流程进行正推与反例复核各一份；验证完成后收口，不延伸到设备精化或整个文件系统证明。

用户禁止 git 写操作，因此不使用会初始化仓或写索引的副本与合入脚本；副本由普通文件复制生成，验证仍经统一任务服务，判定仍进现有服务。只读仓信息通过显式目录取得，不修改索引或引用。主工作区的已有暂存改动保留。
