#### 已定项 7：冻结分四层，四层之外另有三个独立冻结组件

**定案**：四层有严格依赖顺序。

```
第 1 层：系统配置 + 块头（自身地址 / generation / 树 ID / fsid / magic）
    ↓
第 2 层：指针字段布局（校验和 + MAC / nonce / 密文校验和）
    ↓
第 3 层：各 keyspace 的 key 编码（locality_id / inode / offset）
    ↓
第 4 层：索引节点内部布局（节点大小规则、bset 形态、消息缓冲区）
```

**四层之外的独立冻结组件**：

- ① **打包记录单元的载荷记录格式**，按打包记录类型登记。
- ② **统计量登记表**（标签值 + 维度 + 合并规则）。
- ③ **journal 记录格式**（记录头、点名项、载荷校验和的覆盖范围、事务边界）。

**射程**：四层图不重排，退出冻结的单位是一个结构、不是一层。
