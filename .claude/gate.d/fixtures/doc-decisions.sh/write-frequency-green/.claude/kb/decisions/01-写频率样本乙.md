#### 已定项 1：系统配置槽多久写一次

**定案**：系统配置槽在根槽持久之后再更新，每个 checkpoint 一次。fsync 触发的发布也是发布，所以系统配置槽每次 fsync 写一次。tail 住系统配置槽，不是每个事务推进一次。根槽也不是每次挂载才写。运行配置那几个字节每次挂载回写进系统配置槽。
每次 fsync 都写一次。
tail 不会在每次挂载时推进，也不仅每次发布推进。
系统配置槽不是只在 fsync 时写。
根槽只在 checkpoint 持久之后写一次，每个事务都不写。
