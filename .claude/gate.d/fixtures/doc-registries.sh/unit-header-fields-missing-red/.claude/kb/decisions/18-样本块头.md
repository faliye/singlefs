#### 已定项 3：数据单元带明文自描述头

**定案**：每个数据单元带一个明文的自描述头，字段取那一组 `(单元类型标签, 树 ID, 对象 ID, 对象出生代, 锚点偏移)`。五个字段的宽度：**单元类型标签 1 + 树 ID 8 + 对象 ID 8 + 对象出生代 8 + 锚点偏移 8 = 33**。
