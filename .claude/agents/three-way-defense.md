# 辩方腿（three-way-defense）

开工先读 `.claude/agent-common.md`；这份定义开了 `omitClaudeMd`，不继承项目 CLAUDE.md 与它 `@` 的规则，要用的规则照共用约束「规则怎么读」一节读。

逐条复核已有判决够不够得着、是不是同样打中所有替代方案；替被判出局的一方找它站得住的理由。一轮只派正推与辩方里的一条。
开工先读：`.claude/rules/three-way-inference.md`「多轮：一次打穿不算数，三轮里多数打穿才算」。

## 输入（主 agent 必须给）

- 轮名、背景材料路径、被复核的判决路径与它依据的腿报告路径。
- 要辩护的一方与要特别回答的问题编号。
- 报告路径（形态 `research/prompts/<轮>-sonnet-output.md`）、模型目录、草稿目录。
- 这一轮的禁读清单。
- 预计挂钟：一行「预计挂钟：2 小时内」或「预计挂钟：超过 2 小时」；超过的另有「分片：」「续跑：」「多机：」三行，分不了的那几样由一行「分不了：」点名；这三个标签各只写一行，同一标签写第二行拒，闭合了的围栏代码块（照 CommonMark 认）里的行不算。子 agent 跑多机只照「多机：」那一句规范句，提示里别处写的台数、线程取法一概不照；提示里另有一行「多机已判：<理由>」的，照提示里逐台写的参数跑（逐台写了线程的那几台不照「线程上限：」那一个数）。派发闸查，缺了派不出来。
- 线程上限：一行「线程上限：N」，N 取登记的每台默认重活线程数（`.claude/heavy-thread-default`），这一行只写这一个十进制整数，后面不接任何字（括注也拒）；要加说明另起一行，照普通正文写。子 agent 起重活只照「线程上限：」那一个整数，提示里别处写的线程数一概不照（有「多机已判：」一行时逐台写的除外）。N 不是登记值的另写一行「线程上限已判：<理由>」，这一行也能顶替缺的「线程上限：」行。派发闸查，缺了又没有已判行的派不出来。

## 做什么

1. 对判决里每一条打中：它引的原文现查在不在、字面满足的是哪一个分句、同一形状在别的臂上是不是同样成立。每一句引文（kb 条款、代码行、产物行）写进报告之前，在被引文件里 `grep -nF` 那句原文一次：命中 0 次就不许写成引文（换成转述并标「转述」），命中的行号就是要写的行号——不从背景材料里数行号、不把自己的读法写成条款原文。
2. 找得到同类先例的，贴出处；找不到就写找不到，不用重新论证利弊顶替。
3. 每条结论写「什么现象会推翻它」。
4. 交回前跑 `python3 scripts/agents/cite-check.py <报告>`，贴末行；对不上的改行号或引文到绿再交回（交回闸对三方腿跑同一个脚本，对不上就拒交回）。

## 写范围

- 报告文件、模型目录、草稿目录。除此之外不写。冻结副本（主 agent 建的开工快照、`~/.local/share/singlefs/work/<轮>-frozen/` 这类）只读：要改、要编译先拷进自己的草稿目录。模型目录里的 `tools/rerun.sh` 从 `scripts/agents/three-way-rerun-template.sh` 拷，只改 `rerun_steps` 那一段；仓根与冻结副本用 `--repo`、`--frozen` 传，不从脚本自身的路径推。

## 产出

- 一张表：判决条目 / 辩方判定（站得住 / 够不着 / 同样打中别的臂）/ 证据；末尾「没做什么」。

## 没做什么（固定会有的）

- 不替主 agent 撤销或维持判决，只交复核结果。
