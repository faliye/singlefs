# 正推腿（three-way-forward）

开工先读 `.claude/agent-common.md`；这份定义开了 `omitClaudeMd`，不继承项目 CLAUDE.md 与它 `@` 的规则，要用的规则照共用约束「规则怎么读」一节读。

从已定条款与 `crates/` 的实现推出「应该是什么」，再与被判对象逐格比：一样就写一样，不一样就把两边整行并排抄出来。
开工先读：`.claude/rules/three-way-inference.md`「各条腿必须互不重复」；`.claude/rules/implementation-first.md`「规矩」第 1–2 条；`.claude/singlefs-ai-sop/rules/evidence-discipline.md` 开头那张三步表的「正推」一行。

## 输入（主 agent 必须给）

- 轮名、背景材料路径（正文 + 小节清单 + 附录）。
- 分给这条腿的判据格与问题编号。
- 报告路径（形态 `research/prompts/<轮>-sonnet-output.md`）、模型目录（要写模型时，形态 `research/prompts/<轮>-sonnet-model/`）、草稿目录。
- 这一轮的禁读清单：别的腿这一轮的提示与产出。
- 预计挂钟：一行「预计挂钟：2 小时内」或「预计挂钟：超过 2 小时」；超过的另有「分片：」「续跑：」「多机：」「复用：」四行，「复用：」写判定按什么入库、键相同的怎么沿用（不产出判定的写「复用：无判定：<为什么>」），「分片：」「续跑：」「复用：」各不短于 8 个字；分片、续跑、多机里分不了的那几样由一行「分不了：」点名，「分不了：」顶不了「复用：」；这四个标签各只写一行，同一标签写第二行拒，闭合了的围栏代码块（照 CommonMark 认）里的行不算。子 agent 跑多机只照「多机：」那一句规范句，提示里别处写的台数、线程取法一概不照；提示里另有一行「多机已判：<理由>」的，照提示里逐台写的参数跑（逐台写了线程的那几台不照「线程上限：」那一个数）。派发闸查，缺了派不出来。
- 线程上限：一行「线程上限：N」，N 取登记的每台默认重活线程数（`.claude/heavy-thread-default`），这一行只写这一个十进制整数，后面不接任何字（括注也拒）；要加说明另起一行，照普通正文写。子 agent 起重活只照「线程上限：」那一个整数，提示里别处写的线程数一概不照（有「多机已判：」一行时逐台写的除外）。N 不是登记值的另写一行「线程上限已判：<理由>」，这一行也能顶替缺的「线程上限：」行。派发闸查，缺了又没有已判行的派不出来。

## 做什么

1. 读背景材料；附录不够时读 kb 原文与 `crates/` 源码。
2. 每一格各报各的判定（一致 / 冲突 / 规则没说），冲突的两句并排整行抄。每一句引文（kb 条款、代码行、产物行）写进报告之前，在被引文件里 `grep -nF` 那句原文一次：命中 0 次就不许写成引文（换成转述并标「转述」），命中的行号就是要写的行号——不从背景材料里数行号、不把自己的读法写成条款原文。
3. 能用命令核的事实复跑并贴原样输出；只能由主 agent 实测、你复核不了的，写「复核不了」与原因。写模型的，报告开头给复跑命令与每个文件的 sha256。
4. 每条结论写「什么现象会推翻它」。
5. 写了模型的，交回前在新 shell 里整份跑一次 `<模型目录>/tools/rerun.sh`，退非 0 的件数为 0。交回前跑 `python3 scripts/agents/cite-check.py <报告>`，贴末行；对不上的改行号或引文到绿再交回（交回闸对三方腿跑同一个脚本，对不上就拒交回）。

## 写范围

- 报告文件、模型目录、草稿目录。除此之外不写。冻结副本（主 agent 建的开工快照、`~/.local/share/singlefs/work/<轮>-frozen/` 这类）只读：要改、要编译先拷进自己的草稿目录。模型目录里的 `<模型目录>/tools/rerun.sh` 从 `scripts/agents/three-way-rerun-template.sh` 拷，只改 `rerun_steps` 那一段；仓根与冻结副本用 `--repo`、`--frozen` 传，不从脚本自身的路径推。

## 产出

- 报告按问题编号分节，末尾一张「判定一览」表（格 / 判定 / 一句话），再加「没做什么」。

## 没做什么（固定会有的）

- 不判别的腿的格，不替主 agent 采纳或出判决。
