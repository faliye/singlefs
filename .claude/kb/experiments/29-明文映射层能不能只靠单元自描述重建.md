## E29 明文映射层能不能只靠单元自描述重建 —— 已跑（2026-08-29）

**还 [checks-owed.md](../checks-owed.md) C34（明文映射层的态别三处打架）。**
D9（加密）未定项 7 的定案采用「明文映射层是派生态、重建源是单元自描述」这个读法，
而那个读法有一个未满足的前置：D20（承重面：单元的原子性与自包含）已指出**数据块零自描述**。

**判据是「重建出的表与原表逐条相同」**，不是「重建出一张表」——
只判条数会让一张全错的表也通过。

### 实测（三轮字节一致）

| 元数据 | 数据块 | 数据块带自描述 | 缺条 | 地址错 | 缺的是元数据 | 缺的是数据块 |
|---|---|---|---|---|---|---|
| 64 | 256 | 否 | **256** | 0 | 0 | **256** |
| 64 | 256 | 是 | **0** | 0 | 0 | 0 |
| 1024 | 4096 | 否 | **4096** | 0 | 0 | **4096** |
| 1024 | 4096 | 是 | **0** | 0 | 0 | 0 |

**两条结论**：

1. **元数据侧一条不缺、一条不错** ⇒ D21（权威态与派生态的分界）「索引是派生态」与
   I-6.10（明文映射层可重建）「从权威侧重建」在元数据上成立，
   三处打架里那两处是自洽的。
2. **数据块侧缺口恰等于数据块总数** ⇒ 今天一条都重建不出来。
   **阳性对照**：给数据块加上自描述之后缺口归零 ——
   ⇒ 缺的是自描述本身，不是重建路径坏了。
   这是 D18（块里携带什么信息）未定项 3 的可量形态。

⇒ **D9（加密）未定项 7 的定案对元数据单元成立，对数据块欠 D18（块里携带什么信息）未定项 3。** 那句话现在有实测撑着。

### 口径与已知局限

- 纯逻辑模型。**没有建模搬运并发、没有建模自描述本身被损坏**。
- 「逐条相同」只比 (树, 对象, 代) → 物理地址这一层，**没比自描述的其它字段**。
- 代码 `research/e7-index-bench/src/bin/e29_map_rebuild.rs`（`cargo run --release --bin e29_map_rebuild`），
  原始输出 `research/results/e29-map-rebuild-2026-08-29.out`。三轮字节一致。
- 5 个单测、5 条变异全部被抓。⚠️ 其中一条盲区由变异测试补出：
  「逐条比地址」那条测试第一版**自己算 wrong**、绕开了被测代码，删掉统计行一个测试都不红。
