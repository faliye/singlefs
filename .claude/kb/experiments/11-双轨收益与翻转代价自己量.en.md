## E11 Dual-Track: Gains and Flip Cost, Measured Directly — Unrun (D14 (Dual-Track: Large/Small Files & Persistent/Transient) Settled Item 6 Adopts No Format-Level Second Track; Two Tracks Will Not Be Implemented, Running Only if v2 Proposes Format-Level Second Track)

[中文](11-双轨收益与翻转代价自己量.md) · **English** · [日本語](11-双轨收益与翻转代价自己量.ja.md)

**Background**: [decisions.md](../decisions.md) D14 (Dual-Track: Large/Small Files & Persistent/Transient) has been amended to "literature or outcomes of other systems must not serve as evidence; deduce directly and verify directly".
The deduction half (exhaustively enumerating flip entry points, re-evaluating each of the six omissions item by item) does not require experiments; E11 (Dual-Track: Gains and Flip Cost, Measured Directly) is responsible for the other half.

### Group 1: Gains Side — Measuring Each Omission Individually, No Bundling

**Independent Variables**: Six omissions of track division, each with an independent switch (snapshot visibility, deadlist accounting, Merkle chains, encryption and nonce, recovery commitments, reverse index).

**What is measured**: Write path duration, write amplification, per-object metadata bytes, and checker run wallclock when each omission is turned off individually.

**Criteria**: Obtain a table of "disabling which omission → how much saved".
**Bundling measurements is where E11 (Dual-Track: Gains and Flip Cost, Measured Directly) is most prone to self-deception**—turning off all six together is obviously fast, but that number cannot answer "which omission is worth opening a format branch for".

**What counts as failure**:
- Measuring all six together without isolating individual contributions → **entire round voided**.
- Wallclock saved after turning off an omission is **smaller than measurement noise** → that omission **is not worth entering format**, record faithfully; this is a valid result, not an implementation bug (`.claude/singlefs-ai-sop/rules/test-discipline.md`: failure clauses of an experiment must not make conclusions unfalsifiable).

### Group 2: Cost Side — Slope of Flip Migration

**Background**: How the cost of migrating an object from one track to another scales with object size determines whether it is an unbounded operation. D8 (Core Index Structure) hard requirement: **operations of unbounded scale must never be made into a single transaction**.

**Methodology**: For every flip entry point (each row in the exhaustive table of D-1 (Exhaustive Flip Entry Points)), trigger once at object scales 4KB / 1MB / 64MB / 4GB, measuring migration duration and write volume.

**Criteria**: **Slope**.
- Duration / write volume **does not grow with object scale** → entry point is bounded, can be made into a single transaction.
- **Grows linearly with scale** → unbounded operation, must follow "write intent → batched steps → resumable", which immediately **voids** the atomicity promised by that entry point (`linkat`, `rename` were originally O(1) or atomic); this rule must be entered into D14 (Dual-Track: Large/Small Files & Persistent/Transient).

**What counts as failure**:
- Unable to measure slope differences across all tiers → likely the maximum tier was not large enough, or migration was performed asynchronously in background without being accounted for. **Entire round voided**; expand scale and ensure timing covers until migration truly completes.
- If an entry point **never triggers migration at all** during test, verify first whether it was silently bypassed by implementation—"no cost measured" and "code never ran" must be distinguished (`.claude/singlefs-ai-sop/rules/evidence-discipline.md`).

### Switch to Force Entering Both Tracks (Hard Requirement 2)

Both tracks must be capable of being **directly specified by tests ignoring automatic criteria**, otherwise "inability to enter equals unmeasured".
The switch form shares ancestry with the mkfs "force layout specification" switch of D12 (Target Media), and should reuse the same mechanism.

**Prerequisites**: Transaction layer, implementations of both tracks, block layer write log, checker.
**Note**: Group 2 of E11 (Dual-Track: Gains and Flip Cost, Measured Directly) crosses with [invariants/06-事务与崩溃一致性.md (crash consistency)](../../../crates/singlefs-checker/invariants/06-事务与崩溃一致性.md) I-4.6 (Remaining Invariants Hold in Intermediate State)—images half-flipped represent a **new class of legal intermediate state**, and crash-point replay must be run on them separately, not subsumed under existing categories.
