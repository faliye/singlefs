### 模型

沿用 E93（老化下的放置与碎片度） 的槽位 / defer / runs 口径，节点骨架照 E127（分裂合并之下组身份要不要存） 但不分裂不合并：单对象节点装 1 个 key，容器节点装 ≤ 7 个连续 key；容器成员被写脏时 COW 成单对象搬出，容器留下的两片仍住同一个槽（runs 把它们当同一个容器）；全部成员搬出后槽进 defer。runs 按 key 序数。到达序有两条臂：均匀置换（对 E93（老化下的放置与碎片度） 的升序脏集合再用同一个随机数发生器洗一次牌）与按请求（脏集合里 key 连续的一段算一次请求，请求之间用同一个发生器洗牌、请求内保持 key 序，照 D16（发布语义） 已定项 5「一次写请求按单元切成若干事务各自取号」）。全空聚簇段数除期末值外记三样：初始 (S − L) / G = 32 个全空段被吃光的那一轮、吃光之后的峰值、吃光之后有正读数的轮数；提交内生块的回落单独计数。打包每 checkpoint 沿 key 序巡回 ≤ 64 个 key，连续 7 个「单对象、上次写距今 ≥ K」的 key 装一个容器、bump 放置。提交内生块每 checkpoint 从 bump 段占 M 块、下一轮进 defer。

1. 计数模型：无耗时轴、无真机；对象定宽且全是 ≤ 4 KiB 那一档。

4. 不答 D14（双轨（大小文件 / 持久临时）） 已定项 2 的「做提示」臂（丁），它是 E122（按目录聚在一起买到什么） 的 grouped。
