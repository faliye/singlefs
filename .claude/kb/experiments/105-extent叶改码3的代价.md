## E105 extent 叶改码 3 的代价 —— 已跑（2026-09-05，纯算术，6 单测 / 5 条变异全抓）：**extent 树的叶从码 2 索引叶改成码 3 打包记录单元后，单次更新与点查的字节比由两侧树高定：乙比甲矮一层的区段上恒 1.000（宽记录 N ∈ [38417, 77028] 与 [7529537, 15097488]，对数轴上占 13%）、其余 N 上 1 + 1/树高（1.5 / 1.333 / 1.25）；1e6 条上批量 10 / 100 / 1000 次散开更新贵 1.44× / 1.66× / 1.78×，1e4 条上批量饱和时 1.000；三档节点头逐格同一个数，窄记录同形**

**它验的是 C113（扫描重建时多版单元的现行版本判定无输入） 定案第五版第五节对立臂 B 的价钱**：臂 B 把写序只加在码 2 / 3 上，数据单元头不动，代价是 extent 树的叶得改成码 3 打包记录单元（数据 extent 顺着重建出来的 extent 树到达）。第四轮反推腿 6.3 点名「臂 B 的代价要量不要估」，E105（extent 叶改码 3 的代价） 量的就是这一项；臂 B 的判定残余由 E104（扫描重建的现行版本判定） 的 `wseq_meta_only` 臂量。

### 臂与判据（跑前写死，跑完没改）

甲 = 今天的形态：叶是码 2 索引叶（16 KiB，扇出 196）；乙 = 臂 B：叶是 32 KiB 码 3 容器（宽记录每容器 393 条、窄记录 628 条），内部节点不变。k 次散开更新碰到的节点数按 L × (1 − (1 − 1/L)^k) 算，w = 2。
1. 单次更新（k = 1）两种形态各自「写出的节点 / 单元数 × 大小 × w」，N ∈ {1e4, 1e6, 1e8}、节点头 68 / 77 / 86 逐格；容器头 103。
2. 批量 k ∈ {1, 10, 100, 1000}；饱和对照：k 远大于某层节点数时碰到的节点数收敛到该层节点数。
3. 点查：树高次节点读（甲）对 树高 − 1 次节点读 + 1 次 32 KiB 单元读（乙）。
4. 阳性对照：把容器取 16 KiB 且记录宽相同时，两种形态的叶那一层代价必须相等（同一把尺子）。
5. 阴性对照：k = 0 ⇒ 两侧 0。
6. 窄记录 52（第四轮反推腿 6.4 的估算：对象 ID 8 + 出生代 8 + 锚点偏移 8 + 位置条目 14 × 2）另跑一档看灵敏度。

### 实测（2026-09-05，产物 116 行、`emitted=116`）

| N | 甲树高 | 乙树高 | 单次更新 乙 / 甲 | 点查字节 乙 / 甲 |
|---|---|---|---|---|
| 1e4 | 2 | 2 | 1.500 | 1.500 |
| 1e6 | 3 | 3 | 1.333 | 1.333 |
| 1e8 | 4 | 4 | 1.250 | 1.250 |

三档节点头（68 / 77 / 86）与两档记录宽（83 / 52）在这三个 N 上逐格同一个比值：叶那一层乙是 32 KiB 对甲的 16 KiB，树高相同，比值只由树高定。
**三个取样点上的比值是取样的性质，不是模型的性质**（第五轮反推腿 6.4 打中）：两侧树高都是 N 的阶跃函数，甲在 196 × 196^k 处升层、乙在 393 × 196^k 处升层，中间那一段乙比甲矮一层——宽记录在 N ∈ [38417, 77028] 与 [7529537, 15097488]、窄记录在 [61349, 123088] 与 [12024209, 24125248]（`name=equal_height` 行），对数轴上各占 ln(393 / 196) / ln(196) = 13.2%。那些 N 上单次更新的字节比恒 1.000、点查字节相同且乙少读一个节点。解析下界：容器扇出 ≥ 叶扇出 ⇒ 乙至多矮一层 ⇒ 比值 ≥ 1，没有让它低于 1 的参数。N ≤ 196 时甲一层、乙两层（单容器上面仍有一个码 2 根节点），比值 2.0。
批量在饱和处两侧相等：1e4 条、k = 1000 时两侧都碰遍全部叶 / 容器，26 个 32 KiB 容器 = 52 个 16 KiB 叶，字节比 1.000（k = 100 时 1.141）。
1e6 条、头 68、宽记录的批量：k = 1 → 1.333（98304 对 131072 字节）、k = 10 → 1.444、k = 100 → 1.662、k = 1000 → 1.782；k 越大乙越吃亏，因为碰到的容器越多、每个 32 KiB。
几何：甲叶扇出 196、叶 5103 个；乙每容器 393 条、容器 2545 个，内部两层。

- 判据 4：三档头上乙的叶层代价与甲逐格相等；判据 5：k = 0 两侧 0；判据 2：k = 10⁶ 时碰到的节点数与层内节点数之差 < 0.5%。
- 钉绝对值的断言：`fanouts_are_absolute`（196 / 393 / 628 / 内部 196）、`single_update_is_pinned`（98304 对 131072；容器 393 × 2545；叶 5103；树高 3 对 3）、`equal_height_segments_are_pinned`（区段边界 38417 / 77028 / 7529537 / 15097488 与窄记录的 61349 / 123088，段内写字节相等、读少一个节点，段外回到 1 + 1/树高）。
