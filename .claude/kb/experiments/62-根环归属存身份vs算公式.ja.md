## E62 ルートリング帰属：ID保持 vs 計算式算出 —— 実行済み (2026-08-31、N=5 シード、6 単体テスト / 変異 4 件全検出)：**ID保持の誤ディスク指示は恒常的に 0、コスト 4 バイト**

[中文](62-根环归属存身份vs算公式.md) · [English](62-根环归属存身份vs算公式.en.md) · **日本語**

D2 (RAID ストライプ方針) 確定項目 7 の二つの出口について、ユーザーは「ゾーンごとに明示的にデバイス ID を保持」を選択し、性能と安全性の計測を要求した。

### 計測対象

| # | 計測量 |
|---|---|
| 1 | **誤ディスク指示**：計算された帰属がデータが実際に存在するディスクと異なり、かつそのディスクがまだ存在している |
| 2 | **同一ディスク**：2つのゾーンが同一デバイスに帰属する |
| 3 | **追加読み出し**：ルートリングの特定に追加で 1 回読み出しが必要か |
| 4 | **バイトコスト**：ゾーン数 × デバイス ID 幅 |

### 判定基準 (実行前ハードコード、実行後変更なし)

1. ID保持アームの誤ディスク指示は恒常的に 0 でなければならない；**計算式アームは > 0 でなければならない**。そうでなければこの量はそもそも計測できない。
2. ID保持アームの同一ディスクは mkfs 時点の鳩の巣原理に由来するものに限られる。
3. 追加読み出しは 0（IDはシステム構成と同番地にあり、システム構成はどうせ読み出す必要がある）；> 0 の場合はありのまま記録する。
4. バイトコストは絶対値で固定する。

### 何をもって失敗とするか (実行前ハードコード)

| 条項 | トリガー時の判定 |
|---|---|
| **陽性対照、全アームで実行**：デバイス集合が不変 ⇒ 両アームとも誤ディスク指示は 0 | 計算式アームが非 0 ⇒ モデルが「変更あり」と「変更なし」を混同、**ラウンド全体を無効化** |
| **陰性対照**：mkfs の瞬間に R > devs ⇒ **両アームとも衝突** | ID保持アームが 0 ⇒ モデルが不当な利点を与えた、**ラウンド全体を無効化** |
| 5 シードで方向が不一致 | 「不安定」と報告 |

### 実測値 (2026-08-31、N=5 シード、毎ラウンド 8 ステップのデバイス集合変化)

| アーム | 誤ディスク指示 | 同一ディスク | 追加読み出し | バイトコスト |
|---|---|---|---|---|
| 計算式 (帰属を現在の devs から算出) | **2 / 4 / 6 / 17 / 19** | 0 / 6 / 2 / 2 / 0 | 0 | 0 |
| **ID保持** (mkfs 時に書き込み、以後は非計算) | **0 (5 シード全数)** | **0** | **0** | **4 バイト** |

- **コストは 4 バイト**：4 ゾーン × 1 バイトのデバイス ID。追加読み出し 0——IDはシステム構成と同番地にあり、システム構成はどうせ読み出す必要がある。
- **全数探索で 1 つ検証済み**：R∈[2,8] × devs∈[1,64] の計 504 セルのうち、計算式アームが衝突した **28 セルはすべて `devs < R`** であり、`devs ≥ R` でありながら衝突したセルは **0 セル** ⇒ ディスク追加方向では衝突せず、衝突はディスク脱落によって `devs < R` になった場合にのみ生じる。

### 対照の項目別判定

| 条項 | 判定 |
|---|---|
| 陽性対照、両アームで実行：デバイス集合が不変 | **合格**、両アームとも誤ディスク指示は 0 |
| 陰性対照：mkfs 時に R=4 > devs=3 | **合格**、両アームとも衝突 (各 1 回) ⇒ **ID保持は鳩の巣原理を解決できない**、解決するのは誤ディスク指示である |
| 5 シードの方向性 | **一致**：ID保持アームは 5 ラウンドすべて 0、計算式アームは 5 ラウンドすべて > 0 |

変異 4 件全検出：ID保持アームを現在の devs による計算に変更 / 誤ディスク指示で通信途絶ディスクを除外 / 素数を合成数に変更 / バイトコストをゼロ化。

### 本実験では答えられない半面

1. **カウントモデル**：システム構成なし、実ディスクなし、マウントなし、ファイル操作 0 箇所。「追加読み出し 0」は「IDがシステム構成内に存在し、システム構成はどうせ読み出す必要がある」という前提に基づき算出したものであり、**実測 I/O ではない**。
2. **ディスク脱落の次元の損失はカバーしない**：ゾーンが配置されたディスクが失われればそれまでであり、E62 (ルートリング帰属：ID保持 vs 計算式算出) は帰属の正しさのみを判定する。
3. R とデバイス ID 幅は入力値であり計測値ではない。

### 前提条件

なし。純粋なカウントモデル。
