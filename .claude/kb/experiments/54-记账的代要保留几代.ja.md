## E54 記帳の「世代」は何世代保持すべきか —— 実行済み (2026-08-30、N=5 ラウンドバイト一致、単体テスト 8 件 / 変異 6 件全捕捉)：**案甲と案丙は2つの候補ではない**、真に決定すべきは K のみ

[中文](54-记账的代要保留几代.md) · [English](54-记账的代要保留几代.en.md) · **日本語**

**ユーザーが「世代が必要」と決定した後、D5 (スナップショット・領域会計メカニズム) 確定項目 2 は案甲と案丙のみとなった**：

| 候補 | 「世代」に何を採用するか |
|---|---|
| 案甲 | チェックポイント番号 (D16 (パブリッシュセマンティクス) の txg)、**破棄しない** |
| 案丙 | 直近 K 世代のみを保持、K にはルートリング深さを採用 |

E54 (記帳の「世代」は何世代保持すべきか) は 2 つの事項を測定する：**双方の key 数の増大傾向**、および**案丙の破棄処理に走査が必要か否か**——
案丙の破棄処理に走査が必要か否かは生死を分かつ判定基準である：`.claude/rules/fs-design.md` 第 1 項目は
「ランタイム決定パスにおいて走査を禁じ、コストはディスク容量に伴って増大してはならない」と明令している。

### 何を測定するか

| # | 測定量 |
|---|---|
| 1 | チェックポイント数に伴う key 数の増大 (案甲 vs 案丙)、統計量数 × K × チェックポイント数をスキャン |
| 2 | **1 世代破棄時にアクセスされる key 数**、および**それがディスク容量に依存するか否か** |
| 3 | チェックポイントごとの記帳書き込み増幅 (案甲は書き込みのみ、案丙は書き込み + 削除) |
| 4 | **案甲と案丙が同一のパスか否か**：案甲に増分破棄ルールを付与した場合、案丙と key 数がセルごとに一致するか |

### 判定基準 (実行前ハードコード)

| # | 判定基準 |
|---|---|
| 1 | **案丙の key 数はチェックポイント数と無関係** (傾き 0)；**案甲の傾き = 統計量数** |
| 2 | **案丙の破棄コストはディスク容量と無関係**——コスト計算式に容量が含まれるか否かを判定基準とし、含まれれば `.claude/rules/fs-design.md` 第 1 項目違反と判定 |
| 3 | 案甲 + 増分破棄 と 案丙 の key 数が**セルごとに同一** ⇒ 「同一パスの 2 つの表現」と記録；異なる場合 ⇒ 相違点を記録 |
| 4 | K の下限は**ルートが最大何世代ロールバック可能か**により提示：E53 (丸ごと1台のディスク喪失後にルートリングがマウントできるか) の実測最悪ロールバックは **1**、E50 (ルートリングスロット数の上下限) が提示した総スロット数は N ⇒ 2 つの候補下限をそれぞれ計算 |

### どのような場合を失敗とするか (実行前ハードコード、実行後変更不可)

| 条項 | トリガー時の判定方法 |
|---|---|
| **陽性対照**：K = ∞ のとき案丙は案甲に縮退しなければならない (傾きが統計量数になる) | 縮退せず ⇒ モデルが K に基づき計算していない、**ラウンド全体無効** |
| **陰性対照**：統計量数 = 0 ⇒ 双方の key 数は恒常的に 0 | 非 0 ⇒ **ラウンド全体無効** |
| **案丙の破棄に走査が必要** | **忠実に記録し案丙を淘汰**——key 数がどれほど良好でも第 1 項目違反となるため |
| 双方がセルごとに同一 | **「2つの候補ではない」と忠実に記録**、強引に差異を捏造してはならない |

### 本実験で答えられない半分

1. **これはカウントモデルであり実装ではない**、E50 (ルートリングスロット数の上下限) / E52 (2つのマルチ書き込みヘッド機構の運用コスト) と同一の制約：ファイル操作 0 箇所。
2. **統計量がいくつ存在するか**は入力であって測定値ではない——本プロジェクトにはまだ統計量一覧が存在しない (D5 (スナップショット・領域会計メカニズム) 確定項目 1 も未確定)。
3. **write buffer のマージをモデル化しない**：同一チェックポイント内で同一統計量に対する複数回の更新はバッファ内で 1 つにマージされるが、
   E54 (記帳の「世代」は何世代保持すべきか) は「チェックポイントごと・統計量ごとに 1 エントリ」として計算しており、**上限値である**。

### 前提条件

なし。純粋なカウントモデル。

### 実測 (2026-08-30、N=5 ラウンドバイト一致)

#### 結果 1：**案甲 + 増分破棄ルール ≡ 案丙、セルごとに一致**

4 段階の統計量数 × 5 段階のチェックポイント数 × 3 段階の K (60 セル) を網羅スキャン：
`a_with_discard` と `scheme_c` は**全セルで一致** (`a_and_c_identical_with_discard=1`)。

⇒ **これらは 2 つの候補ではなく、同一パスの 2 つの言い回しである**：
案甲は「世代にチェックポイント番号を採用」、案丙は「直近 K 世代のみ保持」と主張している——
しかし「世代に何を採用するか」と「何世代残すか」は**2つの直交する問い**であり、E54 (記帳の「世代」は何世代保持すべきか) より前には二者択一として記述されていた。
⇒ **決定すべきは K のみである。**

#### 結果 2：破棄しないコストは非有界、破棄するコストは定数

| | key 数 (64 統計量、100 万チェックポイント) | チェックポイント数に対する傾き |
|---|---|---|
| 破棄しない (案甲の文字通りの形態) | **64 000 000** | **= 統計量数** (8 / 64 / 512 の 3 段階でセルごとに検証済み) |
| 直近 K = 8 世代を保持 | **512** | **0** |

#### 結果 3：破棄は増分処理であり、**`.claude/rules/fs-design.md` 第 1 項目を満たす**

1 世代破棄時にアクセスされる key 数 = **統計量数** (K=8、64 統計量、100 万チェックポイント時で **64**)、
**チェックポイント数とは無関係、ディスク容量とも無関係** (`discard_depends_on_capacity=0`)。

メカニズム：`(統計量, 次元タプル, 世代)` において「世代」は key の一部であり、破棄対象の世代は**計算可能** (現世代 − K)、
**探索不要** ⇒ スキャンではなくポイント削除。
⇒ **第 1 項目の「走査を禁じ、コストはディスク容量に伴って増大してはならない」を満たす。**
代償として、チェックポイントごとの記帳書き込み回数は `統計量数` から `統計量数 × 2` (書き込み 1 回 + 削除 1 回) になる。

#### 結果 4：K の下限は「ルートが最大何世代ロールバック可能か」により与えられる

| 出典 | ロールバック深さ | K 下限 | 64 統計量下の key 数 |
|---|---|---|---|
| E53 (丸ごと1台のディスク喪失後にルートリングがマウントできるか) **実測**最悪ロールバック | 1 | **2** | **128** |
| E50 (ルートリングスロット数の上下限) の総スロット数 (保守的：生存スロットはいずれも選ばれ得る) | 8 | **9** | **576** |

⇒ **2 つの下限は 4.5 倍の差があるが、いずれも定数であり、非破棄の路線より 5 オーダー小さい。**

#### 対照の逐条判定

| 条項 | 判定 |
|---|---|
| **陽性対照**：K = ∞ ⇒ 案丙が案甲に縮退 | **合格** (双方とも 64 000 000) |
| **陰性対照**：統計量数 0 ⇒ 双方とも恒常的に 0 | **合格** |
| 案丙の破棄に走査要 ⇒ 案丙淘汰 | **発生せず**：破棄コスト = 統計量数、式にディスク容量なし |
| 双方がセルごとに同一 ⇒ 「2つの候補ではない」と記録 | **発生、忠実に記録済み** |

### 結論

1. **「世代に何を採用するか」と「何世代残すか」は直交する問い**であり、E54 (記帳の「世代」は何世代保持すべきか) 以前は二者択一として記述されていた。
   世代にチェックポイント番号を採用 + 増分破棄ルールを付与することは、「直近 K 世代のみ残す」こと**そのもの**である。
2. **破棄は第 1 項目を満たす**：ポイント削除、コスト = 統計量数、ディスク容量とは無関係。
3. **K の下限は「ルートが最大何世代ロールバック可能か」に縛られる**：実測計測条件では K ≥ 2、保守的計測条件では K ≥ ルートリング総スロット数 + 1。
4. ⚠️ **key 数の絶対値は依然として統計量数に依存する**が、本プロジェクトにはまだその数値が存在しない
   (D5 (スナップショット・領域会計メカニズム) 確定項目 1 も未確定) ⇒ K 下限の表の 128 / 576 は **64 統計量で計算した例示**であり、予測値ではない。
