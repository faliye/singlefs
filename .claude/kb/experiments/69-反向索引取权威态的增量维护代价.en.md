### Definitions Read Verbatim (No Modeling on Impression)

Verbatim from D21 (Boundary Between Authoritative and Derived States) "Self-containment turns half of reverse mapping into O(1)":

> Units carry "whom I belong to" ⇒ "which object occupies this physical location" requires reading only that single unit, without needing an reverse index tree.
> ⚠️ **Only half, however.** Under sharing (snapshots / reflink / deduplication), a unit may have **multiple** referrers,
> which a fixed-length unit header cannot accommodate. ⇒ **Reverse index is still needed, but its remit narrows**:
> narrowed from "answering all reverse queries" to "answering the shared portion".

⇒ **The tested object only records "the shared portion"**, not all reverse mappings.
Per the same section, D21 (Boundary Between Authoritative and Derived States) settled item 1 also wrote verbatim: if derived ⇒ balance / GC cannot run until index rebuild finishes; if authoritative ⇒ must maintain incrementally alongside commits.

### What to Measure

Two arms, same workload:

| Arm | What It Is |
|---|---|
| **A: Authoritative state** | Reverse index entries **incrementally maintained** alongside transaction commits. Cost falls on commit path |
| **B: Derived state** | Not maintained; **rebuilt by full disk scan of unit self-describing headers** when needed. Cost falls in window before balance / GC |

Three quantities:

1. **Commit cost of Arm A**: Extra entries written per transaction. **Must be proportional to new shared references in this transaction**,
   invariant to disk capacity or total object count — otherwise it degenerates into traversal, precisely what
   `.claude/rules/fs-design.md` first cell expressly prohibits ("not slow, but having no answer at the instant queried").
2. **Rebuild cost of Arm B**: How many units full disk scan must read. **Must be proportional to total units on disk.**
3. **Availability window of Arm B**: Duration during which balance / GC stalls during rebuild, translated into unit counts.

### What It Cannot Answer

1. **Sharing reference density in real workloads lacks local origin** (snapshot frequency, reflink utilization, deduplication hit rate never measured)
   ⇒ Conclusion written solely as "how much cost per shared reference", **not written as "how much total cost"**.
   Same shape as E43 (Extension Point Byte Upper Bound) lacking demand side and E40 (Ciphertext Checksum Bit Width) lacking corruption rate.
2. **Concrete structure of reverse index unsettled** (D1 (Data Mobility / Reverse Index) only stated requirement, form unsettled) —
   modeled as a generic "physical location → referrer set" btree, **numbers will change under alternative structure**.
3. **Does not measure wall clock**: Counting model, measuring entry counts and units read, not elapsed time.
4. ⚠️ **Arm B side only modeled "how much to read for rebuild", not consequences of "balance / GC stalled during rebuild"** —
   listed as quantity 3 during proposal, actually omitted. D21 (Boundary Between Authoritative and Derived States) settled item 1 verbatim wrote that consequence,
   **it still has zero coverage.**
