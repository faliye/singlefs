### Worlds and Arms

Count model, zero file operations, no concurrency. "Disk" is mapping from placement → unit, allocator reuses released space via FIFO (reuse overwrites old header, default probability 50%, turned off as needed in target worlds); released placement must wait 2 more publishes before entering allocatable set (defer window, for rollback). Instance table row is three segments (instance code, chosen root txg T_pub, maximum transaction number W applied continuously from tail of chosen root): crash row = (i, chosen root txg, W) — recovery consistently chooses latest readable root, so usually inflight txg − 1, retreating one step if latest root slot corrupted; rollback row = (r_old, T_old, 0), intermediate instance = (i, 0, 0). Predicate partitioned by unit class (round 7 P2): data unit b ≤ T_pub ∨ n ≤ W; containers written only at checkpoint fixed point, b ≤ T_pub. W is prefix: records appended in transaction number order, transaction failure after issuing unit write triggers instance switch, no records with higher number appended.
Ground truth recorded by generator at moment each root is published, passing through zero reconstruction code. Code 3 container header holds only birth tree, model gives rebuild no more info than header holds (writer tree = birth tree).
