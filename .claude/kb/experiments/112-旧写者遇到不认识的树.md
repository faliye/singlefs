## E112 旧写者遇到不认识的树 —— 已跑（2026-09-06，纯算术，11 单测 / 9 条变异全抓）：**在挂得上的四个格子里 `Skip + Carry` 零静默结局，代价每代多写 2 行；⚠️ `Refuse` 两格同样零静默，是被 `mount_ok` 筛子请出天平的——它的代价没进静默这个判据**

**它要答的是 D8（核心索引结构） 已定项 8 收口清单里两条**：
「旧写者对不认识的记账维度」与「flags 其余 15 位取哪一侧」。
两条**不是独立的**：flags 取「跳过该条目」时，v1 **写者**也跳过那棵树，
于是它的记账行没人维护——正好落进第一条那个洞。所以一个实验交叉两组政策。

### 模型（跑前写死）

一个池有 `T_known` 棵 v1 认识的树与 `T_new` 棵 v1 不认识的树（新种类，或已知种类但置了 v1 不认识的 flags 位）。
一个 **v1 写者**挂上来发布 `G` 代。每棵树每代有 `R` 条记账行，key 带代号，**只保留最近 K 代**。

**两组政策交叉**：

| flags 政策 `F` | 含义 |
|---|---|
| `Ignore` | 忽略未知位，按已知语义继续解释这条条目 |
| `Skip` | 按「不认识这棵树」跳过该条目（与未知种类同档） |
| `Refuse` | 拒绝挂载 |

| 记账政策 `C` | 含义 |
|---|---|
| `Carry` | 写者把它不认识的记账行**原样带到新代**（值不变、只换代号） |
| `NoCarry` | 不带 |

### 判据（跑前写死，跑完不许改）

1. **每个格子报四个绝对值**，不许只报臂间比较：
   `misread_records`（被按错编码解释的记录数）、`rows_lost`（第 G 代时已经不存在的 v1 不认识的树的记账行数）、
   `rows_written_per_gen`（每代写多少行）、`i31_red`（I-3.1（已分配统计对得上） 会不会红，0/1）。
2. **`rows_lost` 要有独立算出来的期望值**：`NoCarry` 且 `G > K` 时应恰为 `T_new × R`，
   这个数由另一条闭式算术给出，不由模拟计数得来，两者必须相等。
3. **静默性要能被数出来**：一个结局是「静默」当且仅当 `misread_records > 0 ∧ i31_red = 0`
   或 `rows_lost > 0 ∧ i31_red = 0`。**逐格报静默结局数**。
4. **写代价要报绝对值**：`Carry` 相对 `NoCarry` 每代多写多少行，按 `T_new × R` 报，不报百分比。
5. **`Refuse` 那一列要报它的代价**：v1 写者挂不上的代数 = `G`（全部），
   以及这与 D15（格式冻结政策） 已定项 2「新增 keyspace ⇒ compat」是否相容（0/1）。

### 失败条款（跑前写死）

| 条款 | 触发时怎么判 |
|---|---|
| **阳性对照甲**：`Skip + NoCarry` 且 `G > K` 时 `rows_lost` 必须 > 0 | 不成立 ⇒ 代际丢弃这一维没进模型，**整轮作废** |
| **阳性对照乙**（`Ignore` 臂专用）：`Ignore` 下 `rows_lost` 必须 == 0 **且** `misread_records` > 0 | 不成立 ⇒ 「自以为认识」这一维没进模型，**整轮作废** |
| **阳性对照丙**（`Refuse` 臂专用）：`Refuse` 下 `mount_ok` 必须 == 0，且 `rows_lost` 与 `misread_records` 都必须 == 0 | 不成立 ⇒ 拒绝挂载这一维没进模型，**整轮作废** |
| **阴性对照**：`Carry` 且 `G > K` 时 `rows_lost` 必须 == 0 | 不成立 ⇒ 搬运这一维没进模型，**整轮作废** |
| **阳性对照二**：`Ignore` 下 `misread_records` 必须 > 0 | 不成立 ⇒ 误读这一维没进模型，**整轮作废** |
| **反向接受条款**：若 `Skip + Carry` 的静默结局数 **不是**全表最小，如实写，并按最小的那个格子改结论 | —— |
| **反向接受条款二**：若 `Carry` 的每代多写行数超过 `T_known × R`（即搬运比写者自己那些树的账还贵），结论改成「搬运不划算，要另找出路」 | 照实写 |

**跑之前写下的接受条款**：主 agent 目前倾向 `Skip + Carry`。
**若 `Skip + Carry` 的静默结局数不是最小，或它的写代价超过反向接受条款二那条线，就改结论**——
这句话在跑之前写下，跑完不许改。

⚠️ **这三条阳性对照是 2026-09-06 建档当日、跑之前改过一次的**，改前只有一条「`NoCarry` 且 `G > K` 时 `rows_lost` 必须 > 0，任一 `F` 下不成立即整轮作废」。改的理由：`Ignore` 臂下写者**自以为认识**那棵树、照样维护它的行 ⇒ `rows_lost` 合法地等于 0，原条款会因此把一个正确的结果判成整轮作废。**这是「阳性对照必须对每一条被测的臂都跑」那条纪律的另一面**——每条臂要跑的对照**不是同一条**，照抄一条会误伤。改动发生在**任何数字出现之前**，改后不许再动。

### 关键的模型前提（现查，2026-09-06）

**今天只有一个统计量带树维**：D5（快照 / 空间记账机制） 已定项 4 第 12 项「inode 号水位」，逐字「**带**（只为可写头维护）」——第 8 / 9 项已于同日撤回。
⇒ **一棵 v1 不认识的树，只有当它是可写头时才有记账行可丢**；不是可写头就一行都没有，`NoCarry` 无害。
⇒ 丢了之后**谁会发现**：I-9.11（可写克隆头有水位行） 逐字「每个可写克隆头的树 ID 在记账里都有『inode 号水位』行」，而它**未实现** ⇒ 要分开报「按规范会不会被抓」与「今天会不会被抓」两个数。

### 实测（2026-09-06，纯算术，11 单测 / 9 条变异全抓）

**口径与复跑**：代码 `research/e7-index-bench/src/bin/e112_old_writer_unknown_tree.rs`
（`cargo run --release --bin e112-old-writer-unknown-tree`），
产物 `research/results/e112-old-writer-unknown-tree-2026-09-06.out`（11 行，收尾 `emitted=11`），
变异表 `research/mutations/e112_old_writer_unknown_tree.tsv`、日志 `research/results/e112-mutate-2026-09-06.log`，
已挂 `research/scripts/replay.sh`（复跑命令 `bash research/scripts/replay.sh` 加上本实验的编号）。
参数：`t_known=12 h_known=6 t_new=4 h_new=2 r_tree_dim=1 r_pool=11 k_keep=4 g_gens=10 records_per_new_tree=1000`。

| 格子 | 挂得上 | 误读记录 | 丢行 | 每代写行 | 今天静默 | 按规范静默 |
|---|---|---|---|---|---|---|
| `Ignore + Carry` | 是 | **4000** | 0 | 19 | **1** | **1** |
| `Ignore + NoCarry` | 是 | **4000** | 0 | 19 | **1** | **1** |
| **`Skip + Carry`** | 是 | 0 | 0 | 19 | **0** | **0** |
| `Skip + NoCarry` | 是 | 0 | **2** | 17 | **1** | 0 |
| `Refuse + Carry` | **否** | 0 | 0 | 0 | 0 | 0 |
| `Refuse + NoCarry` | **否** | 0 | 0 | 0 | 0 | 0 |

⚠️ **六个格子只有四个不同的结局**：`Ignore` 两格与 `Refuse` 两格各自逐字段相同——搬运政策在这两条 flags 政策下**没有作用点**（`Ignore` 下写者自以为认识、那些行本来就在它的维护范围里；`Refuse` 下它根本没挂上）。⇒ **搬运政策只在 `Skip` 下才是一个真选择**，而这正是「两条政策不独立」那句话的定量形态。报六格是为了让这个退化本身看得见，不是六个独立观测。
- **判据 2**：`rows_lost` 与独立闭式在全部 6 × 4 个（格子 × 代数）取样点上逐格相等。
- **判据 4**：搬运每代多写 **2 行**（`Skip` 两臂之差），写者自己的账 **17 行**，
  反向接受条款二的阈值 `T_known × 12 = 144` ⇒ **不触发**。
- **判据 5**：`Refuse` 下 v1 写者 **10 代全部挂不上**，且与 D15（格式冻结政策） 已定项 2
  「新增 keyspace 对旧读者只是看不到新树 ⇒ compat」**不相容**（产物里 `compat_with_d15_item2=0`）。
- **代数边界**：恰好 K 代不丢，K+1 代丢 2 行——off-by-one 由单测钉死。

### 结论（与跑前写死的接受条款对照）

跑前写的是「主 agent 倾向 `Skip + Carry`；若它的静默结局数不是最小，或写代价超过阈值，就改结论」。
**两条都没触发**：`Skip + Carry` 的静默结局数是 **0**，写代价 2 行远低于 144。⚠️ **但「全表唯一」这句话是错的，产物自己就写着**：`Refuse_Carry` / `Refuse_NoCarry` 两行同样 `silent_today=0 silent_by_spec=0`。六格里三格零静默，`Skip + Carry` 只是**挂得上的那些里**唯一的一个——把 `Refuse` 请出天平的是源码里那道 `if o.mount_ok` 筛子，不是它的表现。⇒ **「按静默最少选」这个选法本身不给「挂不上」定价**，判据 5 的 `unmountable_gens=10` 是单独报的、没进那个比较。
⇒ **结论维持**：flags 未知位取「跳过该条目」，写者把不认识的记账行原样带到新代。

⚠️ **三条实测顺带得到的、不在原问题里的结果**：

1. **`Ignore` 按规范也是静默的**（`silent_by_spec=1`）——不变量清单里**没有**抓「记录被按错编码解释」
   那一条。这不是 `Ignore` 输在别处，是它输的那一格**根本没人看**。落点 C156（记录编码误读没有不变量）。
2. **`Skip + NoCarry` 只在今天静默**（`silent_today=1` 而 `silent_by_spec=0`）：
   丢的是可写头的「inode 号水位」行，I-9.11（可写克隆头有水位行） 正对着它，**而它未实现**。
   ⇒ 实现 I-9.11（可写克隆头有水位行） 会把 `NoCarry` 从「静默错误」降级成「会被抓的错误」，
   但**不会**让它变对——`Carry` 仍然是丢 0 行对丢 2 行。
3. **暴露面很窄**：今天只有一个统计量带树维，且只为可写头维护
   ⇒ 一棵 v1 不认识的树，**不是可写头就一行都没有**，`NoCarry` 对它无害。
   ⚠️ **这一格会随统计量清单变宽**：再加一个带树维的统计量，`NoCarry` 的丢失量就按树数长。

### 口径

纯算术 / 离散模拟，无 I/O。**同一个二进制跑 N 遍必然一模一样**，
所以轮数不构成证据强度，证据强度来自变异测试与钉死绝对值的断言
（`.claude/singlefs-ai-sop/rules/test-discipline.md`「单次观测不算数」那条的确定性例外）。
