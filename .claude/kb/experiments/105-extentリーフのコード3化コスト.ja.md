### 腕と判定基準 (実行前に確定、実行後の変更なし)

甲 = 現行形態：葉はコード 2 インデックス葉 (16 KiB、ファンアウト 196)；乙 = 腕 B：葉は 32 KiB コード 3 コンテナ (幅広レコード 1 コンテナあたり 393 件、幅狭レコード 628 件)、内部ノードは不変。k 回の分散更新でヒットしたノード数は L × (1 − (1 − 1/L)^k) で計算、w = 2。
1. 単一更新 (k = 1) で両形態それぞれ「書き出されたノード / ユニット数 × サイズ × w」、N ∈ {1e4, 1e6, 1e8}、ノードヘッダ 68 / 77 / 86 でセルごと；コンテナヘッダ 107 (ノードヘッダ 3 档は依然 68 / 77 / 86、72 / 81 / 90 への変更は C288 (マッピング key 確定に伴う連動変更が他決定へ未反映) 第 ⑦ 条に帰属)。
2. バッチ k ∈ {1, 10, 100, 1000}；飽和対照：k がある層のノード数よりはるかに大きい場合、ヒットしたノード数はその層のノード数に収束。
3. ポイント参照：木の高さ回のノード読み出し (甲) 対 木の高さ − 1 回のノード読み出し + 1 回の 32 KiB ユニット読み出し (乙)。
4. 陽性対照：コンテナを 16 KiB としレコード幅が同一の時、両形態の葉の層のコストは等しくなければならない (同一の物差し)。
5. 陰性対照：k = 0 ⇒ 両側とも 0。
6. 幅狭レコード 52 (第 4 ラウンド逆推レッグ 6.4 の概算：オブジェクト ID 8 + 誕生世代 8 + アンカーオフセット 8 + 位置エントリ 14 × 2) で別途 1 档を実行し感度を確認。

### 実測 (2026-09-05、成果物 116 行、`emitted=116`)

| N | 甲 木の高さ | 乙 木の高さ | 単一更新 乙 / 甲 | ポイント参照バイト 乙 / 甲 |
|---|---|---|---|---|
| 1e4 | 2 | 2 | 1.500 | 1.500 |
| 1e6 | 3 | 3 | 1.333 | 1.333 |
| 1e8 | 4 | 4 | 1.250 | 1.250 |

3 档のノードヘッダ (68 / 77 / 86) と 2 档のレコード幅 (83 / 52) はこれら 3 つの N においてセルごとに同一の比率：葉の層で乙は 32 KiB 対 甲の 16 KiB、木の高さは同一、比率は木の高さのみで決定。
**3 つのサンプリング点における比率はサンプリングの性質であり、モデルの性質ではない** (第 5 ラウンド逆推レッグ 6.4 が的中)：両側の木の高さはともに N の階段関数であり、甲は 196 × 196^k で階層が上がり、乙は 393 × 196^k で階層が上がる；その中間区間では乙が甲より 1 層低い —— 幅広レコードは N ∈ [38417, 77028] および [7529537, 15097488]、幅狭レコードは [61349, 123088] および [12024209, 24125248] (`name=equal_height` 行)、対数軸上でそれぞれ ln(393 / 196) / ln(196) = 13.2% を占める。それらの N において単一更新のバイト比は恒常的に 1.000、ポイント参照バイトは同一かつ乙がノード読み出しを 1 回減らす。解析的下限：コンテナファンアウト ≥ 葉ファンアウト ⇒ 乙は高々 1 層低い ⇒ 比率 ≥ 1、1 を下回らせるパラメータは存在しない。N ≤ 196 の時、甲は 1 層、乙は 2 層 (単一コンテナの上に依然としてコード 2 ルートノードが存在)、比率 2.0。
バッチは飽和点において両側が一致：1e4 件、k = 1000 の時両側とも全葉 / コンテナにヒット、26 個の 32 KiB コンテナ = 52 個の 16 KiB 葉、バイト比 1.000 (k = 100 時 1.141)。
1e6 件、ヘッダ 68、幅広レコードのバッチ：k = 1 → 1.333 (98304 対 131072 バイト)、k = 10 → 1.444、k = 100 → 1.662、k = 1000 → 1.782；k が大きいほど乙が不利となり、ヒットするコンテナが増加し各 32 KiB。
幾何構造：甲の葉ファンアウト 196、葉 5103 個；乙は 1 コンテナあたり 393 件、コンテナ 2545 個、内部 2 層。

- 判定基準 4：3 档のヘッダにおいて乙の葉層コストは甲とセルごとに一致；判定基準 5：k = 0 で両側 0；判定基準 2：k = 10⁶ の時ヒットしたノード数とその層のノード数の差 < 0.5%。
- 絶対値を固定するアサーション：`fanouts_are_absolute` (196 / 393 / 628 / 内部 196)、`single_update_is_pinned` (98304 対 131072；コンテナ 393 × 2545；葉 5103；木の高さ 3 対 3)、`equal_height_segments_are_pinned` (区間境界 38417 / 77028 / 7529537 / 15097488 および幅狭レコードの 61349 / 123088、区間内は書き込みバイトが一致、読み出しノードが 1 減少し、区間外は 1 + 1/木の高さに復帰)。
