## E27 D5のモデル化可能な3つのリスクパス —— 実行済み (2026-08-29)

[中文](27-D5三条可建模的风险路径.md) · [English](27-D5三条可建模的风险路径.en.md) · **日本語**

**[experiments.md](../experiments.md) E13 (D5 の 4 つのリスクパス) のうちモデル化可能な 3 つのパスを清算** (パス 1 / 2 / 4)。
⚠️ **パス 3（クラッシュ再生）は E27 (D5のモデル化可能な3つのリスクパス) には含まれない**：ブロック層の書き込み記録 + checker + クラッシュポイント再生 harness が必要であり、
その 3 者がいずれも存在しないためである。E27 (D5のモデル化可能な3つのリスクパス) は**それをカバーしたかのように偽装しない**。

### パス 1：3 つの境界、誤選択の結果は真に非対称である——ただし 3 つの独立した筆誤ではない

D5 (スナップショット / 領域台帳機構) の定義文原文：**ブロック b がスナップショット S に参照される ⟺ `birth(b) ≤ S.txg < death(b)`、左閉右開。**

| 規則 | データ喪失 | リーク | 本文との一致 |
|---|---|---|---|
| `birth ≤ S < death` (本文) | 0 | 0 | **3 / 3** |
| `birth < S < death` (左境界を厳格化) | **1** | 0 | 2 |
| `birth ≤ S ≤ death` (右境界を閉じる) | 0 | **2** | 1 |

**2 つの結論**：

1. **2 種の誤った選択の失敗方向は真に正反対である**——左境界の厳格化はデータ喪失のみを招き、右境界を閉じることはリークのみを招く。
   D5 (スナップショット / 領域台帳機構) 本文の「結果の非対称性」の表が実証された。
2. ⚠️ **しかし「右境界を閉じる」は 1 つではなく 2 つの境界を同時にヒットする。**
   `birth ≤ S ≤ death` は `death == S.txg` と `birth == death` の両セルにおいて「参照中」と判定される。
   ⇒ **本文は 3 つの境界を 3 行に列挙しており 3 つの独立した筆誤のように読めるが、実際には同一の筆誤が 2 行を同時にヒットする。**
   E27 (D5のモデル化可能な3つのリスクパス) の第 1 版は本文の表から推測して「1 回のリーク」と予測し、その場で赤に倒れた。D5 (スナップショット / 領域台帳機構) へ書き戻し済み。

### パス 2：deadlist カスケードマージ、birth によるバケット分割で約半分削減

測定対象は**検査対象エントリ数**であり、時間ではない。対象スナップショットは中央値を採用。

| deadlist エントリ | バケット分割なし | バケット幅 16 | バケット幅 64 | バケット幅 256 |
|---|---|---|---|---|
| 64 | 64 | **34** | 64 | 64 |
| 256 | 256 | **136** | 130 | 256 |
| 1024 | 1024 | **544** | —— | —— |

⇒ バケット分割により検査量を約 **53%** に圧縮；**バケット幅がエントリ数に等しい場合はバケット分割なしへと縮退する**（バケット丸ごとのスキップが不能）。
削減されるのはまさに「バケット全体が対象より古い」半分である——絶対値は計算可能：
1024 エントリ、バケット幅 64、対象が 512 ⇒ 先頭 8 バケットを丸ごとスキップ（各バケットヘッダ検査を 1 回支払う）+ 残り 512 エントリを 1 件ずつ = 520。

### パス 4：defer キューの永続化コスト

D16 (パブリッシュセマンティクス) 確定項目 15 は、チェックポイント内の解放がパブリッシュ前に割り当て可能集合に入ることを禁ずる
⇒ 本来「即時解放」されるはずの半分もまず defer キューに入る必要があり、それは余分な永続化書き込みとなる。

**エントリ数と I/O 回数は別個の指標であり、混同してはならない**：エントリ数は解放数のみによって決まり、
I/O 回数はエントリ数をパッキング幅で切り上げた値である（16384 エントリ、1 ブロックあたり 128 エントリ ⇒ 128 回；1 ブロックあたり 512 エントリ ⇒ 32 回）。

### 計測条件と既知の限界

- 純粋な論理と純粋なカウント。デバイスなし、トランザクション層なし。
- **パス 3 は完全に未実施**であり、D5 (スナップショット / 領域台帳機構) のクラッシュ再生リスクは依然としてカバレッジゼロである。
- パス 2 の deadlist エントリは birth に従い均等分布しているが、**実際の分布は未知**である——
  バケット分割の利益は分布に強く依存し、均等分布はバケット分割にとって最も有利な条件の 1 つである。
- パス 4 はエントリ数と I/O のみを数え、**defer キュー自体が占有する領域はモデル化していない**（それは E19 (defer ウィンドウ下での擬似 ENOSPC) の領分である）。
- コード `scripts/experiments/e27_snapshot_accounting_risk_paths.rs` (`cargo run --release --bin e27_snapshot_accounting_risk_paths`)、
  生の出力 `e27-d5-paths-2026-08-29.out`。3 ラウンドでバイト単位一致。

**エンジニアリング品質**：9 個の単体テスト、**8 つのミューテーションをすべて捕捉**、3 ラウンドでバイト単位一致。
