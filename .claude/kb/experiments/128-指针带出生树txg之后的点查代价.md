## E128 指针带出生 (树, txg) 之后的点查代价 —— 已跑（2026-09-10，15 单测 / 14 条变异全抓；**记账那一对四轮同向，inode 那一对四轮不稳定**）

**它要答的是 D19（块指针的结构与宽度预算） 已定项 7 欠的那一笔**：候选甲把指针头部 31 → 47，
连带把 inode 树内部条目 93 → 109、记账树内部条目 81 → 97，**这一步多付多少一次点查的 CPU 时间**。
2026-09-10 用户定案把那一格判「先不定、另走一轮」，理由逐字是
「甲的一样代价（E20（指针变宽的 CPU 缓存代价） 实测 67 字节条目在 16 KiB 节点上 2.22×）
**这一笔从没进过任何一条腿的材料**」。
E128（指针带出生 (树, txg) 之后的点查代价） **只给代价，不给判决**——判决要走三方
（`.claude/rules/three-way-inference.md`）。

### 为什么另立新号，不在 E20（指针变宽的 CPU 缓存代价） 上加臂

E20（指针变宽的 CPU 缓存代价） 的判据 2026-08-29 写死、产物已入库、`replay.sh` 已注册，
与 E95（老化的节点布局臂） 缺臂另立 E127（分裂合并之下组身份要不要存） 那次同一条理由。

**而且 E20（指针变宽的 CPU 缓存代价） 量的不是这一笔**：它的档位是 16 / 24 / 32 / 40 / 67 / 111，
本工程真实的两组是 93 → 109 与 81 → 97，**一档都不在其中**。
拿 67 与 111 那两个比值代替，是拿另一个量的数回答这一问。

### 判据、阈值、作废条款（写在任何一行测量代码之前）

原件 `research/prompts/e128-preregistration.md`，跑完一个字没改。四条：
① 六条臂各自的阳性对照（L1 档比 DRAM 档快 ≥ 2 倍），任一格不过整轮作废；
② **跨装置闸**——`xdev_67` 与 `xdev_111` 必须落回 E20（指针变宽的 CPU 缓存代价） 入库产物那两个数（差 ≤ 15%）；
③ 绝对值断言，槽数与树深逐档钉死，防「六条臂一起错」；
④ 跑 5 轮，要说「甲慢」得 5 轮都慢，要说「不慢」得 5 轮都不慢，都不满足就写「不稳定」。

⚠️ **跑前明写不设「慢多少算可接受」的阈值**：那个数属于判决不属于实验
（`.claude/singlefs-ai-sop/rules/test-discipline.md`「失败条款不许让结论不可证伪」）。
⚠️ **跑前明写接受相反结果**：原件逐字「若 `inode_jia` 比 `inode_bing` **快**，或两者差 **< 2%**：
我会写下「**甲的这笔缓存代价在 16 KiB 节点上不成立**」……**这是我接受的结果，不是要规避的结果**」。
**实测正是这一格。**

### 实测（产物 `research/results/e128-pointer-birth-cost-2026-09-10.out`，134 行、`emitted=134`）

**结论一：inode 树那一对**（93 → 109）**不稳定，E128（指针带出生 (树, txg) 之后的点查代价） 今天答不了这一格。**
跑了**四整轮**，前三轮都判「甲从不更慢」，第四轮判「甲每一轮都更慢」，方向相反。
**逐轮表**（复跑再翻向时往这张表加行）：

| 轮 | 产物 | inode 比值 | 判决 |
|---|---|---|---|
| 一 | 未留存（去掉 `tree_per_level` 之前那版源码）| 0.9686 | `0/5 jia_never_slower` |
| 二 | 未留存（`replay.sh` 校验轮，同上版源码）| 0.9655 | `0/5 jia_never_slower` |

| **四** | `e128-pointer-birth-cost-2026-09-10-rerun4.out` | **1.0885** | **`5/5 jia_slower_every_round`** |

⇒ 按 `.claude/singlefs-ai-sop/rules/test-discipline.md`「要说『通过』就得每轮都通过，要说『失败』就得每轮都失败……
两边都不满足，就如实说『不稳定』，不下结论」——**这一格记「不稳定」，不下结论。**

第三轮与第四轮的产物逐字：

⚠️ **一个未验证的候选解释，写下来但不采信**：第四轮整机偏慢——跨装置闸那两档比 E20（指针变宽的 CPU 缓存代价） 的基准高 4.9% 与 5.9%
（前三轮是 −2.4% 到 +2.6%），而 `inode_jia` 的工作集（929 MB）比 `inode_bing`（790 MB）大，
本机当时有别的会话在跑构建。**这只是候选**：E128（指针带出生 (树, txg) 之后的点查代价） 没有记录当时的机器负载，
所以「整机偏慢导致大工作集那条臂多吃亏」这句话今天**证不了也否不掉**。落点 C252（E128 的 inode 那一对不稳定，装置没有隔离负载）。

⚠️ **这次翻向是被逐字节比对抓住的，不是被区间断言抓住的**：`replay.sh` 的 `strip_timing` 有意**不抹** `verdict=`
与 `rounds_jia_slower=` 两个字段（它们是结论不是计时）⇒ 判决翻向在结构比对那一步就判红。
若当初把它们一并抹掉，第四轮会报「仅计时不同，结构一致，符合声明」而绿着过去。

**结论二：记账树那一对**（81 → 97）**四轮同向，甲每一轮都更慢**，比值 1.0179 / 1.0454 / 1.0210 / 1.0357。
⇒ 这一条按同一条纪律**站得住**：四轮都判同一个方向。产物逐字（第三轮）：

**结论三：跨装置闸四轮都过**，四轮的偏差是 −2.4% / +2.6%、−1.9% / +3.0%、−0.2% / +1.4%、**+4.9% / +5.9%**。

### ⚠️ 第三轮产物里有一处非单调，如实摆着，没有解释

第三轮里，同在 16 KiB 节点、同为树深 4 时，93 字节条目（586.89 ns）**比 109 字节（572.95 ns）
和 111 字节（555.26 ns）都慢**；**第四轮这处非单调消失了**（612.09 对 667.30）。E20（指针变宽的 CPU 缓存代价） 那一列在 67 → 111 之间是单调涨的，这里不是。
一个未验证的猜想是节点按 16384 对齐、条目跨步与缓存组数相互作用。
⚠️ **它跨轮不复现，所以它与 E20（指针变宽的 CPU 缓存代价） 的 8 KiB 反常不是同一性质**——
那个六轮稳定，这个四轮里出现三次、第四轮没有。**两者不许并列引用。**

### 这份模型是 E20（指针变宽的 CPU 缓存代价） 那份的手抄件，靠跨装置闸兜着

`Tree` / `generate_lookup_keys` / `bench` 三段与 `e20_fanout.rs` 同源，没有并成一份。
理由是 E20（指针变宽的 CPU 缓存代价） 的变异表按**原文匹配**改它自己那个文件，
移走那三段会让 E20（指针变宽的 CPU 缓存代价） 已入库的 5 条变异证明当场失配。
代价是手抄，兜底是跨装置闸。⚠️ **闸只钉 DRAM 档那两个点**，抄漏在别的档上它不会说话，
落点 C249（两套点查模型手抄同一段布局代码，闸只钉两个点）。

### 口径与复跑

纯 CPU / 内存实验，按数组铺开的隐式 B 树，节点内二分，条目按条目宽跨步，
条目第二个 8 字节存子节点号（形成依赖式载入链）。**固定 key 数、不固定工作集**——
条目变宽 ⇒ 工作集变大 ⇒ 被挤出缓存，这才是要问的。
本机每核 L1d 48 KiB、L2 1 MiB、L3 32 MiB、缓存行 64 字节。
工作集四档 2¹¹ / 2¹⁵ / 2¹⁹ / 2²³ key，每档 5 轮、每轮取 3 次的最小值，`iters = 2000000`。

代码 `research/e7-index-bench/src/bin/e128_pointer_birth_cost.rs`
（`cargo run --release --bin e128-pointer-birth-cost -- 2000000`），
原始输出 `research/results/e128-pointer-birth-cost-2026-09-10.out`（第三轮，入库那份）
与 `research/results/e128-pointer-birth-cost-2026-09-10-rerun4.out`（第四轮，方向相反的那份）。
前两轮跑的是去掉 `tree_per_level` 之前的源码，**产物未留存**。

```bash
cd research && bash scripts/replay.sh E128
```

⚠️ **E128（指针带出生 (树, txg) 之后的点查代价） 的复跑会间歇性判红，这是有意的，不是噪声。**
inode 那一对的 `verdict=` 参与逐字节结构比对，而它本身不稳定 ⇒ **翻一次向就判红一次**。
判红时该做的**不是**去调宽容差，是：把新跑那一次的比值与判决**添进 E128（指针带出生 (树, txg) 之后的点查代价）
「结论一」里那张逐轮表**（四轮就变五轮、六轮……），然后决定要不要换入库产物。
**每一次红都是一次新观测**——对一格记着「不稳定」的实验来说，这正是复跑该有的行为。
反过来把这两个字段抹掉会让它恒绿，而恒绿的那个版本什么也不证明。

`replay.sh` 的区间断言钉的是**四轮里稳得住的那些**：跨装置闸两格都要 `ok=true`；
记账那一对的比值要落在 (1.00, 1.10)。**inode 那一对不钉方向**——四轮里三轮一个方向、一轮相反，
钉哪一边都是把一条不稳定的观测写成断言。⚠️ 结构比对那一步仍然逐字比 `verdict=` 与
`rounds_jia_slower=`（`strip_timing` 有意不抹这两个字段）⇒ **判决再翻一次，复跑仍会判红。**
