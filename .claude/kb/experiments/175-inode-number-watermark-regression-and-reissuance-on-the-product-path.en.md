### What was done

- **Three readings** (registration section six): S1 ledger: after each step list readable roots using `singlefs_core::recovery::readable_roots`, rebuild each root key only once with `rebuild_version`, read that version's accounting watermark and all inode-tree (number, birth generation) pairs, recording for each number “birth generations seen → roots that held it”. S2: after each step run `singlefs_checker::walk::check_pool_image` on the image without stopping on failure, counting I-9.29 (only one birth generation per number) and I-9.6 (Watermark Greater Than Maximum Number of Both Locations) as holds / inapplicable / partially unjudged / violated. S3: two paths for roots abandoned by crash recovery: path 1 uses the newest root's instance table with `publish_is_abandoned_by_the_instance_table`; path 2 is the step ledger (created each mount: the new instance attaches to the model root ring's latest root before that step; roots with larger txg in the same old instance are abandoned).
- **Arms**: P uses frozen-copy `crates/` unchanged, byte-identical to the workspace at copy time (`baseline-frozen-crates.out` says `main_before_copy_equal=true main_after_copy_equal=true`). V1 changes the rollback watermark in `crates/singlefs-core/src/mount.rs` to the target version's; V2 replaces `} + new_inodes_of_this_publish;` with `} + 0;` in `crates/singlefs-core/src/transaction.rs`. V717 (named in `crates/mutations.tsv` “actual implementation three (D23 settled item 14 watermark): rollback inode watermark uses only roots readable in the ring, without max against the in-memory current version”) was registered to run only if Q6 > 0. Q6 is zero in every family in both segments, so record “same output as P (inferred from Q6 = 0), not run”. Line numbers and hit counts for all three anchors are in three `name=mutation_anchor` rows of `baseline-frozen-crates.out`; patches are verbatim in `patch-V1.diff`/`patch-V2.diff`. Before applying each arm and after restoration, verify `baseline-frozen-crates.sha` at the copy root (nine `name=arm_check` rows, `listed_mismatch=0 extra_files=0`); each arm binary was compiled once and shared between segments (three `name=arm_binary` rows).
- **Execution**: `HistoryExecution { per_step_checker: Skipped, device_width: FourGibibytes（G-small 换 UnitAreaOf384Slots）, space_admission: JudgedByTheFormula }`; do not call `set_inode_number_watermark_source` or add `SharedFaultPlan`. Five worker threads (dispatch limit) claim work in ascending sequence number, merge in sequence order, matching single-thread output verbatim (quick tier `one_thread_and_three_threads_give_the_same_lines`). Each history's wall clock is measured in the apparatus process (`elapsed_ns` in result row); rerunning an interrupted command resumes and skips sequence numbers already present. Each result file starts with `# code_baseline=…`; resume refuses a different header, summary requires all inputs share a `code_baseline` and includes it in every summary row (revision 2 item 2).
- **Trials** (revision 2 item 5): first eight F2 P seeds, 488 steps, average 281.86 ms/step/thread, projecting ~54 minutes for segment one; first four G-long P seeds, 604 steps, 272.74 ms/step, projecting ~45 minutes for segment two.
