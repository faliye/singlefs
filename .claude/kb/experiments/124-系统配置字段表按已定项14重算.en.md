### Criteria (Hardcoded Before Run, Never Modified After)

1. **Nonce Watermark Recalculation Gate**: According to 96-bit nonce of D18 (Information Carried in a Block) settled item 14, what watermark width does I-6.5 (Nonce Watermark Is Monotonic) require? **Report absolute value**, and report how many bytes it differs from 8 bytes used by E100 (Three-Segment Geometry of System Configuration) / E115 (Completeness and Byte Budget of System Configuration Field Table). After difference enters budget, **re-report cell by cell on 512 / 4096 tiers "fits / overflows by how many bytes / how many tear states"**, in absolute values.
2. **`devs` Redundancy Two Arms**: Arm A takes device table unit as **Code 3 packed record container** (record count 2 bytes at offset 69 in header) ⇒ `devs` in slot can be omitted; Arm B takes **Code 2 index node class** (no record count in header) ⇒ cannot be omitted. **Both arms report absolute bytes in slot**, reporting difference alone is forbidden. ⚠️ **Both arms must be run** (`.claude/singlefs-ai-sop/rules/test-discipline.md` "Positive control must be run on every tested arm").
3. **Synthesis Arm Recalculated Under New Input**: Synthesize four indirect pointers (device table / tree table / master key slot / central mapping) into one indirect directory unit, leaving only one pointer in slot, reporting absolute bytes and tear states for all four cells (`wide` × `map_sep`).
4. **Cross-Apparatus Reconciliation**: Recompute `candidate_bytes` and `plus_devtable_ptr` of E115 (Completeness and Byte Budget of System Configuration Field Table) using E124 (System Config Field Table Recomputed per D18 Settled Item 14) own code; both numbers must match E115 (Completeness and Byte Budget of System Configuration Field Table) artifact verbatim (361 / 420). Judged red if mismatched. This follows `.claude/singlefs-ai-sop/rules/show-me-test.md` "When two apparatuses compute the same quantity, a check must force them to land on the same number".
5. **Absolute Value Assertion**: Every conclusion in criteria 1/2/3 must have an assertion pinning absolute values, mutual comparisons between arms alone forbidden (`.claude/singlefs-ai-sop/rules/test-discipline.md` "Comparing multiple arms only against each other cannot detect when all arms are wrong together").

#### Criterion 1: Nonce Watermark Requires 12 Bytes, 8 Used by E100 / E115 Is Short by 4

Artifact first two lines verbatim:

```
name=watermark_gate decided_nonce_bits=96 required_bytes=12 e100_used=8 consistent=0 short_by=4
name=watermark_gate_control fed=12 consistent=1 short_by=0
```

⇒ **I-6.5 (Nonce Watermark Is Monotonic) requires "recorded nonce watermark > maximum nonce ever appeared across entire disk",
and following D18 (Information Carried in a Block) settled item 14 that nonce is full 96 bits** ⇒ watermark must be at least 12 bytes.
The line in E100 (Three-Segment Geometry of System Configuration) source code was verbatim `("nonce_watermark", 8)`, representing only 64 bits.
⚠️ **8 bytes was not wrong prior to settled item 14** —— at that time plaintext header held nonce code, and watermark applied to code;
it was settled item 14 combining code and nonce into the identical quantity that altered the input for this cell.

⚠️ **This is not "an assertion was written wrong in E100 / E115"**: neither had an assertion stating what width watermark should be,
they simply copied the candidate table of that time. **Nothing speaks to this cell when settled item 14 lands** ——
an owed check of identical shape is registered in C178 (system configuration required fields table relies on manual copying).
