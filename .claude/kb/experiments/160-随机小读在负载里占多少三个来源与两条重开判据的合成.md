**岔路单第 2 行——两条判据怎么合，第一段能判的部分：**

- **Q13（判据 1 与随机小读占比有没有关系）：读法 A 下无关。** 甲（6 个 ε 取样点，p_B 从 0 到 20%）与丙-规格
  （4 个取样点，reads_per_second 从 1 到 1 000 000）逐点算出的判据 1 值全部相同、都等于锚点 1.086：

  ```
  E7RESULT name=q13 weight_arm_all_equal=true weight_arm_reference=1.086000 declared_arm_all_equal=true declared_arm_reference=1.086000 reading=无关
  ```

  原因是甲、丙两类模型的 R 类恒为单一 4 KiB 请求，读法 A 的值只由 R 类内部尺寸混合决定，不进 p_B、p_N。
  这直接限定了 C357「两条判据落在同一根轴」这句话的射程：**它对判据 5 成立，对判据 1（读法 A）不成立**——
  判据 1 在来源之间会不会翻面，只能经由请求尺寸分布或队列深度，不能经由占比。乙 1（fio 定义值）的尺寸有混合
  （512 B 到 64 KiB），判据 1 值降到 1.064765（仍 < 1.136，未触发），但这是「同一个来源换了尺寸混合」，
  不是「同一个来源换了占比」，与 Q13 的读数不矛盾。
- **p_B < 1.0% 的实例——「相加」按上界给出结论：** C1 上界 = 锚点 − 1 = 0.086（C5 < 0，交叉点定义）。
  0.086 < 0.136（相加主阈值），所以只要来源的 p_B < 1.0%，「相加」在 T_sum = 0.136 时必不重开；
  T_sum = 0.05 或 0 时凭上界判不出（0.086 ≥ 两者），需要第二段实测 C1、C5 的真实值：

  ```
  E7RESULT name=additive_rule_demo load_level_cost=0.08 header_cost=0.07 threshold=0.136 reopens=true
  E7RESULT name=additive_rule_demo load_level_cost=0.08 header_cost=0.07 threshold=0.05 reopens=true
  E7RESULT name=additive_rule_demo load_level_cost=0.08 header_cost=0.07 threshold=0 reopens=true
  ```

  （这三行是相加规则算术本身的演示：`load_level_cost=0.08、header_cost=0.07` 是登记 5.4 节的真值表 f 行，
  不是任何来源的实测 C1、C5——今天没有 p_B < 1.0% 的真实实例：乙 1 的两种切点、丙-规格从 X*/2 起、
  丙-实测的全部 14 个配置，p_B 都 ≥ 0.5%，唯一落进 [0, 1.0%) 的是甲的部分 ε／ω 取样点，
  而甲今天没有真实权重，所以「p_B < 1.0%」这一支目前没有一个来源给出真实占比，只有理论上界推出的结论）。
- **四条合成规则在今天算得出具体占比的实例上：** 乙 1（两种切点）、丙-规格（X ≥ X* 起）、丙-实测（全部 14 个
  配置）的 p_B 都落在「越过」，判据 1（读法 A）在这些实例上恒为 1.086、恒不触发（B5 数列见下）。
  于是「先到先触发」「只看判据 5」在这些实例上都是重开，「只看判据 1」都是不重开，「相加」在这些实例上
  p_B ≥ 1.0% ⇒ 由上界推不出结论、要第二段实测。

### 它答不了什么

- **甲的真实占比**：D25（目标负载优先级） 没有数值权重，今天没有真实的 (w, b)；甲只给函数与取样点。
- **「相加」在 p_B ≥ 1.0% 时重不重开**：需要第二段本机新量的 C1（负载级设备时间比）、C5（含头相对补齐的
  代价），这一轮没有一个真实来源的 p_B 落在 < 1.0%，也没有第二段的实测代价，「相加」目前对所有算得出具体
  占比的实例都答不出（只答得出 p_B < 1.0% 时的上界结论，而这一支没有真实实例）。
- **判据 1 的锚点在本机今天成不成立**：这一轮全用 E58（校验和粒度的端到端代价） 的锚点 1.086，没有新量；
  F1 打不打中要第二段。
- **判据 5 在条款依据形态（头 133、AES-256-GCM）上的今天真实交叉点**：这一轮只用条款给的带
  [1.0%, 1.5%]，没有新量的交叉点；F2 打不打中要第二段。
- **乙的 Kavalanekar 2008 与三方比较论文六条来源的占比**：公开数据本身没有随机 + 小的联合统计，
  查了没有第二条独立路子能补，不是这一轮漏做。
