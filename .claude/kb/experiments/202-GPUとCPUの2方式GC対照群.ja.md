### 計測条件

- 生出力未保存：実験未実行。
- 1回の整理：1回の実行で GC スレッドが最初のバックグラウンドエントリ呼び出しから最後の呼び出し復帰までに行うすべての整理。
- GC 壁時計時間：GC スレッドでのバックグラウンドエントリ呼び出し前後の `std::time::Instant` 読み値の差分の総和。
- GC のホスト CPU 時間：各 GC 呼び出し前後の `clock_gettime(CLOCK_PROCESS_CPUTIME_ID)` 読み値の差分から同ウィンドウ内のフォアグラウンドスレッド増分を引いた値。
- 節約された CPU 時間：同一レベル・同一反復における CPU アームのプロセスメトリックから GPU アームのプロセスメトリックを引いた値。
- 反復回数：各セル・各アーム 5 回、中央値、最小値、最大値、中央絶対偏差を報告。

### 判定基準と失敗条項

- 判定基準：各容量レベルで「CPUモード - GPUモード」の差が測定され、正負および散らばりが示されること；陽性対照群で節約されたCPU時間が通常対照群より少ないこと。
- 失敗条項：GPUモードによるホストCPU節約時間が全容量段階で恒常的に <= 0 である場合、またはフォアグラウンドのfsyncレイテンシが限界を超えて劣化した場合に発動。
