### 做了什么

- **模型**：两块盘镜像、根环 R = 3 个区域（归属 0 / 1 / 0）× 每区 S 个槽，落点 txg mod 3 与 (txg ÷ 3) mod S；计数单位是块，覆盖写发布新占并放掉 d + c 块（d = 8，c = c_max = 5 或 10），空发布新占并放掉 c 块，放掉的块带释放代 = 发布的 txg，每记一条根按门槛 max(F_生效, 环里最旧有效根) 回收，抬 F 那一串回收出来的扣到这一串做完；根环表照冻结树分「有效根、挂载时读坏（带可能住过的最旧 txg 与能住的最大 txg）、挂载时读回全零」三类；进程内记根先重读钉着的槽；算上限那一遍读一次、知道住着根的槽重读仍坏就报抬 F 自己的错；一次准入最多 B = 8 次发布；用户发布要求空闲 − P保留 ≥ d + c，空发布与抬 F 那一串只要求空闲 ≥ c。
- **臂**：Q1 四条（照今天、推空B、推空W、不并），Q2 两条（全零不并、全零并）。推空B 在上限卡在读坏槽上（C并 ≤ F 而 C0 > F）时推一次不抬 F 的空发布、算进已推次数；推空W 推到卡住解开为止、推空不受 B 限、至多 3S 次；不并取 C0。
- **历史与读故障**：H1 崩溃、H2 抬过 F、H3 正常卸载、H4 覆盖写与空发布交替、H5 年轻环崩溃留洞（只给 Q2）；读坏三种 e（设备报错）、g（读得出而自证不过）、z（读成功字节全零），持续四种 P1（写掉就好）、P2（写了也坏）、T1（挂载里瞬时）、T2（坏到第一次抬 F 那一串做完）；池三种近满 k = 0、k = 2、宽松，保留池两种读法（代码读法 c、条款读法 10 + 7c）；S = 4 / 8 / 16、c_max = 5 / 10；每个读坏位置 j = 1..3S − 1 各跑一次挂载，每次挂载 J = 2 × 3S + 8 次覆盖写请求。
- **对照与零点**：每格另跑一次去掉读故障的挂载当零点（H1–H4 上四条 Q1 臂、两条 Q2 臂的零点逐项相同，装置核过）；因读坏多拒 = 两次被拒次数之差；F 越过的非空根数、少掉的状态数与回退候选数按真值盘面算（无读故障、每槽按真住着的内容读）。
- **修订**：第十二节 11 条，要点：PC1、PC3 的池从近满 k = 8 改成第一次请求就走抬 F 的近满 k = 0（k = 8 的池在 J 次请求里一次抬 F 都不走，读数写在产物里）；M5 的取样点换成单测里找到的一格（登记写的那一格在 H1–H4 第一次请求的算术上两个 B 读数相同）；M6、M9 的变异写成实现里真有的写法（M6a、M6b、M9）；补变异 M13–M15 与 Mm1–Mm7；Q2-2 对 H5 补与全零不并并排的位置级读数；PC4 的「强制走一次不够」取成第一次请求里每一轮都当不够。
