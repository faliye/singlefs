## E56 条带映射的算术在真设备上对不对 —— 已跑（2026-08-30，真 dm-stripe 设备）：**72/72 格全对**，素数步长 6 组全部落在互不相同的盘上

**它补的是 E54（丢一整块盘之后根环还挂不挂得上） 明写没验的那一半。**
E47（根环区域间距与失败域） / E49（根环几何的可行点） 的全部几何结论压在一条算术上：
逻辑地址 `p` 落在第 `(p / chunk) % devs` 块盘。
那条算术**此前只读过 Linux 源码（`raid0.c` / `raid5.c`），从没在设备上量过**；
而 E54（丢一整块盘之后根环还挂不挂得上） 的虚机里是 4 块裸盘、**没有条带**，
区域是手工一对一摆上去的 ⇒ 它验的是「后果」，不是「前提」。

### 要测什么

在**真的条带设备**上（`dm-stripe` 建在 4 个 loop 之上）：

1. **映射**：往逻辑地址 `k × chunk` 写一个唯一标记，回查它落进了哪个**后端文件**，
   与 `k % devs` 比对。扫 devs ∈ {2,3,4} × chunk ∈ {64 KiB, 512 KiB} × 12 个 `k`。
2. **素数步长**：区域 r 放在 `r × P × chunk`（P = 13，素数且大于设备数），
   回查 R 个区域是不是落在 R 块**互不相同**的盘上。

### 判据（跑前写死）

| # | 判据 |
|---|---|
| 1 | **每一格** `实测落盘 == k % devs`。任一格不符 ⇒ **E47（根环区域间距与失败域） / E49（根环几何的可行点） 的地址算术当场作废** |
| 2 | 素数步长下 R 个区域落在 **R 块互不相同**的盘上（devs ≥ R） |

### 怎样才算失败（跑前写死，跑完不许改）

| 条款 | 触发时怎么判 |
|---|---|
| **阳性对照**：步长取**非素数** 8（= 2³）时，devs=4 上四个区域必须**撞在同一块盘** | 不撞 ⇒ 测量分不开素数与非素数，**整轮作废** |
| 任一映射格不符 | **如实记录并作废那条算术**——这是E56（条带映射的算术在真设备上对不对）最有价值的可能结果 |
| `dmsetup` 建不起来 | 记 `name=skip`，**不许当成通过** |

### 实测（2026-08-30）

| 组合 | 映射对上的格数 | 素数步长下互不相同的盘数 |
|---|---|---|
| 2 盘 / 64 KiB | **12 / 12** | 2 / 2 |
| 2 盘 / 512 KiB | **12 / 12** | 2 / 2 |
| 3 盘 / 64 KiB | **12 / 12** | 3 / 3 |
| 3 盘 / 512 KiB | **12 / 12** | 3 / 3 |
| 4 盘 / 64 KiB | **12 / 12** | **4 / 4** |
| 4 盘 / 512 KiB | **12 / 12** | **4 / 4** |
| **合计** | **72 / 72** | 六组全部 all_distinct |

**阳性对照**：步长取 8（非素数）时，devs=4 上四个区域的 `distinct_devices = 1`
——**全部撞在同一块盘**，两档 chunk 都是。⇒ **测量分得开素数与非素数，那 6 组「全不同」不是白给的。**

### 结论

1. **`(p / chunk) % devs` 这条算术在真条带设备上成立**（72 格全对）
   ⇒ E47（根环区域间距与失败域） / E49（根环几何的可行点） 的地址算术**不再只是读源码读来的**。
2. **素数步长把区域摊到互不相同的盘上，在真设备上复现**
   ⇒ **E54（丢一整块盘之后根环还挂不挂得上） 明写没验的那一半补上了**：
   前提（区域落在不同盘）与后果（丢一块盘仍挂得上、回退 ≤ 1）现在各自有了真设备证据。
3. ⚠️ **仍未验**：**物理失败域**（控制器 / 背板 / 电源 / 固件批次）——那要真硬件，本机做不到。
