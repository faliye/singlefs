### What to Measure

**Enumerate "consumers of older generation roots" one by one, derive for each consumer its block reuse delay requirement, and answer in what unit the requirement is priced** — by generations (publish count), by wallclock time, or by external events. This is decisive: K in I-7.4 (recent K generations of blocks not reused) is counted in **generations**; if any consumer's requirement is in **wallclock**, under Path A (one generation = one fsync ≈ 0.36 ms), generation units cannot protect it.

The runnable half (counting model): simulate publish stream (2785 publishes/sec) + one slow consumer (scrub traversing generation K−1 root at N blocks/sec), scan K × scrub duration, count events where "consumer has not finished traversing, but blocks it references have already been reused"; consumers priced in generations verified identically to be constant zero.

### Criteria (Hardcoded Before Run)

1. **Enumeration completeness latch**: Consumer list must give origins (decision / invariant / owed check number) entry by entry, at least one cell per consumer in model; consumers discovered outside list after run => supplement list and rerun, no quiet omissions.
2. **Unit verdict**: Requirement of each consumer written as 3-way choice of (generations | wallclock | external event) with mechanism derivation; if wallclock priced consumer exists and its requirement under Path A publish rate exceeds K generation window => **verdict: "unit of I-7.4 (recent K generations of blocks not reused) in generations cannot protect it under Path A"**, recorded truthfully, placement handed over to decide (do not alter invariants on the spot).
3. **Positive control**: Root selection rollback cell must derive "exactly 1 generation + verification lag" (structurally derivable), violation of this consumer is constant 0 in simulation when K ≥ 2; violation must appear when K changed to 1 (discriminating power self-evidence).
4. **Absolute values**: Violation count of slow consumer independently given by arithmetic of "scan duration × publish rate − K", simulation exactly matches closed-form.

### Failure Clauses (Hardcoded Before Run)

- Discriminating power self-evidence of criterion 3 misses => model is not measuring reuse, entire round voided.
- C88 (Timeline discrimination for root ring unimplemented) cell cannot answer requirement => honestly mark "blank", do not fabricate.

### Measurement Basis and Known Limitations

- Pure counting model: does not build real scrub, consumption rate is parameter; publish rate 2785/sec is local machine figure (E44 (Local Measurement and Cost of Sequence Number Bit Width)).
- "Reuse" modeled literally per I-7.4 (recent K generations of blocks not reused) (physical extent reallocated), does not model "reused but content happened not to change".
- Prerequisites: none (pure arithmetic + simulation).
