## E123 Trade-off Costs Between K and Rollback Depth —— Run (2026-09-09, criteria hardcoded before run, unchanged after run; 9 unit tests / 11 mutations caught, N=5 rounds md5 identical): **All four metrics distinguish the two arms on every swept tier of S; price difference increases linearly with S, while additionally bought "rollbackable generations" and additionally paid "pinned blocks" are opposite ends of the same axis**

[中文](123-K与回退深度的二选一各要付什么.md) · **English** · [日本語](123-K与回退深度的二选一各要付什么.ja.md)

**What it calculates is the cost of the trade-off in C215 (promises on rollback depth and lower bound on K cannot hold simultaneously)**,
so that when handing off this fork both arms carry numbers, rather than merely the statement "both must undergo tripartite review".

| Arm | What Is Modified | Whose Clause Is Modified |
|---|---|---|
| **Arm ①** | K ≡ root ring depth | "K itself is runtime policy, lower bound ≥ 2" in I-7.4 (Blocks in the Last K Generations Have Not Been Reused) |
| **Arm ②** | Rollback depth ≤ K | **User settlement** (2026-09-05) "rollback depth ≤ root ring depth" in D23 (Journal Role & Format) settled item 14 |

### What to Measure

Four metrics, reported separately for each of the two arms under **the identical measurement basis**:

| # | Metric | Formula and Provenance |
|---|---|---|
| 1 | **Blocks pinned by I-7.4 (Blocks in the Last K Generations Have Not Been Reused)** | E50 (Upper and Lower Bounds of Root Ring Slot Count) verbatim `N × blocks written per fsync`; substitute N for Arm ①, K for Arm ② |
| 2 | **Accounting key count** | E54 (How Many Generations of Accounting 'Generations' to Retain) measurement basis: metric count × retained generations; D5 (Snapshot / Space Accounting Mechanism) settled item 2 verbatim "**K = root ring total slots + 1** (conservative measurement basis)" ⇒ Arm ① N+1, Arm ② K+1 |
| 3 | **Rollbackable generations** (external commitment) | Arm ① N, Arm ② K |
| 4 | **Phases of ENOSPC escape hatch** | E33 (Two Block-Pinning Rules) verbatim "helpful phases count is `root_ring(K) − 1`" |

Swept dimension: **S ∈ {1, 2, 4, 8, 16}** (R = 3 settled, D22 (Synthesizing Unit Atomicity) settled item 2)
⇒ root ring depth N = 3S ∈ {3, 6, 12, 24, 48}; Arm ② takes K as lower bound **2** from I-7.4 (Blocks in the Last K Generations Have Not Been Reused).

### Criteria (Hardcoded Before Run)

| # | Criterion |
|---|---|
| 1 | All four metrics must be given for both arms under **the identical measurement basis** —— one arm reporting block counts while the other reports byte counts is forbidden |
| 2 | Each metric must be **given per S**, taking values at only a single S is forbidden (`.claude/singlefs-ai-sop/rules/evidence-discipline.md` "Did I only sample at one point?") |
| 3 | **Positive control**: at S=1 (N=3) "rollbackable generations" of both arms must differ (3 vs 2). Identical ⇒ model fails to distinguish both arms, **entire round invalidated** |
| 4 | **Negative control**: set Arm ② K to N (both arms converge) ⇒ all four metrics must be **equal cell by cell**. Not equal ⇒ **entire round invalidated** |
| 5 | **Each metric must have assertions pinning absolute values**, mutual comparisons between arms alone forbidden (`.claude/singlefs-ai-sop/rules/test-discipline.md` "Comparing multiple arms only against each other cannot detect when all arms are wrong together") |

### Failure Clauses (Hardcoded Before Run)

- Failure on criterion 3 or 4 ⇒ **entire round invalidated**.
- **Any metric being identically equal across both arms** ⇒ record faithfully that "this metric cannot distinguish the two arms",
  **tweaking parameters to fabricate differences is forbidden**.
- Deterministic model: running N rounds proves only absence of hidden state, not statistical stability.

### The Other Half It Cannot Answer (Hardcoded Before Run)

1. **"How deep a rollback suffices" is a product judgment, experiments cannot answer it.** The shape is identical to disposal of F
   in E48 (Feasible Points of Root Ring Geometry) —— experiment provides costs, value choice is settled by user.
2. **Writing 13 blocks per fsync** is taken from coarse-grained settlement in D25 (Target Workload Priority) (8 leaves + 1 shared spine + 1 root + 1 record),
   which is a workload model set by decision, **not measured**.
3. **Metric count 64 has zero provenance**: E54 (How Many Generations of Accounting 'Generations' to Retain) verbatim
   "**how many metrics there are** is an input not a measurement —— this project has no metric inventory yet (D5 (Snapshot / Space Accounting Mechanism) settled item 1 remains open)"
   ⇒ **absolute values** in accounting key column scale linearly with this figure, with only column ratios and directions of both arms unaffected by it.
4. It does not judge which arm is right, only balancing the ledger between both arms.

### Actual Run (2026-09-09)

⚠️ **Deterministic model**, N=5 rounds only proves absence of hidden state; evidence strength derives from 9 unit tests and 11 mutations.

#### All Four Metrics Distinguish the Two Arms, None Being Identically Equal

Artifact verbatim `name=discriminating s_total=5 pinned=5 accounting=5 rollback=5 phases=5`
⇒ across all five swept tiers of S, all four metrics **cell by cell** distinguish both arms.
Positive control `name=poscontrol_s1 ring_depth=3 arm1_rollback=3 arm2_rollback=2 differs=1` ——
**both arms already separate on the smallest ring**; negative control `name=negcontrol_merged all_equal=1 expect=1`.

#### Price Difference Table: What Arm ① Pays More and Buys More Compared to Arm ②

| S | Root Ring Depth N | Additional Pinned Blocks | Additional Accounting Keys | Additional Rollback Generations | Additional Escape Phases |
|---|---|---|---|---|---|
| 1 | 3 | **13** | 64 | 1 | 1 |
| 2 | 6 | 52 | 256 | 4 | 4 |
| 4 | 12 | 130 | 640 | 10 | 10 |
| 8 | 24 | 286 | 1408 | 22 | 22 |
| 16 | 48 | **598** | **2944** | **46** | 46 |

**Additional rollback generations and additional escape phases are cell-by-cell equal** (both equal N − K), which is no coincidence ——
phase count in E33 (Two Block-Pinning Rules) is verbatim "`root_ring(K) − 1`", sharing the identical independent variable with rollbackable generations.

⇒ **Trade-off between both arms in one sentence**: For each additional generation of rollback depth Arm ① buys, it pins 13 more blocks and stores 64 more accounting keys;
Arm ② pins rollback depth to 2 generations, with pinned blocks and accounting keys not growing with S.

#### Absolute Values (Not Price Differences, but Each Arm's Own Quantities)

Arm ② constant: pins **26 blocks**, **192** accounting keys, rollback **2 generations**, **1** escape phase.
Arm ① scales with S: at S=1, 39 blocks / 256 keys / 3 generations / 2 phases; at S=16, **624 blocks / 3136 keys / 48 generations / 47 phases**.
⚠️ 624 blocks converted at 16 KiB unit size is **9.75 MiB** —— the "significant" line in E50 (Upper and Lower Bounds of Root Ring Slot Count) is 1000 blocks,
**Arm ① did not reach it across all five swept tiers of S**.
