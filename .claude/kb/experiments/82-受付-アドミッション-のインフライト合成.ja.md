## E82 受入のインフライト合成 —— 実行済み（2026-09-02、純粋算術、7単体テスト / 6ミューテーション全検出）：**直感的な3つの書き方はそれぞれ計算可能な違反を発生：発行済み値のみ参照で 80/120 を過剰販売、ウィンドウ内解放クレジットの早期発行で 20 セルを過早再利用、墓石予約の忘却で満杯後 100 件の削除が全数デッドロック**

[中文](82-准入的在飞合成.md) · [English](82-in-flight-synthesis-for-admission.en.md) · **日本語**

受付・受入（アドミッション）の不等式（権威正文 D28 (マウント時コミットメント量) 確定項目 1、2026-09-13 前は D3 (領域割り当て) 確定項目 4 に配置）における当時の6項目はいずれも**パブリッシュ済み**統計量であり、受入はウィンドウの中間で発生する——「受入の読み出し値 = パブリッシュ済み値 + インフライト overlay」という合成層はリポジトリ全体でカバレッジゼロであった（C87 (受入が読む合成値が未定義)）。E82 (受入のインフライト合成) は暗黙に誤りとなる3つの書き方をそれぞれ計算可能な違反として具現化し、受入パスのテストにおける必須赤ケースを提供する。

### 判定基準（実行前にハードコード、実行後変更なし；すべて閉形式）

1. published_only の過剰販売はちょうど = K×R − 利用可能；overlay の過剰販売は恒常的に 0 かつちょうど ⌊利用可能/R⌋ を承認。
2. クレジット発行アームの過早再利用はちょうど = B 要求 − クレジットなし利用可能；正常アームは恒常的に 0。
3. 墓石予約の忘却 ⇒ ディスク満杯後の削除デッドロックはちょうど = 試行数；予約形態のデッドロックは恒常的に 0、⌊CAP/2⌋ 個のオブジェクトを格納。
4. 3つの違反カウンタはそれぞれ非ゼロを読み出せること（C60 (一定読み出し値に故障注入自己検証がない)）；正常アームはすべて 0。

### 実測（CAP=100 の手計算規模；全表は成果物を参照）

| アーム | 結果 |
|---|---|
| published_only（K=4 × R=30、パブリッシュ済み利用可能 40） | 4件すべてゲート通過、**80セル過剰販売**——割り当て途中で初めて失敗 |
| **overlay（正しい形態：パブリッシュ済み − インフライト承認済み）** | ちょうど 1 件承認、3 件拒絶、過剰販売 **0** |
| credit_frees（ウィンドウ内解放を利用可能として計上） | B がゲート通過、**20セルが defer で保留すべきブロックを侵食**——D16 (パブリッシュセマンティクス) 確定項目 15 が暗黙に迂回される |
| forget_tombstone（受入で「自己のアンラップ」を未計算） | 100個のオブジェクトを格納、ディスク満杯後 **100件の削除が全数デッドロック**；予約形態は 50 個格納、デッドロック 0 |

⇒ **正しい形態の要約**：受入読み出し値 = パブリッシュ済み統計量 − インフライト承認済み；ウィンドウ内解放には**クレジットを発行しない**（D16 (パブリッシュセマンティクス) 確定項目 15 の受入側形態）；「自己のアンラップ」は墓石のセルを含む（D3 (領域割り当て) 確定項目 2 の実行可能な解釈）。3つの各々に赤となるカウンタを配置し、クラッシュポイント再生および受入単体テストにそのまま活用可能。
**正しい形態は確定済み（2026-09-02）：D28 (マウント時コミットメント量) 確定項目 2（2026-09-13 前は D3 (領域割り当て) 確定項目 6）。**

### 失敗条項（実行前にハードコード）

判定基準 1–4 はすべて的中。無効化はトリガーされず。

### 答えられないこと

純粋算術、ファイル操作 0 箇所。defer ウィンドウ時間長、複数デバイス次元、回収不能容量はモデル化されていない；「墓石1セル」は E83 (墓石の粒度) で粒度を決定する前の過大見積もり計測条件——粒度決定に伴い定数は置き換わるが、判定の形状は不変。

### 計測条件と再実行

- コード `scripts/experiment-apparatus/e82_admission_overlay.rs`（`cargo run --release --bin e82-admission-overlay`）、元出力 `e82-admission-overlay-2026-09-02.out`（8行、完了行 `emitted=8`）。
- 純粋算術、5ラウンド同一 md5。**7単体テスト、6ミューテーション逐一的中、盲点 0**、ミューテーション表 `scripts/mutation/tables/e82_admission_overlay.tsv`（`bash scripts/mutation/mutate.sh e82-admission-overlay scripts/experiment-apparatus/e82_admission_overlay.rs scripts/mutation/tables/e82_admission_overlay.tsv`）。
