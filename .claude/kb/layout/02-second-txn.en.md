# Bytes Written by Overwrite, Release, Rollback, and Reuse (On-Disk Patterns Absent in New-Pool File Creation)

[中文](02-second-txn.md) · **English** · [日本語](02-second-txn.ja.md)

**Registry table for Step 7 of milestone "Overwrite, Release, Rollback, and Reuse"** ([02-second-txn.md](../milestone/02-second-txn.md)), established 2026-09-17. Each byte segment of new-pool file creation is in [layout/01-first-txn.md](01-first-txn.md); here we only register the **newly written** patterns of overwrite, release, rollback, and reuse—widths and placements of identical fields still follow that table without duplicate copying, recording the value of "first non-zero / first appearance" and the decision items it rests upon. The registry location is `.claude/kb/layout/02-second-txn.md` (a file under `.claude/kb/layout/` sharing the same number with the milestone, per `.claude/rules/path-moves.md` "place files incrementing by milestone into the same directory"); each row points to a milestone step and its "Bytes Written" line, with actual bytes pinned by test cases in `crates/singlefs-harness/tests/` named in the "Test Cases Pinning It" column of the registry (the new-pool file creation table is pinned by artifacts of E142 (New-Pool File Creation Dry Run); overwrite, release, rollback, and reuse have no dry-run artifacts).

⚠️ The first two patterns in the table (released allocation records, non-zero defer release rows) already appeared in the first file version A (txg 3): when A rewrote the tree table, it released the version 0 tree table unit from mkfs (defer row 16384 in the table of D5 (Snapshot / Space Accounting Mechanism) settled item 8, bytes in [layout/01-first-txn.md](01-first-txn.md)). They remain in this table registering the state after B; the heading stating "absent in new-pool file creation" held true for these two only when the table was originally drafted.

## Measured in Run of E152 (File System Benchmark by Milestone) 2026-09-17 Step 7

Publish B on real devices (two 16 GiB virtio disks) produced identical byte results across 5 rounds: 21 write calls across both disks (guest block layer recorded 26 write requests: each barrier and FUA recorded once extra), 344,576 bytes (2 × 172,032 + root slot 512), 4 barriers, 1 FUA, segment sequence 16+2+1+2, (at the time) isomorphic to `path=transaction` of new-pool file creation—recorded on `name=summary` line of artifact `e152-file-system-benchmark-second-transaction-2026-09-17.out`, table in Section III.2 of `scripts/experiments/perf-by-milestone.md`. Bytes written by rollback, raising F, and reuse publishes are pinned solely by crash-point replay and test cases, unmeasured on real devices.
