# Pending Experiments

[中文](experiments.md) · **English** · [日本語](experiments.ja.md)

**Before running any experiment, three things must be clearly defined: what is being tested, what the criteria are, and what constitutes failure.**
If the criteria cannot be written down, it means the problem has not been thoroughly thought through and running is forbidden—setting criteria after running is equivalent to issuing oneself a certificate.

<!-- doc-lint:not-numbers M23 M24 -->
`M` plus a number is the intra-page identifier for each experiment's mutation table: each mutation table starts numbering from M1 independently; the same number refers to different mutations on different experiment pages and cannot be tracked repository-wide; references should be based on the mutation table of that specific page.

Each experiment page includes a section "### Impacted Decisions", specifying item by item whether it supports, overturns, prepares material for, or has no impact on which decision. Every row must be reviewed whenever an experiment produces new conclusions; see `.claude/rules/format-evolution.md` "Decision body only describes current state, rationale as pointers; two-way registration of decisions and experiments", checked by gate doc-experiments `decision-links` cell.

Follow `.claude/singlefs-ai-sop/rules/test-discipline.md`: N≥5 rounds,
a "Pass" verdict requires all rounds to pass, a "Fail" verdict requires all rounds to fail; if neither is satisfied, report "unstable".
