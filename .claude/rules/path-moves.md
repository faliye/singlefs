# 文件与目录的路径不在冻结范围内

`.claude/rules/evidence-discipline.md`「原样保存的证据不许事后改」冻结的是内容（提示说了什么、腿答了什么、产物量到什么数），不冻结文件与目录的路径：一个文件或目录搬家、改名，全仓指向它的地方一次改成新路径，`research/prompts/`、`research/results/`、`records/`、变更史与历史版本节、别的会话的记录都算；旧路径只留「怎么做」第 5 步留的那几处。

## 怎么做

1. **搬之前把旧路径的全部写法搜一遍，清单留在手边**：整条路径、`kb/` 起的写法、光文件名、不带 `.md` 的名字，四种各搜一次；整串替换打不到的写法另搜：正则里的交替与分组（`<上一层>/(<旧名>/…|…)`）、拆成几段的写法（`"<上一层>", "<旧名>"`、`os.path.join(…, "<旧名>")`）、相对路径（`../<旧名>`）、rsync 与 glob 的排除写法（`--exclude /<旧名>/…`）、把 `/` 换成别的字符拼出的名字（`<上一层>__<旧名>__…`）。输出不截断：`grep -c` 先数，数对上了再看内容。
2. `git mv` 搬，在同一次改动里往 `.claude/gate.d/path-moves.tsv` 登记一行（旧前缀、新前缀、日期、出处），整个目录与单个文件都能登记。
   - **整目录搬，搬前搬后各跑一次 `python3 scripts/kb/move-directory-in-use-check.py`**：搬之前跑 `<旧目录>`，退 0 才 `git mv`；退 1 时等它列出的进程退出、子 agent 交回再搬，等不了的给在跑的子 agent 发消息改路径。搬完当场跑 `<旧目录> --moved-to <新目录>`：退 1 照它给的出路做（还有引着旧路径的，在旧路径留一条指到新目录的符号链接、不 `git add`；都交回了删掉那条链），做完再跑；退 3 是链留着、还有引着的，等它们交回再跑；退 0 才算搬完。
   - 一次改动里一条路径只搬一次；分几步搬的，搬一步、等 gate 基准前移（推上去，或 gate 基准那一版里已有新前缀）再登记下一步。
   - 把命令里的目录换成另一个已有的目录、换了实现的，不登记，照真改动交审。
   - 整份搬进另一个按路径管的类的，照算改动，新增行一条不剔：`.claude/agents/`、`.claude/agent-common.md`、`.claude/main-agent.md`、`.claude/rules/`、`.claude/hooks/`、`.claude/gate.d/` 顶层、`.claude/singlefs-ai-sop/rules/`、`crates/<包>/src/` 各算一类。
   - 登记行什么时候生效、门禁照它换算哪几样、改动范围与新增行里只差搬迁的怎么剔、登记表怎么判（写法、不许串、搬迁实据、新行必须生效）与门禁关不住的几样，写在 `.claude/gate.d/lib-lag-baseline.py` 文件头「搬迁登记」。
3. 照第 1 步的清单逐处改成新路径。Markdown 链接按**每个文件自己的位置**重算相对路径，不照抄仓根路径。
4. **改完照同一份清单再搜一遍，除第 5 步留的之外 0 命中**；再逐个打开被改的文件，确认新路径指得到东西，并按各自的解析基准逐类核：`Cargo.toml` 的 `path =` 按 crate 根解析，`replay.sh` 登记表的产物列要纯文件名。旧路径搜不到不等于新路径是对的。
5. **说搬迁这件事本身的那一行留旧路径**：同一行里旧、新路径都在，或带「改前」「搬到」「搬进」「搬迁」「改名为」这类记变更的词。换成新路径之后那句话就成假话的同样留：指 git 历史的写法（`<提交>:<路径>`，`git log`、`git show`、`git blame` 里 `--` 之后的路径）、抄下来的命令和它的输出。门禁 doc-registries 的 governance-refs 格在 kb 里自动认两种：git 历史命令里 `--` 之后的路径、同一行还写着后继文件名的搬迁行；其余人判，判过该留旧路径的（将来落点、句子本身说它不在、抄下来的命令或输出、仓外副本里的路径）登进 `.claude/gate.d/dead-path-kept.tsv`，一行一对（载体、路径）带理由。
6. 判决或核对表里记过的 sha256 因此对不上：只差路径的不算证据被改，在那一轮的记录里写明哪个文件、改了几处。产物里带路径的，装置源码与留存产物一起改，复跑仍要逐字相同。
7. **门禁、钩子与脚本的自检样本和用例跟着搬**：被搬的路径、包名或目录布局出现在哪道门禁、哪个钩子、哪个脚本的判据里，就把它们的样本（`fixtures/` 下的 red 与 green、自检里造的临时仓）与自检用例一起改成新布局，每个弄坏开关仍要判红。搬迁让判据的某一支没了对象（按旧名字、旧目录认的那一支），把那一支连同它的自检用例、弄坏开关一起删掉。

## 按里程碑递增的文件放进同一个目录

同一类随里程碑一份一份长出来的 kb 文件（字节布局表之类）放进一个目录，文件名 `NN-简称.md` 与 `.claude/kb/milestone/` 同号，不在 kb 根目录下并排起 `first-…`、`second-…`，也不把几份合成一份。例：`.claude/kb/layout/`（`01-first-txn.md`、`02-second-txn.md`）。新立这类文件直接建目录；已经并排起了名的，照「怎么做」搬。

## 改一个全仓术语：正文之外还有五处会红

术语改名（把一个概念的中文名全仓换掉）登记在 `.claude/kb/term-renames.md`（「匹配」一列写 `整串`、`词边界` 或 `正则`；同一个串在别处是另一个量时写 `正则`，只打这一个概念的写法；写法在 `scripts/kb/sweep-term.py` 文件头），落地一次做完：用 `scripts/kb/sweep-term.py` 把全仓（git 跟踪的与未跟踪而未忽略的文件）的旧名换成新名，正文之外还有五处会红：

| 跟着要改的 | 哪道门禁会红 | 怎么做 |
|---|---|---|
| **编号的简称** | kb 里由 doc-lint、kb 之外的 D / E 编号由共享 `gate.sh` 的「编号与简称」阶段判（引用与登记位逐字一致）；C / I 编号在 kb 之外没有检查 | 简称里含旧名的编号全仓一起改，kb 之外的 C / I 引用手工全仓搜；**历史类文件里的引用也改** |
| **简称的宽度上限 48** | doc-lint | 新名比旧名长撞上限的，当场缩简称并全仓同步 |
| **文件名与指向它的链接** | 共享 `gate.sh` 的「链接指向」阶段 | 文件名含旧名的，照「怎么做」搬 |
| **决策分项清单** | 门禁 doc-decisions 的 kb-shape、decision-items-sync 两格 | 跑 `SINGLEFS_RUN_SCOPE='种类=items; 跑什么=门禁 doc-decisions.sh 的 decision-items-sync 格（--write）; 范围=1 格; 为什么=…' bash .claude/gate.d/doc-decisions.sh --write --check decision-items-sync` 重新生成 |
| **实验页的「影响的决策」回看** | 门禁 doc-experiments 的 decision-links 格 | 纯改名也触发：逐行回看、写当天日期与「不受影响：改名只动措辞，结论、数与产物不变」 |

**留存产物分两类**，判据是「这份产物跑得出来吗」：装置源码在树里、`replay.sh` 判 `exact` 的产物，跟着源码一起换名，换完复跑仍要逐字节相同；已归档、要虚机或真设备、别人的产物，一个字节都不动，连同引它的正文整段留旧名，登记进 `.claude/term-rename-exempt`。引它的文件名本身不用登记：`scripts/kb/sweep-term.py` 把文件名形态、历史里 `research/results/` 下出现过而树里没有的串当已归档产物的名字，不换也不报；把这类串一起换掉了的，换回旧名（门禁 doc-experiments 的 results-cited 格在历史里按旧名找）。

**历史类文件同样换名**（`.claude/kb/decisions-history.md`、`experiments-history.md`、`records/`）；换了就成假话的那一句留旧名，判据同「怎么做」第 5 步（整行抄自已归档产物的、别家的术语与原文引文、记「这个词被改掉了」这件事本身的）。留旧名的登记进 `.claude/term-rename-exempt`、写明为什么：只有一句留旧名的按行登记（`<路径>:「<那一行里的一段原文>」`，只豁免那一行），整份都留旧名的逐文件登记，不整个目录豁免；变更史里加一条改名条目当索引，写明旧名指的就是新名。

英文标识符与中文术语可以分批改：只改中文时门禁 code-source-discipline 的 format-constants 格不红。

## 变体起新名字，不用角标

候选、臂、方案、命题、提问编号有了变体，给变体起一个新名字，不在原名后面加撇号类字符（U+2032、U+2033、U+2034、U+02B9、U+02BA），也不用 ASCII 单引号代替：

1. 先定这个名字属于哪一族、那一族在哪几份文件里定义与被引用（同一个字母加数字，在两个轮次、两个实验里可能是两件事）。
2. 在那一族里取下一个没用过的号；取号会造成误读的，起一个不超过 8 个汉字的描述性名字。
3. 新名字在那一族的全部文件里零命中。
4. 变体与原名的关系写在新名字的定义那一句里，不写进名字。

门禁 doc-text 的 prime-marks 格扫全仓（冻结证据也在内），撇号类字符一处就判红；ASCII 单引号当角标它判不了，靠写的人与 review。

## 门禁管哪一半

- 搬迁：共享 `gate.sh` 的「链接指向」阶段判 Markdown 相对链接；门禁 doc-registries 的 governance-refs 格判治理文档与 kb 中文页反引号里的路径：kb 里不在的路径判红并写出 `scripts/kb/path-successor.py` 找到的后继，`research/` 下进过 git 的放行，存量在只缩不涨的 `.claude/gate.d/dead-path-lag.tsv`，照规矩留旧路径的在 `.claude/gate.d/dead-path-kept.tsv`。
- 搬迁登记表由门禁 code-tooling 的 change-range-single-source 格判，判法与关不住的几样在 `.claude/gate.d/lib-lag-baseline.py` 文件头「搬迁登记」。
- 靠人的：活文件（代码、脚本、表）里还剩不剩旧前缀与旧包名、新路径指得对不对、`Cargo.toml` 与 `replay.sh` 登记表按各自基准解析得对不对、保留表里登的理由对不对与哪一句该留旧路径；「怎么做」七步都靠人跑（第 7 步的自检由各道门禁、钩子与脚本自己的自检跑，样本改没改靠人），第 1、4 步自己搜到 0 命中、打开文件看。
- 术语改名没有门禁复查全仓剩几处旧名：改完用 `scripts/kb/sweep-term.py --check` 自己查（登记在 [.claude/kb/term-renames.md](../kb/term-renames.md)）。
