# 文件与目录的路径不在冻结范围内

**这是 singlefs 的项目本地规则**，不在共享 SOP 里。共享规则在 `.claude/singlefs-ai-sop/rules/`。

`.claude/singlefs-ai-sop/rules/evidence-discipline.md`「原样保存的证据不许事后改」冻结的是**内容**：发给模型的提示说了什么、腿答了什么、产物量到什么数。
**文件与目录的路径不在冻结范围内**：一个文件或目录搬了家、改了名，全仓指向它的地方一次改成新路径——`research/prompts/`、`research/results/`、`records/`、变更史与历史版本节、别的会话的记录都算，不留一处旧路径。

## 怎么做

1. 搬之前在 `research/scripts/path-moves.tsv` 登记一行：旧路径、新路径（都从仓库根写）、日期、依据。
2. 搬完跑 `python3 research/scripts/rewrite-moved-paths.py --apply`：Markdown 链接按每个文件自己的位置重算相对路径，其余写法（整条路径、`kb/` 起、文件名、不带 `.md` 的名字）按登记表改，改完回读。别的会话正在写的文件用 `--skip` 跳过，把旧路径与新路径的对照发给它自己改。
3. 说搬迁这件事本身的那一行保留旧路径：同一行里旧、新路径都在，或带「改前」「搬到」「搬进」「搬迁」「改名为」这类记变更的词——变更史里「改前：链接指向旧路径」照旧是真话。
4. 改写会让被改文件的 sha256 变：判决或核对表里记过的 sha256 对不上时，先对 `path-moves.tsv` 的日期；只差路径的不算证据被改。产物里带路径的，装置源码与留存产物一起改，复跑仍逐字相同。

## 按里程碑递增的文件放进同一个目录

同一类随里程碑一份一份长出来的 kb 文件（字节布局表之类）放进一个目录，文件名 `NN-简称.md` 与 `.claude/kb/milestone/` 同号，不在 kb 根目录下并排起 `first-…`、`second-…`。要的是放进一个文件夹，不是把几份合成一份。第一例是 `.claude/kb/layout/`（`01-first-txn.md`、`02-second-txn.md`）。新立这类文件时直接建目录；已经并排起了名的，按「怎么做」那一节搬。

## 改一个全仓术语：正文之外还有五处会红

路径搬迁之外的另一类是**术语改名**（把一个概念的中文名全仓换掉）。它不归本规则的登记表管，落地时同样要一次做完：正文改完之后还有五处会红。

| 跟着要改的 | 哪道门禁会红 | 怎么做 |
|---|---|---|
| **编号的简称** | doc-lint（登记位与全仓每处引用要逐字一致） | 简称里含旧名的编号全仓一起改（那次 17 个：`C245`、`I-7.7`、`E126`……），**历史类文件里的引用也要改**——引用与登记位不一致就红，与那句话是不是历史无关 |
| **简称的宽度上限 48** | doc-lint | 新名比旧名长时可能撞上限（那次 C232 从 48 涨到 50），要当场缩简称并全仓同步 |
| **文件名与指向它的链接** | 23 号（文档指向） | 文件名含旧名的，按本规则登记 `path-moves.tsv`、`git mv`、跑 `rewrite-moved-paths.py --apply`；只改链接文字不改文件名，链接当场失效 |
| **决策分项清单** | 20 / 21 号 | 清单是正文的投影且按宽度截断，名字变长会让截断位置变 ⇒ 跑 `21-decision-items-sync.sh --write` 重新生成 |
| **实验页的「影响的决策」回看** | 75 号 | 它的判据是「正文有新增行、而影响的决策表一行没动」⇒ 纯改名也触发。逐行回看、写当天日期与「不受影响：改名只动措辞，结论、数与产物不变」 |

**历史类文件保留旧名**（`.claude/kb/decisions-history/`、`experiments-history.md`、`records/`），判据与本规则第 3 条同形：把旧名换成新名之后那句话还是不是真话——它们断言「那一天文件字面写了什么」，换了就是假话。**代价是新旧名长期并存**：变更史里要有一条改名条目当索引，写明旧名指的就是今天的新名。

⚠️ **英文标识符与中文术语可以分批改**：只改中文时 `format-const` 标记名与源码里的 `const` 名仍成对，门禁 27 号不红；而 `crates/` 正被别的会话改时，先改中文不会让它编译失败。

## 门禁管哪一半

`.claude/gate.d/64-moved-paths.sh` 用同一个脚本的 `--check` 查全仓不再出现登记过的旧路径，判别力样本在 `.claude/gate.d/fixtures/64-moved-paths.sh/`。
**它管不到的**：没登记的搬迁（登记表是它唯一的输入）；路径以外的改名（章节标题、编号、简称）不在这条规则里，照旧按冻结与 `kb-discipline.md` 办。
