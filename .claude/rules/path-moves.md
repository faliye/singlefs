# 文件与目录的路径不在冻结范围内

**这是 singlefs 的项目本地规则**，不在共享 SOP 里。共享规则在 `.claude/singlefs-ai-sop/rules/`。

`.claude/singlefs-ai-sop/rules/evidence-discipline.md`「原样保存的证据不许事后改」冻结的是**内容**：发给模型的提示说了什么、腿答了什么、产物量到什么数。
**文件与目录的路径不在冻结范围内**：一个文件或目录搬了家、改了名，全仓指向它的地方一次改成新路径——`research/prompts/`、`research/results/`、`records/`、变更史与历史版本节、别的会话的记录都算；除「怎么做」第 5 步留的之外，不留一处旧路径。

## 怎么做

**没有专管搬迁的门禁**：Markdown 相对链接由共享 `gate.sh` 的「链接指向」阶段、治理文档反引号里的路径由门禁 doc-registries 的 governance-refs 格兜一部分，`Cargo.toml`、`replay.sh` 登记表、代码与脚本里的路径没人兜，每一步都要自己跑出来看。

1. **搬之前先把旧路径的全部写法搜一遍，把清单留在手边**：整条路径、`kb/` 起的写法、光文件名、不带 `.md` 的名字，四种各搜一次；整串替换打不到的写法另搜：正则里的交替与分组（`<上一层>/(<旧名>/…|…)`）、拆成几段的写法（`"<上一层>", "<旧名>"`、`os.path.join(…, "<旧名>")`）、相对路径（`../<旧名>`）、rsync 与 glob 的排除写法（`--exclude /<旧名>/…`）、把 `/` 换成别的字符拼出的名字（`<上一层>__<旧名>__…`）。输出不许截断（`grep -c` 先数、数对上了再看内容）。
2. `git mv` 搬。在 `.claude/gate.d/path-moves.tsv` 登记一行（旧前缀、新前缀、日期、出处），整个目录与单个文件都能登记。
   - **登记行只在搬迁提交之前对门禁生效**：一行此刻生效，当且仅当这一行不在 gate 基准那一版的登记表里，gate 基准那一版里旧前缀下有文件、新前缀下没有文件；提交进基准之后（基准那一版的登记表里有了这一行）门禁不再按它换算，基准树之后又满足「旧前缀下有文件、新前缀下没有文件」也不醒来。
   - 门禁照此刻生效的登记换算四样，只差仓根起的这一段前缀的不算改动：与基准比只缩不涨的表、改动范围、新增行、门禁 doc-experiments 的 decision-links 格里基准那一版的实验页正文。装置与判决工具（E171、E170 的钉值核对，`scripts/agents/snapshot-tree.py` 的快照倒推）里按 sha256 钉的值按全部登记行倒换，提交之后照旧。
   - 改动范围：与基准只差仓根起的这一段前缀的文件不算这一次碰了的；旧前缀紧挨在 `/` 后面的，`/` 前面要是 `./`、`../`、`$变量/`、`${变量}/`、`<仓根>/` 或本仓的绝对路径，别的目录下同名的一段（`tools/docs`、`vendor/tools`、`/docs`）照算改动。改了路径的文件只在新路径恰好等于旧路径照一行生效的登记换前缀时才可能剔，单个文件登记的文件名（最后一段）不许变。整份搬进别的按路径管的类的照算，新增行一条不剔；`.claude/agents/`、`.claude/agent-common.md`、`.claude/main-agent.md`、`.claude/rules/`、`.claude/hooks/`、`.claude/gate.d/` 顶层、`.claude/singlefs-ai-sop/rules/`、`crates/<包>/src/` 各算一类。
   - 新增行：同一处被删的旧行照登记换算之后与它相同的那一行不算新增，配法是 diff 同一块里第 k 条删掉的配第 k 条加进来的，删加条数不等的块一行都不剔；整份恰好换前缀搬了家的，diff 里没动的行也算旧行，另剔。
   - **不许串**：此刻生效的几行之间，任一行的旧前缀或新前缀不许等于、包含或落在另一行的旧前缀或新前缀下面（A→B、B→A 来回也算）。一次改动里一条路径只搬一次，要分几步搬的，搬一步、等 gate 基准前移（推上去，或 gate 基准那一版里已有新前缀）再登记下一步。
   - **登记行要有搬迁实据**：基准里旧前缀下的每份文件，此刻在新前缀下照换前缀的同一相对路径上都在，而且被 git 跟踪（在索引里，或是没被忽略的工作区文件）；新前缀在基准里没有文件；旧前缀此刻不在磁盘上。
   - **新行必须生效**：不在基准那一版登记表里的新行，旧前缀在基准里没有文件、或新前缀下有基准里本来就在的文件（含只放着占位文件的目录），判红「这一行不是一次搬迁」；登记写在搬迁的同一次改动里，搬迁推出去之后补登记的同样判红。
   - 把命令里的目录换成另一个已有的目录、换了实现的不登记，照真改动交审。
3. 按第 1 步那份清单逐处改成新路径。Markdown 链接要按**每个文件自己的位置**重算相对路径，不是照抄仓库根路径。
4. **改完按同一份清单再搜一遍，除第 5 步留的之外必须 0 命中**；然后逐个打开被改的文件确认新路径指得到东西。⚠️ 「旧路径搜不到了」**不等于**「新路径是对的」。按各自的解析基准逐类核一遍：`Cargo.toml` 的 `path =` 按 crate 根解析，`replay.sh` 登记表的产物列要纯文件名。
5. **说搬迁这件事本身的那一行保留旧路径**：同一行里旧、新路径都在，或带「改前」「搬到」「搬进」「搬迁」「改名为」这类记变更的词。换了就成假话的同样留旧路径，判据与「改一个全仓术语：正文之外还有五处会红」那一节同一条（把旧路径换成新路径之后那句话还是不是真话）：指 git 历史的写法（`<提交>:<路径>`，`git log`、`git show`、`git blame` 里 `--` 之后的路径）与抄下来的命令和它的输出。⚠️ 这条要人判，别做成正则。
6. 判决或核对表里记过的 sha256 会因此对不上：只差路径的不算证据被改，在那一轮的记录里写明哪个文件、改了几处。产物里带路径的，装置源码与留存产物一起改，复跑仍要逐字相同。
7. **门禁、钩子与脚本的自检样本和用例跟着搬**：被搬的路径、包名或目录布局出现在哪道门禁、哪个钩子、哪个脚本的判据里，就把它们的样本（`fixtures/` 下的 red 与 green、自检里造的临时仓）与自检用例一起改成新布局，每个弄坏开关仍要判红。搬迁让判据的某一支不再有对象（按旧名字、旧目录认的那一支），就把那一支连同它的自检用例、弄坏开关一起删掉，不留绿着的旧用例；要查就去 git 历史里找。

## 按里程碑递增的文件放进同一个目录

同一类随里程碑一份一份长出来的 kb 文件（字节布局表之类）放进一个目录，文件名 `NN-简称.md` 与 `.claude/kb/milestone/` 同号，不在 kb 根目录下并排起 `first-…`、`second-…`。要的是放进一个文件夹，不是把几份合成一份。例：`.claude/kb/layout/`（`01-first-txn.md`、`02-second-txn.md`）。新立这类文件时直接建目录；已经并排起了名的，按「怎么做」那一节搬。

## 改一个全仓术语：正文之外还有五处会红

路径搬迁之外的另一类是**术语改名**（把一个概念的中文名全仓换掉）。它登记在 `.claude/kb/term-renames.md`（「匹配」一列写 `整串`、`词边界` 或 `正则`：同一个串在别处是另一个量时写 `正则`，只打这一个概念的写法；写法在 `scripts/kb/sweep-term.py` 文件头）、由门禁 doc-text 的 term-renames 格判全仓（git 跟踪的与未跟踪而未忽略的文件）不再出现旧名，落地时同样要一次做完：正文改完之后还有五处会红。

| 跟着要改的 | 哪道门禁会红 | 怎么做 |
|---|---|---|
| **编号的简称** | kb 里由 doc-lint、kb 之外的 D / E 编号由共享 `gate.sh` 的「编号与简称」阶段判（引用与登记位要逐字一致）；C / I 编号在 kb 之外没有检查 | 简称里含旧名的编号全仓一起改，kb 之外的 C / I 引用要手工全仓搜；**历史类文件里的引用也要改** |
| **简称的宽度上限 48** | doc-lint | 新名比旧名长时可能撞上限，要当场缩简称并全仓同步 |
| **文件名与指向它的链接** | 共享 `gate.sh` 的「链接指向」阶段 | 文件名含旧名的，按本规则「怎么做」那一节搬 |
| **决策分项清单** | 门禁 doc-decisions 的 kb-shape、decision-items-sync 两格 | 跑 `SINGLEFS_RUN_SCOPE='种类=items; 跑什么=门禁 doc-decisions.sh 的 decision-items-sync 格（--write）; 范围=1 格; 为什么=…' bash .claude/gate.d/doc-decisions.sh --write --check decision-items-sync` 重新生成 |
| **实验页的「影响的决策」回看** | 门禁 doc-experiments 的 decision-links 格 | 纯改名也触发：逐行回看、写当天日期与「不受影响：改名只动措辞，结论、数与产物不变」 |

**留存产物分两类，别一把梭**：装置源码在树里、`replay.sh` 判 `exact` 的产物，跟着源码一起换名，换完复跑必须仍然逐字节相同；已归档、要虚机或真设备、别人的产物，一个字节都不许动，连同引它的正文整段留旧名，并登记进 `.claude/term-rename-exempt`。引它的文件名本身不用登记：`scripts/kb/sweep-term.py` 把文件名形态、历史里 `research/results/` 下出现过而树里没有的串当已归档产物的名字，不换也不报；改名时把这类串一起换掉了的，换回旧名，门禁 doc-experiments 的 results-cited 格才在历史里找得到。分不清两类时看一句话：**这份产物跑得出来吗**。跑不出来就不许改它，也不许改引它的那一行。

**历史类文件同样换名**（`.claude/kb/decisions-history.md`、`experiments-history.md`、`records/`）；只有换了就成假话的那一句留旧名，判据与「说搬迁这件事本身的那一行保留旧路径」那一步同形：把旧名换成新名之后那句话还是不是真话（整行抄自已归档产物的、别家的术语与原文引文、记「这个词被改掉了」这件事本身的）。留旧名的登记进 `.claude/term-rename-exempt`、写明为什么：只有一句留旧名的按行登记（`<路径>:「<那一行里的一段原文>」`，只豁免那一行），整份都留旧名的逐文件登记，不整个目录豁免；变更史里要有一条改名条目当索引，写明旧名指的就是新名。

⚠️ **英文标识符与中文术语可以分批改**：只改中文时门禁 code-source-discipline 的 format-constants 格不红。

## 变体起新名字，不用角标

候选、臂、方案、命题、提问编号有了变体，给变体起一个新名字，不在原名后面加撇号类字符（U+2032、U+2033、U+2034、U+02B9、U+02BA），也不用 ASCII 单引号代替它：

1. 先定这个名字属于哪一族、那一族在哪几份文件里定义与被引用（同一个字母加数字，在两个轮次、两个实验里可能是两件事）。
2. 在那一族里取下一个没用过的号；取号会造成误读的，起一个不超过 8 个汉字的描述性名字。
3. 撞号先查：新名字在那一族的全部文件里零命中。
4. 变体与原名的关系写在新名字的定义那一句里，不写进名字。

门禁 doc-text 的 prime-marks 格扫全仓（冻结证据也在内），撇号类字符出现一处就判红；ASCII 单引号当角标它判不了，靠写的人与 review。

## 门禁管哪一半

**搬迁这一半没有专管它的阶段**：「链接指向」阶段与门禁 doc-registries 的 governance-refs 格顺带罩住 Markdown 链接与治理文档里的路径，其余落点靠人。
搬迁登记表 `.claude/gate.d/path-moves.tsv` 写得对不对由门禁 code-tooling 的 change-range-single-source 格判：每一行的写法、出处在；此刻生效的行不串、有搬迁实据；不在基准那一版登记表里的新行不生效的判红「这一行不是一次搬迁」；已在基准那一版登记表里的行不生效，不核。被判的根不在 git 仓里、或在仓里但不是仓根时判不了哪几行生效，不核。「换了实现的不登记」门禁不判，换了的那几份文件照算改动。哪几行生效、改动范围与新增行里只差搬迁的怎么剔，写在 `.claude/gate.d/lib-lag-baseline.py` 文件头「搬迁登记」。「怎么做」那七步全靠人跑（第 7 步里的自检由各道门禁、钩子与脚本自己的自检跑，改没改全靠人），第 4 步那条「旧路径搜不到了不等于新路径是对的」尤其要自己打开文件看。

**门禁关不住的**（改动范围里这几样照算改动，要人看）：
- gate 基准不总是 HEAD：有上游而没推、`--staged` 推完之后里层基准取 HEAD~1 时，搬迁提交之后那一行仍生效，此时删掉一份搬过去的文件、在旧前缀下重用旧名字、搬第二步都判红；出路是搬一步、等 gate 基准前移再登记下一步。
- 钉值一侧按全部登记行逐次倒换：登记表里留着一行老行（旧前缀下已没有文件、新前缀是早就在的另一份实现），再加一行真搬迁，钉住的文件改指那一份早就在的实现，倒换倒得回钉值，钉值一侧认；门禁一侧这份文件照算改动。
- `${变量:-旧前缀/…}` 这类默认值写法：旧前缀前面接 `-`，不换，照算改动。
- 新前缀下基准里已有占位文件的目录：整次真搬迁不生效，登记表那一格判红，问题句点名新前缀下基准里已有的文件。

**门禁管的是另一半**：术语改名归门禁 doc-text（`.claude/gate.d/doc-text.sh`）的 term-renames 格，它按 [.claude/kb/term-renames.md](../kb/term-renames.md) 的登记表查全仓不再出现旧名。
