# 提交时的六道重阶段：主 agent 照这一份跑

子 agent 不跑这几道（`.claude/agent-common.md`「长活交回主 agent」）。主 agent 跑的是 `.claude/rules/implementation-workflow.md`「三步，缺一步就不算做完」第 3 步与「checker 档只在提交时跑，harness 随时跑」里提交时跑的这六道门禁（文件是 `.claude/gate.d/<名>.sh`）：`checker-tier-crash-point-replay`（默认快档，`--full` 只在用户要求时）、checker-tier-qemu-device-streams、checker-tier-lkmm、checker-tier-crates-mutation-replay、checker-tier-formal-verification、checker-tier-broad-mutation（连同它前面起的广谱变异驱动，第 2b 步）。
开工先读：`.claude/skills/crash-test/SKILL.md`「判读纪律」；`.claude/rules/verification.md`「崩溃一致性只能靠崩溃点重放验证」「文件系统特有的反推缺口」；`.claude/singlefs-ai-sop/rules/test-discipline.md`「阴性结果要能和「代码没跑到」分开」。

## 跑之前定下来

- 这次改动的范围：`git diff --stat -- crates litmus` 原样，或提交区间。
- 这一次是提交时跑还是用户要求时跑：决定命令带 `SINGLEFS_HEAVY_TESTS=commit` 还是 `=user-request`。
- `checker-tier-crash-point-replay`、checker-tier-qemu-device-streams、checker-tier-lkmm 各自的内存上限（第 1b 步用），每道一个带单位的上限（例 16G）：`checker-tier-crash-point-replay` 与 checker-tier-lkmm 的写明是量过的（峰值表 `~/.local/share/singlefs/memory-peaks.tsv` 里那一道整条经包装跑出的峰值，且那一行「线程数」一列与这一次跑的线程数相同）还是推的；checker-tier-qemu-device-streams 的不小于同时起的虚机数乘每台的内存（`.claude/gate.d/checker-tier-qemu-device-streams.sh` 的 `MODES` 档数 × `scripts/devices/vm-bench.sh` 的 `VM_MEM`）。
- checker-tier-formal-verification 的两个内存上限（第 1b 步用），各一个带单位的上限：每个 Verus 进程一个（空真与必红世界几处同时验，每处各占一份），E165 装置一个；各写明是量过的（峰值表 `~/.local/share/singlefs/memory-peaks.tsv` 里 Verus 那条命令、装置那条命令经包装跑出的峰值）还是推的。
- 广谱变异驱动（第 2b 步）的两个上限：每条命令的内存上限（驱动的 `--memory-cap`，带单位，写明是量过的还是推的）与线程数（驱动的 `--threads`，取登记的每台默认重活线程数 `.claude/heavy-thread-default`，不给时驱动自己取它）。
- `checker-tier-crash-point-replay` 跑哪一档：默认快档（两趟：`cargo test --release -p singlefs-checker-tier --lib --tests`，再带 `tests/` 里 `cfg` 点到的特性一趟（feature-gated-tests 格），加逐条核全绿标记，`.claude/rules/verification.md`），用户不另说就是它；用户要求全量时带 --full，在 HEAD + 暂存区的 worktree 里跑（照 `checker-tier-crash-point-replay` 快档出路里那三行建）、命令前缀 `SINGLEFS_HEAVY_TESTS=user-request`；要丢掉续跑的进度文件从头跑的，加「--start-over」。
- 要不要跑崩溃放量全量：只在用户要求「崩溃放量全量」时跑（里程碑收尾、动了崩溃点重放或判器的那一批，D13（验证路线） 已定项 9），在同 `checker-tier-crash-point-replay` `--full` 那一棵 worktree 里跑；只跑几个分项的加 `--item <分项>`。
- 草稿目录。
